# _archive —— 存档（不发布）

这个文件夹里的东西**不会出现在网站上**。它以下划线开头、且已加入
`_config.yml` 的 `exclude`，Jekyll 构建时会完全跳过。用来安全地留住
一些「写过、但决定不上线」的旧稿，避免它们随着旧分支被删而丢失。

## the-one-who-remembers/

Leonard Shelby（《记忆碎片》Memento，Guy Pearce 饰）AU 的**早期版本**，
系列名《The One Who Remembers》，酒吧 / bartender 视角，主题曲 Iris，共 3 章。

这个点子后来被**推翻重写**成了线上的《You Are My Fact》（把他从通宵餐馆
带回家的设定，`series/you-are-my-fact/`）。两版是同一个人物、完全不同的
写法。这里保留的是被替换掉的旧稿，仅作留档。

- `2026-06-01-...-chapter-1/2/3-*.md` —— 三章正文（原 `_posts/` 里的文件）
- `series-index.html` —— 原系列首页（原 `series/the-one-who-remembers/index.html`）

> 存档来源：2026-07-07 清理旧分支时，从 `claude/sweet-planck-lt0hcr` 等 8 个
> 分支（内容一致）中提取。存好后这些分支即可安全删除。
