# 卡牌图鉴维护

入口：`sam/shelf/cards/`。从藏品架工具栏进入。

`data.json` 是逐款数量的唯一主账。身份键是系列、卡号、版本；同剧照不一定同款。买到复数修改 `quantity`，不要新建重复条目。`null` 表示未登记，不表示0；`0`只在确认未持有时填写。统计只合计 `quantity > 0` 的逐款记录，含在途。

`legacy` 保留原藏品架的组合记录，未计入逐款总数。逐张核对后再迁移，并移除对应旧组合，避免重复计算。Topps `2/5` 是限编、持有1张，不是数量2。Phantom 40张是旧组合，不能推断成40款。

Infinity Saga ORIGIN 橙色与金边各1张已到手。两款卡背均印有 FP-1，金边的正式平行名与发行年份待确认。FINDING CARD 是卡夹上看到的标记；不据此认定原配或防UV。

图像：`photo` 区分 Winter 实拍与卡面参考图。衣料参考图只用来认款，实际布纹以实物为准。`image` 是正面图，用于列表和导出；可选的 `backImage` 是背面图，可在馆长模式补传，详情可切换正反面并打开大图。两款 ORIGIN 的详情使用各自的正反面实拍。

数量及新卡可在网页馆长模式修改，沿用藏品架的本机钥匙 `ws-sam-shelf-key`。每次写入均重新读取最新仓库文件及SHA，只修改目标条目，409冲突时重读后重试；不把旧的整份本地副本覆盖回仓库。钥匙不进入数据文件、导出图或分享链接。

公开PNG（保存卡面图）不包含数量、已购状态、备注。数量PNG显示已购数量并标明含在途。选中时导出所选卡；否则导出当前筛选。每页最多9款，手机长按或Web Share保存，桌面下载。

本轮初始逐款统计：2010 Iron Man 2 11款18张＋2012 Avengers Assemble #35 1款1张＋Infinity Saga ORIGIN 2款2张＝14款21张。2010 #09、#32尚无购买确认。另收录13款其他系列参考卡，总计29个卡面条目。研究来源见 `sources.md`。


## 精确在手与在途（2026-11-22，覆盖旧的合并状态写法）

Winter已确认：两款ORIGIN各在手1张，其余19张全在途。本轮逐款合计在手2张、在途19张；旧藏组合仍单列。

主账字段为 `on_hand`（实际已收到）、`in_transit`（已购未收到），`quantity`保持两者之和兼容旧筛选。未核对的卡两项均为null，绝不从“含在途”推断精确数。每款、总览、详情和数量导出图都分别显示两项。

“收货1张”从in_transit减1、on_hand加1，总数不变；“新增在途”只给in_transit加1。编辑可填写两项，不再用一个状态下拉框代替数量。
