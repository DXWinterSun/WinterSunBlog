Happiness一日三事

Happiness上架路线

从你的 Mac 到 App Store，一共四段路。这一页一直有效，做到哪儿、打勾到哪儿，下次回来接着看。

  1. 1装好工具你自己，主要是等下载
  2. 2开工看样子Mac 上的 Claude 来做
  3. 3装进你手机要 Jack 在场十分钟
  4. 4提交上架我们一起，审核一两天

动手之前，先知道三件事

  • 名字。手机主屏幕上，图标底下就写 Happiness。但商店里的名字全世界只能有一个，Happiness 这种常见词基本肯定被人占了，到第 4 步要给它加个小尾巴，到时候我给你几版挑。
  • Jack。用他的开发者账号的话，商店页面上“开发者”那一栏会写他的名字（如果他是公司账号，就写公司名）。第 1、2 步完全不用他，第 3 步要他在你 Mac 旁边待十分钟。
  • 歌词。博客卡片上那句 The Fray 的歌词不会印进应用里：上架的应用印歌词有版权风险，审核可能会被退回。Happiness 这个名字本身，就是在向那首歌致意。

1装好工具 你自己来

这一段主要是等下载。可以先开始下，去做别的事。

  1. Mac 上打开 App Store，搜“Xcode”，点 获取。以前装过的话，看看有没有 更新，有就点。

    它有十几个 G，可能要下一两个小时。插上电、连着网，让它慢慢下。

  2. 先弹出一个同意条款的窗口，点 Agree，再输入你的 Mac 开机密码。接着它会问要装哪些平台，勾上 iOS，点下载，再等一会儿。

    装完就可以把 Xcode 关掉，以后不用你亲手碰它。

  3. 在 Mac 的浏览器里打开 claude.ai/download，下载 Mac 版。打开下载好的文件，把 Claude 图标拖进 应用程序，然后打开它，用你现在这个账号登录。

    已经装过的话，这一步直接打勾。

2开工看样子 你点几下，Mac 上的 Claude 来写

这一段不需要 Jack，也不花钱。做出来的应用先在电脑里一台模拟的 iPhone 上跑给你看。按钮上的字要是跟这里对不上（应用更新时常改名字），截图发我。

  1. 打开 访达，点左边的 文稿，在右边空白处点右键（触控板两指轻点），选 新建文件夹，取名 Happiness。

    应用的所有东西以后都放在这里，别删它。

  2. Claude 应用顶上有几个标签，点 Code。再点 Select folder，选“文稿”里刚建的 Happiness。如果让你在 Local 和 Cloud 之间选，选 Local。

    Local 就是在你这台 Mac 上干活。Cloud 是在云端，跟现在跟你说话的我一样，碰不到你的电脑。

  3. 输入框旁边有个选权限的小菜单，选 Accept edits。这样它改代码时不用每次都问你。

    它要运行东西的时候（比如打开模拟的 iPhone），还是会弹窗问你，点允许就行。如果有“以后都允许”这类选项，就点那个，省得一直点。

    弹窗里出现“删除”“rm”“sudo”这类字，或者你心里没底，就先别点，截图发给我。

  4. 点下面的 复制开工口令，粘贴进输入框，按回车。它会先读完说明，存好备忘，再开始写。

开工口令 · 发给 Mac 上的 Claude 
你好！我是冬璇（Winter），完全不懂编程。请在这个文件夹里帮我从零做一个 iPhone 应用，最后要上架 App Store。请先读完下面的说明再动手。

【第一件事】把这整段说明原样存成本文件夹里的 CLAUDE.md（以后开新对话也接得上），再开始干活。

【怎么跟我说话】
- 我看不懂技术：技术上的事你自己拿主意，别让我选；跟我说话用简单的中文，只说效果，别贴命令行。
- 只问我能凭喜好判断的事（颜色、字、样子），而且要在模拟器里做出来给我看，让我挑。
- 小步走：每做好一步，就在模拟器里打开给我看。
- 需要我自己动手点什么，就一步一步说清楚点哪里。
- 如果发现 Xcode 还没装好，或者没有 iPhone 模拟器，先停下来告诉我怎么装。

【这是什么应用】
- 名字叫 Happiness，手机主屏幕上就显示 Happiness。
- 第一版只做一个功能：一日三事，每天写下三件幸运、开心的小事。
- 它来自我博客左下角那叠拍立得里的第一张「每天三件幸运小事」。源码可以参考：https://github.com/DXWinterSun/WinterSunBlog/blob/main/js/polaroid-notes.js（fortunes 那一本；打不开就跳过）。气质要延续：拍立得相纸、暖金色的火花、从暖金到暮色蓝紫的渐变（#c9a16b → #6b5e7a → #3f4a63）、手写的字。
- 商店里同类的「三件好事」应用很多，苹果会退回太简陋的应用，所以要做得完整、精致。

【第一版要有】
1. 今天：一打开就是今天这一页。三行，编号「一、二、三」，边写边自动保存。页顶日期写成 “Tuesday · 30 September 2026” 这样。
2. 翻日子：能往前翻看过去的日子，不能翻到未来。
3. 回看：一个能看到过去所有日子的地方（日历，或者一叠拍立得，做两版给我挑）。
4. 从博客搬家：能读入博客「底片匣」导出的 .json 文件，把我以前写的三件事导进来（格式见下）。
5. 备份：能导出一个备份文件，也能再导回来。
6. 所有内容只存在手机里：不注册、不登录、不联网、不收集任何数据。

【博客导出文件的格式】
{"app":"wiw-polaroid-notes","v":3,"journals":{"fortunes":{"2026-09-30":{"items":["第一件","第二件","第三件"],"ts":1790000000000}}}}
- 只读 journals.fortunes：键是日期，items 固定三条（可能有空的），ts 是毫秒时间戳。
- 更老的文件可能写成 {"lucky":{…}}，意思一样，也要认。
- 同一天两边都有内容时，留 ts 更新的那份。
- 文件里其它部分（notes、marks、别的 journals）跟这个应用无关，忽略。

【技术上照这样来】
- SwiftUI，支持 iOS 17 及以上，只做 iPhone 竖屏。
- 字体：英文用 Caveat，中文用马善政（Ma Shan Zheng），都是开源字体，打包进应用，不在线加载。
- 不要把任何歌词印进应用（有版权风险，审核会退回）。
- 用 git 记录每一步，改坏了能退回去。
- 签名和上架要用我朋友 Jack 的苹果开发者账号，他还没登录。在那之前只用模拟器。Bundle ID 先用 com.wintersun.happiness 占位。

【先别做】
- 没有我明确说“上传”或“提交”，就不上传、不提交审核。
- 其它功能（吐槽窗、写给自己的信、每日提醒、面容锁、iCloud 同步）以后再说，你可以列成建议给我。

现在请：存好 CLAUDE.md → 建项目 → 做出「今天」这一页 → 在模拟器里打开给我看。

  1. 它写一阵之后，会打开一台模拟的 iPhone，里面就是 Happiness。喜欢什么、不喜欢什么，直接在那边跟它说，就像跟我说话一样。

    拿不准怎么说，就截图发回我这边，我帮你翻译成它听得懂的话。

3装进你手机 要 Jack 十分钟

Jack 在你 Mac 旁边，打开 Xcode 的设置，登录他的苹果账号，他手机上会收到一个验证码。他再把你的 Apple ID 加进他的开发者后台。

然后 Mac 上的 Claude 把应用传上去。你在 iPhone 上装一个苹果官方的 TestFlight，就能装上你自己的 Happiness，每天用着试。不用插线，也不用改手机设置。

现在可以先问 Jack 一句：他的开发者账号是“个人”还是“公司”的？答案发我就行，我来决定第 3 步具体怎么走。

4提交上架 我们一起

商店页面要准备这些：商店名（带小尾巴的那个）、几张截图、一段介绍、一个隐私说明网页。截图让 Mac 上的 Claude 在模拟器里拍，隐私说明我在你博客上做好。

交上去以后，苹果审核一般一两天。第一次被退回一两轮很正常，按意见改完再交就是了。

卡住了就截图，发回这个对话。
我看着图告诉你下一步点哪里。
