# 番外五《那几道印子她没有擦》· 他视角 · 写作笔记

Winter 2026-10-02：**「呜呜😭继续！先写‘把您弄脏’那一夜，然后被抓到——骤然从极乐到变故🥺」**
＝ Ch9／Ch10 那三个多月（极乐）＋ Ch11 末那一夜 ＋ Ch12 被抓到（变故）的 B 面。
第一人称「我」＝ Francis。⚠️ 锁未开，他全程「您」。

⚠️ **章名的由来**：她点的是「把您弄脏」那一夜，而那一夜真正的落点不是他说的那句，
是**她的回答**——所以章名落在她那一边：`那几道印子她没有擦`。
⭐⭐⭐⭐ 这是 **Ch1 结尾那层炭灰「你没有擦」的正面回声**，而他到死都不知道那一层也没被擦掉。

## ⭐⭐⭐⭐ 这一篇的题眼：他头一回看见有人不擦他留下的印子

> 我们这行留下的印子，人家都是要擦掉的。这件事不用谁教我，我八岁就知道了。
> 我跟我爹出去干活，走的时候他让我把地上的刨花扫干净，把墙上蹭的那道灰抹掉……
> **他说我们这种人，干完活要让人家看不出来有人来过。**

十月里那一夜，灯底下他看见她锁骨下头一道浅灰——⭐ 他先当是脏东西，伸手要替她擦，
伸到一半认出来那是**自己的指纹**，而且是**好几天以前的**。

⭐ 他的第一反应不是感动，是**吓坏了**（「是不是她病了，是不是那个丫头没给她打热水」），
然后说出那一句：**「我把您弄脏了。」**
→ 她：**「这是我自己留的。」「我天天看见它。我不洗。」**

⭐⭐⭐ 他接不上话（「我这辈子话稠得没完的人，那一下一个字都没有」），
脑子里转的是一笔很笨的账：

> 我做的东西能用二十年……**这个留不了三天。**
> 我手上一辈子做的东西里头，这是最不经用的一样。

→ 「它会掉的。」→ ⭐⭐⭐ **「那你再留一道。」**
⚠️ 中间那一刀：他想起头一天在琴房撑钢琴腿留下的那层灰，**「我想第二天早上就有人擦掉了。」**
——⭐⭐⭐⭐ 读者知道没有，他不知道，一辈子都不知道。

## ⭐⭐⭐ 另外三处新机关

### 1. 他把「跑，Francis」听成了她把名字收回去

Ch12 写他被喊全名时「脸上的东西塌下去了」。他视角给出理由，⚠️ 而且是**误读**：

> 她喊的是 Francis。**她没有叫那一个。**
> 我那一下想的是：完了。她把它收回去了。……她当着这些人不肯叫。
> 我那时候想的是：她想明白了。就是今天夜里，就是刚才那一下，她想明白了我是个什么人。
> **我后来才知道我想错了。我想错了整整三个多月。**

📌 与 extra4 同一个形状（她不出声＝他判拒绝），⭐ 而且与她真正的理由完全相反
（她不叫是**为了不让人听见那个名字**）。这是全系列最大的一处对称误读。

### 2. 他为什么不还手、不跑——两处都是算出来的

- **不还手**：「我要是还了手，这件事当场就变成另外一件事了。一个做工的打了主人家的人，
  那就不是私情，那是案子。案子要报上去，要传人，要问话，**要问她**。」
  ⭐ 更狠的一层：「而他们动手打我，恰恰说明他们还把这件事当成一桩家里的事。
  家里的事是能关起门来的。」→ **「所以我站着让他们打。那是我那一下能替她做的全部。」**
  ⭐ 他甚至在挨打时松了一口气（那种打法他认得，是「让你记住」的那一种，不是往死里打
  ——说明还没闹到外头，说明她还保得住）。
- **不跑**：Ch12 里他盯着那把剪刀不动。⭐ 他视角：**他在看那个尖会不会坏事**
  （「我在算它离皮下面那条脉有多远，算她要是手抖会怎么样」「我这辈子看一样东西只会看一件事：
  它会不会坏」），⭐⭐ 而他不走是因为**他要她先把刀放下**：「您先把它放下。您放下了我再走。」

### 3. 第三级：他本来可以修的

⭐ 新写：头一夜他就说要拿薄木片塞上，**她说不用**；过些日子他真带了裁好的一片，她还是说
「你跨过去不就行了」。那片木片在他口袋里揣了两个多月，后来不知道掉哪儿去了。
⭐⭐⭐⭐ 于是 Ch12 那一声的罪名他自己领了：**「要是我当初修了它，那一夜就没有声音了。
这件事我后来想了很多年。」**

|---|---|

| ⭐ 进院子**蹭三遍鞋，下雨蹭五遍**，外套脱在廊下 | Ch9「我脚上的泥我在院子里蹭干净了再上来」的里子：**人家只要求别弄脏地，是他自己要求的** |
| ⭐⭐⭐ **那只小风箱每夜摆在她枕头边上，离她脸一拃远** | 「那栋房子里什么都是好的……**我做的那个东西离她的脸最近。**」 |
| ⭐⭐ 那三个月**他活干得最好、而且开始攒钱**：「我不敢想我在攒什么」 | 与 Ch15「那包凑份子的钱一分没动」同一条线 |
| ⭐⭐⭐ 「今天不要说对不住」那一夜：他**第二天走在路上才发现自己一句都没说** →「原来那个东西是可以不说的。原来只要有一个人跟我说一声‘不用’。」 | Ch9 那句台词的里子 |
| ⭐⭐⭐ 他第一次睡着：「睡着了就是把自己交出去了……我这个人没有什么东西，只有一双手和一点清醒。」 | Ch9「他后来睡着了」的理由 |
| ⭐⭐ 他醒得早时侧着看她：「我一辈子看东西都是看哪儿要坏……**看她的时候我看不出来她哪儿会坏。**」 | 与 Ch9「他睡着的时候看起来好小」互为反面 |
| ⭐⭐⭐ 雨夜她拿布要给他擦头发，**他把布接过来自己擦**（「我不能让她干这个……要是连这个也让她做，那我就真的不知道我算什么了」），擦完叠成四方放在凳子上 | ⚠️ 这一处是**番外一（二十一岁，她给他抹手）的长线铺垫**：那时他还躲得开，五年后她不许他躲 |
| ⭐⭐⭐⭐ 「您弹」是**他**要的：他听了两年都是隔着东西听的，「我想知道近了是什么样」→「我听不见。」「我知道。」→ 他把手指合起来 →**「我手上这辈子捏过的东西全是坏的……那一夜我手里头头一回是一样好的。而且不用我修。」** | Ch10 两次手心弹琴的里子 |
| ⭐⭐⭐ 他那三个月怕的不是被抓，**是怕她哪天想明白**：「这件事只要有一个人先醒过来，它就完了。而先醒的那个人不会是我——**我这辈子就没有醒过。**」 | |
| ⭐⭐⭐⭐ 礼拜三：他早就从铁匠铺听说了，**那句「恭喜您」他练了半个月**；⚠️ 而且**只备到那一句为止**——「说完那一句以后怎么办，我一次也没有想过……我这辈子干活从来是备全套的。只有这一件我只备到一半。」 | |
| ⭐⭐⭐⭐ 「那您以后嫁谁」**是真心问的**：「我一辈子替人算东西，算得很准……只有一样我没算进去：我自己。」＋ **「你替人家算一屋子的家什，你不会把墙算进去。墙不是家什。墙就在那儿。」** | ⭐ 系列名那道墙的第三次用法 |
| ⭐⭐⭐⭐ 他为什么答不出「你觉得我嫁谁呢」：**「我知道那句话一说出口就成真的了。成了真的我就得去办……我一个修风箱的，拿什么办。」** → 他吻了她 → ⭐⭐⭐ **「没说出口的就不算数。」「我连那一下都给自己留了后路。我也给她留了。」** | Ch11「那就是回答」的背面 |
| ⭐⭐⭐ 他挨打时喊的那一句：「我这辈子说话从来没有一句说到过点子上。**那一句我说对了。我这辈子就说对过那一句。**」 | |
| ⭐⭐⭐⭐ **结尾**：他跑到路边吐了、蹲下、看见他爹那件外套的袖子撕了一道 → 把两边对齐捏住，捏了很久 → **「这个得缝。」** ⭐ 再加一节：天亮前他回去自己缝好了（「我爹的针脚比我密——他能缝得看不出来，我缝完那儿是一道棱」），然后把那一夜从头过了一遍，⭐⭐⭐⭐ **「从那半口气到门被踹开，中间隔了多久？我算过。不到一刻钟。」** | ⭐ 他天塌了也先报一句活（extra4 的回声）；⭐ 三篇他视角的结尾都落在「他回去的路上／屋里在算」，这一篇算的是**极乐到变故之间有多长** |
| 收束引语 | 「她让我别再想她。我这辈子她说什么我都照办。**那一样我没办到。**」 |

## ⚠️ 守住的铁律

- 他全程「您」；她对他「你」。⭐ 「Franco」只出现在她嘴里（雨夜那一声）与他的回忆里。
- 他一次也没叫她的名字。
- 不预支：逃走后的六天、Snug 送信、她翻窗——全留给下一篇（他视角 ③ 的后半）。
- ⚠️ 不与已发布章打架：第三级那片木片是**新加的**（Ch8／Ch12 只说他没修，理由是「不在活里头」），
  ⭐ 本篇让他补上「后来我提过两回，她说不用」，自责仍然落在他自己身上。
