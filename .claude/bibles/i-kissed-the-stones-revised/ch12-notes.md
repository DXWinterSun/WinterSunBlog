# Ch12《跑，Francis》· 写作笔记

⭐ Winter 2026-09-15 拍板 **B：当场抓到，而且要很突然**（我原先推荐的 C「抓到东西不抓到人」作废）。
她给的画面一条没省。

## ⭐⭐ 抓到那一下

- 接 Ch11 结尾那一脚。屋里一下多了人：父亲、Bardi、**两个从小认得她的男仆**
  （一个赶车、一个管院子）——⚠️ 都是家里人，这是「保密」得以成立的前提。
- ⭐⭐ **母亲随后到，站在门口用手背压着嘴，一个字都没说。**
  → 正文落点：**「那是你这一辈子最疼的一下」**——不是他脸上那一拳，不是父亲那句话。
- ⚠️⚠️ **他一下都没有反抗**（这是他：他不会打人）。他先往前挡了半步（没想，就是挡了），
  然后被拧住胳膊、脸上一拳、肚子上一拳。
  ⭐ 打人的声音写实：「不是你在书里读过的那种声音，是一种闷的、湿的、很实在的声音。」
- ⭐⭐⭐ **他被打的时候喊的还是「小姐」**；被拖走时还在喊
  **「不是小姐的事！是我自己来的！」**（⚠️ 他到最后都在替她省事——Ch10 那条线的终点）。
- ⭐ **父亲全程不看她**，第一句话不是骂：**「谁看见了。」** → 「叫他们都不许说，一个字都不许。」
  → 才对她说「你穿上衣服」。⚠️ 红线执行：他的语言是阶级恐慌与名声恐慌，叙述不替他背书。

## ⭐⭐⭐ 剪刀

- 道具落地：**梳妆台上她的针线匣，那把小剪刀在最上面，她每天用它剪线头，用了十年。**
- 动作：抄起来 → 反过来 → 抵在自己喉咙上 → **屋里一下就静了，走廊那头的拖拉声也停了**。
- 台词（Winter 原话「声音颤抖但坚定」，正文写成两层）：
  「你的声音在抖……**可是你也听得出来另一样东西——那句话下面是硬的，硬得连你自己都陌生。**」
  → **「不许伤他。」「放他走。」「别的我都不在乎。」**
- ⭐ 她真按下去了（一道血，母亲叫了一声）。⚠️ 不重，一寸多长，在喉咙偏左。
- ⭐⭐ 她「不在乎」的具体清单写出来了：这栋房子、这个姓、母亲的脸、那副耳坠、
  镇上怎么说、这辈子还嫁不嫁得出去——**一样一样数过去，然后一样一样放下**。
- 父亲那句「您不在乎，这个家在乎」→ 她只答「那就放他走」。
- ⭐ 破局的是父亲自己抬手：**「放手。」**

## ⭐⭐⭐ 「跑，Francis」——本章的刀

- 她喊的时候**声音不抖了**，而且很大（整栋房子都听见了）。
- ⭐ 他**先不肯走**：站在那儿看着那把剪刀，
  ⭐⭐ 「他看那把剪刀的样子，跟他看一只漏气的风箱是一样的——**他在看那个东西坏在哪儿**。」
- ⭐⭐⭐ **她差一点喊「Franco」，咽回去了**。⚠️ 口径写死在正文里：
  「当着这些人，你不能叫那个名字……你要是喊出来，他们就会知道那是什么。」
  → **「所以这辈子他听见你最后一次叫他，是他的全名。」**
  📌 这是全系列最疼的一处称呼调度，⚠️ **回收点：重逢那一刻她第一句就该是「Franco」。**
- 他听见那句「别再回头，也别再想我」时**脸整个变了**——
  「那一下比那两拳都狠……像有人把一样东西从里头抽走了。」
- ⭐⭐⭐ **他下楼第一声是第三级。** 三个多月、每一夜，他一次都没踩过
  （Ch8 他自己交代过那根木条松了、他当时没动它「因为不在活里头」）。
  **这一夜他踩上去了，整栋房子都听见了那一声。**
- ⭐ 她**一直举着剪刀，举到听不见他为止**；听不见了才松手，剪刀掉在地板上弹了一下，
  然后她的腿软了。

## ⭐⭐ 收尾：她恨自己什么

- 她做对了：这栋房子里只有一样东西压得住父亲——**他女儿的性命加这个家的名声**，
  而她把两样一起架在了他脖子上，三十秒里想出来的，至今想不出第二个。
- 她恨那两个从小认得她的男仆、恨「别在屋里」、恨「谁看见了」、
  恨这一整套「让一个人挨两拳只因为他会修风箱」的规矩。
- ⭐⭐⭐ **而她最恨自己的是：救他那句话不是「等我」。**
  「你在那一瞬间替他做了决定。你把他从你自己身上撕下来……你只给了他一个『别想我』。」
  → 落点：**「你保住了他——用的办法是把他从你自己身上撕下来。」**
