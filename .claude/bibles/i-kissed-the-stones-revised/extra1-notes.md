# 番外一《我爱你》· 炽恋 · 写作笔记

⚠️ Winter 2026-09-17 点的第一篇番外，原话：**「炽恋版『我爱你』🥰就是他被我要到忍不住
脱口而出，本来还端着『我爱您』的他被逼出『你』。」**

她当场挑定的三个岔路：
1. **时间 = 那个夏天里另一夜**（七月，不是六月二十三那一夜）；
2. **收尾 = 第二天早上他又说漏回「您」**；
3. **不用那台簧风琴**（干干净净写那张床，不借别的东西说话）。

## ⭐⭐⭐ 这一篇的机关（一句话）

**白天那个字他学得很快，夜里他就掉回去——不是忘，是他在那件事里最怕。**

他自己在余温里说明白了（本篇最要紧的一段）：

> 「白天您让我叫，那我就照办。那是个活儿。活儿我会办。」
> 「可是这会儿不一样。这会儿我什么都想要。」
> **「我一想要什么，我就又变成那个从后门进来的人了。」**

⭐ 这一层把整个系列的阶级伤口接到床上来了：**他不是不会亲密，他是一旦「想要」就记起自己是谁。**
她的答案只有三个字：**「那你就要。」**（＋「你要什么就说。你说了我就给你。你不说我也知道，
可我要你说。」）→ 他要的是 **「那我要天天都这样。」**

## ⭐⭐ 结构（七段）

1. **她开始记一笔新的账**（母题：账）——一天他说几个「您」：多的时候二十几个，「你」三四个。
   ⚠️ 她没告诉他她在数（「他要是知道了会急，会把它当成一件没办好的活」）。
2. **他回来**：马房两只、人家非给整价、一篮杏、那家女儿撬歪了钉孔（他的声口＝报活儿报价钱）。
3. **规矩**：⭐⭐ **「你每说一个『您』，我就停。」** → 他答「是」，**像领一件活**（回收 Ch9 的形状）。
   ⭐ 他真的当活办：每句话之前停一下，「在脑子里说两遍，嘴上说第三遍」。
4. **实写段（炽恋，按全站 Coach 档写足）**：⭐ 她主控、他手悬在半空不敢碰（三年没变）→
   她抓他手腕按到自己身上、「按着」「是」→ 他用手（⭐ **他摸她像摸皮子，那种一件事没办好
   绝不撒手的专心**）→ 她自己坐下去 → ⭐ 「别咬自己。这儿没有人。」（回收 Ch15「不用压着声音」）。
5. ⭐⭐⭐ **罚＝停**（这一篇的狠处）：**她不起来，也不动，就停在最里头看着他。**
   - 第一回 → 他说出一句实话：**「因为这样我知道它在我这儿，可是我要不着。」**
     → 她动了 → 「要就自己拿。」「说一遍。」「……我要。」「要什么。」「要您。」→ 又停。
   - 第二回 → 他哭了（不是疼，是急），两只手把脸盖起来道歉 → ⭐ 她亲他的眼睛（两边都亲）
     → 他自己回来说「您再要我一回」→ 停 → **「……你。你再要我一回。」**
   - 第三回 → 他已经不会说话了（话稠的毛病到这儿最不改：「再一下」「那儿」「就这么」「别走」
     「我不行了」「小姐」，连叫七八声「小姐」一声比一声低）→ 他不求了，只仰起脸看她：
     **「我学不会。」**
   → ⭐ 她这才松口：**「我要的不是那个字。我要的是你。我要你要我的时候，你还是你。」**
     「现在，你要我。」
6. ⭐⭐⭐ **那句是他自己冲出来的，不是她逼的**（这一点最要紧）：她那时候已经不说话了。
   最里头那一下，他绷起来、仰着脸——**「我爱你——」**，⭐ **他说到第三遍才听见自己**。
   → 她停了（这一回不是罚，是她自己停住）→ 「你说了。」「我没有——」「你说了三遍。」
   → ⭐ 他抖（做完一件很难的事以后那种抖）→ 「我自己说的。」「没有人让我说。」→ 哭着
   一边动一边说，⭐⭐⭐ **「我爱你，小姐。」——那两样东西在同一句话里头。**
   → 「再说一遍。」×3，说到嗓子哑掉。
7. **收尾（她选的）**：第二天早上他端水进来，一开口还是「您——」，⭐ **自己停住**，耳朵红，
   抹一下鼻子（他从小紧张就抹鼻子），只说「……水打上来了」。
   ⭐⭐⭐ **她没有纠正他**——「那个字他要用一辈子学……而你有一辈子。」
   ⭐ 最后一手是热的：她把手伸进那盆凉水里，叫「Franco」「过来」。

## ⚠️ 守住的铁律（逐条对过）

- **「小姐」床上也不改**（系列最狠的一条）→ ⭐ 本篇让它和「我爱你」同句出现，这就是这一篇的声音。
- **「Franco」只落在亲密过程中** → 本篇三处都在床上／余温里，没有一处在白天说事儿时冒出来。
- **他的声口**：话稠、说不出漂亮话（「你今天香」「不知道。就是香。我不会说。」）、
  紧张就说活儿和数字、答「是」、一急就道歉——⚠️ **但道歉不是回避**（Winter 铁律）：
  他难受的时候只会离她更近，本篇他每一次都往她怀里去，没有一次躲开。
- **她主控且宠着他**：罚是停，不是骂；他哭她就亲他的眼睛。
- **锁的状态**：⚠️ 本篇在 Ch21 之后，第②把锁**已经开了**，所以他说「你」是正常的
  ——本篇要的不是「第一次说你」，是**这个字第一次被逼进那件事里**。
  ⭐ 地基是正传已经写好的那句：「那一整个夏天他都还是叫你小姐」＋次晨「您——」自己卡住。
- 红线：两人都成年（他二十一、她二十一）、自愿；不写针对底层的猎奇苦难。
