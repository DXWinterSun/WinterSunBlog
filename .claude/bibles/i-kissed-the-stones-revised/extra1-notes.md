# 番外一《我爱你》· 炽恋 · 写作笔记

⚠️⚠️ **改版记录（2026-09-17，Winter 驳回了我的第一版）**

我第一版写成了「她定规矩：他每说一个『您』我就停」——**写错了**。她的原话：

> 「有点夸张了😂我又不是在调教他，怎么还带惩罚的😂**就是我把他伺候得太好了，
> 他动情的时候自己漏出来的『我爱你』，不是我逼他要求他的呀**🤣
> 咱们好像没写过我给他👄……**可以作为第一次**🤭所以他这么动情」

✅ 定稿口径（⚠️ 往后所有番外都按这个来）：
1. **没有规矩、没有惩罚、没有调教**。她一个字都没有要求过他。
2. **她把他伺候得太好了** → 他动情 → 那个字**自己漏出来**。
3. 👄 **是两个人的第一次**，这就是他这么动情的源头。

## ⭐⭐⭐ 这一篇的机关

**他这辈子给人干了十五年的活，没有一个人伺候过他一回。** 那一夜她什么都没有要他做——
于是那个字自己走出来了。

⭐⭐⭐ 落点那句（她说的）：**「今天夜里你什么都不用干。」**
→ 他**是真的在问**：「那……那我干什么。」（⚠️ 他不是客气，他真的不知道一个人不干活的时候该怎么办）
→ 她把 Ch16 那句还给他：**「你就在这儿。」**

## ⭐⭐ 结构（八段）

1. **她记了一笔新的账**（母题：账）——他一天说二十几个「您」，「你」三四个。
   ⚠️ 她**没告诉他，也没纠正过一回**（这一条在改版里比原来更要紧：她从不要求）。
2. **他回来**：马房两只、人家非给整价、一篮杏、那家女儿把钉孔撬歪了（他的声口＝报活儿报价钱）。
3. ⭐⭐⭐ **杏仁油那一段**（全篇第一刀，也是整个系列最好的一次反转）：
   她让他坐下，**在他跟前蹲下去，给他抹手**。
   - 油是她自己在城里买的，一个铜子一罐（⚠️ 她母亲替她收了十九年的那一瓶，她走的时候没带）。
   - ⭐ 他这辈子干的活就是**给人上油**（Ch1「回头我给您上一点，不算钱」）——现在有人给他上油。
   - 他要抢回去：「这个我自己来。」→ **「我看了三年。今天不用你自己来。」**（回收 Ch19「他抹完油，
     把左手摊开」）
   - ⭐ 他一紧张就算钱：「这个油贵。」「一个铜子。一罐油够抹两个月……这个不划算。」→ **「别算了。」**
   - ⭐⭐⭐ 他手在她手里一点一点塌下去 → 他眼睛红了 → **「……没有人给我抹过。」**
     ＋「我娘走的时候我七岁。她给我洗过脸。手没有——那时候我手上也没有东西。」
4. **上楼**：他伸手要提灯、要关七月里的窗子——⭐ **他一辈子只会这么待着：手上有活他才站得稳**。
   灯照旧留着（Ch15 起他从来不肯吹那盏灯）。
5. ⭐⭐⭐ **👄（两个人的第一次）**：
   - 她往下的时候他起先没明白（还抬手要扶她），明白了就弹起来：**「不行不行不行——小姐，那不行。
     那是……那不该您做。」** ⚠️ 理由他一个字都说不出来，**因为那个理由跟五年前那一句是同一句**：
     「不是那边。先生说走前门。」→ ⭐⭐⭐ 她答：**「这儿没有前门后门。」**
   - 她把他的手放进自己头发里：「扶着。」「我不敢用力。」「不用力。扶着就行。」
     ⭐ 他一次也没有真的用力过——**他这辈子不敢用力拿任何东西。**
   - ⭐ 先用手 → 「不用压着。」（回收 Ch15 章名）→ 低下去 → **他喊的那一声不是话**。
   - ⭐⭐ **他手背上还有两个钟头前那点杏仁油**，于是那一夜她头发上一直有那个味道。
   - ⭐ 她**慢慢来、停三回让他缓**（⚠️ 这不是罚，是伺候：「三年了，他什么时候快到了你比他自己先知道」）。
   - ⭐⭐⭐ 他中间说了一句清楚的：**「谢谢您。」** → **「不许谢。也不许还。你这辈子不用还我一样东西。」**
     （回收 Ch16「我拿什么还您」／Ch17「他心里那笔账他到死都算不平」）
   - ⭐ 他要往后躲（⚠️ 口径：**他躲不是不要，他躲是怕弄坏什么东西**）→ 她按住他的腿 → 他不躲了 →
     那一声「跟五年前他在台上摘掉假发那一回一个样」。
6. ⭐⭐⭐ **那句是他自己漏出来的**：「我爱你——」，⚠️ **她没有停**，他一声接一声说到塌下去。
   → 余温里他问 **「……我刚才说了什么。」**（他是真的在问）→ 「你说了‘你’。」→ 「我没有。」
   → 「你刚才说了很多遍。」→ ⭐ 他不信 → 耳朵红 → 嘴唇抖 → **「我自己说的。」「没有人让我说。」**
   → 无声地哭，眼泪淌到耳朵里 → ⭐⭐⭐ **然后他自己又说了一遍：「我爱你，小姐。」**
   → 「再说一遍。」×3。
7. ⭐⭐⭐ **他自己说出病根**（本篇的心脏，⚠️ 也是改版后最重要的一段）：
   > 「白天您让我叫，我就照办。那是个活儿，活儿我会办。可是到了夜里不一样——到了夜里我什么都想要。
   > **我一想要什么，我就又变成那个从后门进来的人了。**」
   > **「今天夜里我没有要。是您给我的。我没有张过嘴。」**
   ⭐ 她的回答：**「那你以后就要。你要什么就说。你说了我就给你。你不说我也知道，可我要你说。」**
   → 他要的是：**「那我要天天都这样。」**
8. **收尾（Winter 挑的）**：第二天早上他端水进来，「您——」，⭐ **自己停住**，耳朵红，抹一下鼻子
   （紧张就抹鼻子，他从小的动作），只说「……水打上来了」。⭐⭐⭐ **她没有纠正他**——
   「那个字不是学会了就有了的东西。他会说一辈子，也会说漏一辈子……**而你有一辈子。**」
   ⭐ 最后一手是热的：她把手伸进那盆凉水里，叫「Franco」「过来」。

## ⚠️ 守住的铁律（逐条对过）

- **「小姐」床上也不改** → ⭐ 本篇让它和「我爱你」同句出现：「我爱你，小姐。」
  ——「你听了五年的那个称呼，和你等了五年的那个字，他把它们放在了一块儿。」
- **「Franco」只落在亲密过程中／余温里**，白天说事儿时没有一处。
- **他的声口**：话稠、说不出漂亮话、一紧张就报价钱算账、答「是」、一有事就道歉；
  ⚠️ **但道歉不是回避**（Winter 铁律）——他每一次都往她怀里去，没有一次躲开。
- **她主控但是「宠溺型」**：⚠️ 不是支配—臣服，是**伺候**。别再写成罚／规矩／要求。
- **锁的状态**：本篇在 Ch21 之后，第②把锁已经开了；本篇要的不是「第一次说你」，
  是**这个字第一次是在他被好好对待的时候出来的**。
- 红线：两人都二十一、成年自愿；不写针对底层的猎奇苦难。
