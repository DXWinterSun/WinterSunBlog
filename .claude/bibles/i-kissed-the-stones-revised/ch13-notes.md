# Ch13《我爱您，Winter 小姐》· 写作笔记

⭐ Winter 2026-09-15 给的后半段：家里压住消息 / 她不能出门 / 那伙人的口径 /
他托人送来一封很用力的告别信 / 她带着风箱和核翻窗去找他、去敲 Bottom 的门。

## ⭐ 封锁怎么写

- 对外只说**小姐病了**（帖子推了，Chiara 来两回都被挡在门厅）。
  ⭐ Ridolfi 家本来也不来了，**两件事凑成一件，谁也不会往别处想**。
- 那夜在屋里的**一共五个人**（父亲、母亲、Bardi、两个男仆），都被交代过 →
  **全镇没有一个人知道那天夜里发生了什么。**
- ⭐ 门口那把椅子（Nella 坐着做针线）「从来不空」；⚠️ **窗子没有钉**——
  「这栋房子最要紧的规矩是一切看起来都好」（📌 这条同时给了她翻窗的可能）。
- ⭐⭐⭐ **琴房钥匙被收走了**，而且没有人告诉她，是她自己发现的。
  → 落点：**「你原以为你要为了他放弃这架琴。他们提前替你办了。」**

## ⭐⭐⭐ 那一个钟头（本章第一个高点）

第五天母亲哭着替她求来一个钟头，门开着、Bardi 在门口站着。

- 她弹的是**他手心里那一段**，「你从来没有弹得这么好过」。
- ⭐⭐⭐ **而整整一个钟头，她想的全是怎么偷东西**：那张琴凳里有四样东西
  （耳坠 / 佛罗伦萨的谱子 / 那只没有字的小风箱 / 最底下那颗核）。
- ⭐ 她趁 Bardi 转头，把**小风箱和核塞进袖子**，又摸出一截铅笔头，
  在那本谱子第一页写下 **「耳坠我留下了。对不住。」**，把耳坠压在那一行字上面。
- ⭐ 收：**「那是你这辈子最后一次弹那架琴。整整一个钟头，你想的全是怎么偷东西。」**
  ⚠️ 与 Ch11「你永远不能弹给他听」连成一条，别删。

## ⭐⭐ Snug 隔着铁栏杆（本章第二个高点）

- ⭐⭐⭐ **隔着院墙那排铁栏杆说话**——正文点了一句：
  「你这辈子第一次隔着栏杆跟人说要紧的话。你们那出戏里，皮拉摩斯和提斯柏就是这么说话的。」
  📌 **系列名在这里第三次落地**（Ch6 台上那句词、Ch13 这一场、以后还可用）。
- 他说的（Winter 定的口径，照抄）：他们早就知道；**Bottom 头一个知道，
  可他嘴最快却一个字都没往外说**；Quince 说过不止一回、Bottom 骂过他一顿、
  Snout 劝过、Snug 也说了一句——**他不听**。
- ⭐⭐⭐ 海妖那一层用两句话办掉：**「起先我们都怪您。」**
  「想着好好的一个小子……这一带的人家小姐多得是，怎么就他。」
  → **「现在我不怪了。」**
- ⭐ 她必须问的：「他的脸。」→「肿了。牙松了一个。别的没事。骨头没事。」
- 他今夜就走，往北边（那边有人有亲戚）。⭐ Snug 走了七八步又回头：**「他是个好小子。」**
- 📌 选 Snug 是因为他话最少——⭐ **让话最少的那个人来说最要紧的话。**

## ⭐⭐⭐ 那封信（`c-note` 卡片，本章的心脏）

⚠️ **物理形态**要写出来（Winter 说「很用力的告别信」，我照字面办）：
字压得**纸背面全是凸起来的印子，摸上去像摸一块粗布**；三处划掉重写，划得很黑；
⭐⭐⭐ **有一个词他大概不会写，就画了一个东西代替——两片木板，中间鼓起来，一圈小点。
一只风箱。**

内容（按 Winter 给的四层，全部用他的笨口气，没有一句漂亮话）：
1. 「我走了。您别找我。」（⚠️ **他没有让她跟他走，一个字都没提「一起」**）
2. 「这几个月我这辈子没有这么好过。……**您叫我的名字那一回我就想过了，
   那一天要是我死了也够了。**」
3. 「我对不住您。**从第一天我就对不住您。** 我那天不该进您那间屋子，
   我进去了还讲了一上午的皮子。我那天就该走的。」（⭐ 回收 Ch1）
4. ⭐⭐⭐ **一个修风箱的人在告别信里交代怎么修那个玩具**：
   「从缝上开的还能补……从中间开的就不行了，那就不用修了。
   **您别拿它给人看，人会问是谁做的。**」（⚠️ 这一句我最舍不得，别删）
5. 「我太没用了。」……**「可是我爱您，Winter 小姐。」**
6. 署名 **Francis Flute**（⭐ 跟他第一天报名字一样：「……Francis。Francis Flute。」）

⭐⭐⭐ **落点（本章的题眼）**：
「他知道你的名字，从第一天就知道……两年半，他一次都没有叫过。现在他叫了。
**他是写下来的。他连这个都要隔着一张纸。**」
→ 所以她要去：**她要他亲口说。因为她也要说，而且要说一辈子。**（Winter 原话）

## ⭐⭐ 出走

- 穿：里头那件**他解不开系带的睡裙**（Ch8 那一夜那件），外头那件**藕灰高领裙**
  （Ch9 她学会装的那天穿的）——⭐ 领子正好盖住喉咙上那道口子。
- 带：**那只小风箱、那颗樱桃核**。⚠️ 没带钱——
  ⭐ **「因为你没有钱——这栋房子里所有的钱都不是你的。」**（这一句要留着）
- 留：那本佛罗伦萨的谱子、外祖母的耳坠，都在琴凳里。
- ⭐ 翻窗：窗子外头是后廊檐顶 → 檐边挂雨水槽的旧铁钩 → 裙子挂住 → 摔下来
  **右膝先着地，皮破了一片**，她咬着牙数到十，看了一眼，把裙子放下来，站起来，腿抖，
  ⭐ **「可是它能走。那就够了。」**
- ⭐⭐⭐ **回收 Ch4 那颗大钉**：「这是你这辈子第一次自己站在夜里的路上。」
  她想起他那句收回去的「您要是——」，想起自己当时在心里的回答「可是你不路过任何地方」；
  ⭐ 今夜她把他讲过的地方一样一样都路过了（卖草编篮子的老太太、铁匠铺的院墙、
  集市的空场、白天挂一整排鸟笼的地方）——
  **「你一样都没有看见过，可是你一走到跟前就知道是哪儿。」**
- ⭐ 结尾：问一个赶夜车的人才找到 Bottom 家（矮门、门板上有块补过的地方）；
  Bottom 开门，头发乱着，看见一个显赫人家的小姐半夜站在他家门口、裙子上有土、
  膝盖那儿洇了一片深的、怀里按着一只玩具风箱和一颗核。
  → **「我要见他。」「他今天夜里要走。」**
