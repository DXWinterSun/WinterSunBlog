# 番外二《我不该进那间屋子》· 他视角 · 写作笔记

Winter 2026-09-17：**「下面写他视角，从他刚见到我开始！」**
＝ Ch1 那一天（他十六岁，三月末，她家琴房）的 B 面。

## ⭐⭐⭐ 体裁决定：第一人称「我」＝ Francis（⚠️ 往后他视角的番外都照这个来）

站内已有先例（Better Living Through You 的两篇「他视角」番外也是第一人称），但更要紧的是
**只有第一人称办得到一件事：他连在心里都不叫她的名字。** 全篇叙述里她只有「她」和「小姐」，
她的名字出现过**一次**，是她自己说出口的那一次。

⚠️ 由此派生的两条纪律：
1. **他不知道自己看了她**——Ch1 的钉子是「那一路，他自己大概都不知道自己看了」。
   ⭐ 所以第一人称里**不能**写「我看了她的头发、又看了她的手」，只能写那个空白：
   **「我进那间屋子的时候，好像忘了呼吸。后来我想不起来那半分钟我看了什么。
   我记得的是我一低头就开始说话了。」**
2. **院子里那一下不许解释**（圣经：他连想要都没有想）。⭐ 所以结尾用他的算法收：
   他站在那儿算工钱、算皮子、算刀该磨了，算到那第九只「多出来的」→
   **「我回去的路上一直在算明天的活。算到一半我忽然笑了一下。我自己都不知道我在笑什么。」**

## ⭐⭐ 这一篇的心脏：他为什么不敢叫她的名字

Ch1 那颗全系列最大的钉（「他把你的名字收进外套里，一次也没拿出来」）在这里第一次给出理由，
⚠️ **而且理由不是自卑，是经验**：

> 我怕的是另一样——我见过那种脸。人家跟你说说笑笑，你多说了一句、越了那条线，
> 那张脸就会收回去。收回去以后就再也不给你了。那不是生气，那比生气难受得多，
> **那是人家忽然想起来你是谁。**

⭐ 配一段具体的往事把它钉住（新写的）：某年冬天一家太太留他喝一碗热的，他多说了一句
「门轴我也给您上点油，不算钱，顺路」，**那张脸就在那一句上变了**；那一碗他没喝完，
端到院子里泼了，「因为端回去不好看」。

⭐⭐⭐ 落点是他的处理方式（＝他这个人）：**「我把它收起来了。收着就不会弄丢——
别人的东西放在我手里，我从来没有弄坏过一件。」**

## ⭐ 这一篇给全系列添的东西（都不违规，只是把已有的钉子接上源头）

| 新写的 | 接到哪 |
|---|---|
| ⭐⭐⭐ **他那件大一号的外套是他爹的**（Ch1 只写了「照着比他宽一号的人做的」） | 直接解释了 Ch1 的那个观察；⭐ 他还想「等我再长开一点它就合身了」 |
| ⭐ 那一袋家伙也是他爹的，锤柄上那层布是他爹缠的，他没换（「换了它就不是那个手感了」） | 与 Ch17「我现在什么工具都有了」成对 |
| ⭐⭐ **他不写字，八只风箱全记在脑子里**（「我们这行的人脑子里都装着一本账」） | 接 Ch19「我记账。我不记这个」＋ Ch18 他后来也有了一个小本子（⚠️ 不 cue） |
| ⭐⭐⭐ **他在楼梯上不肯敲门**：「我不想把那个声音敲断」（他敲过几千扇门，门一开屋里那件事就断了） | 这是全系列「他只想要别停」这条线的最早一处 |
| ⭐⭐⭐ **生火那一套是他的**：「不能一下压到底。它亮一下你压一下，它暗下去你就等一等」 | ＝ Ch15 他教她的原话、Ch21 她每天早上自己生火、番外一她又教给 Emilia。⭐ 源头在这一天 |
| ⭐⭐ **她坐下了**（他的解读：站着看是查你磨不磨洋工，坐下来才是要看很久） | Ch1 那半秒钟的空白第一次有了解释 |
| ⭐⭐⭐ **没有人接过他的话**：「他们听我说是为了等我说完好干活」→ 所以她那一句「我在听」把他打懵了 | Ch1「你不知道他在谢什么」——⭐ 这里给了答案：他也不知道，他只会说「多谢您」 |
| ⭐⭐⭐ **他报全名是故意的**：「我怕她只听见后头那半个，我怕她从这一天起也喊我 Flute」 | 称呼铁律的 B 面（那伙人喊姓、镇上人喊活计） |
| ⭐⭐ **「我娘也不这么叫我。我娘叫我另一个。那个我没有说。」** | ⚠️ 只埋不揭——Ch7「我娘叫我 Franco」的源头，⭐ 且严守时间线（16 岁时母亲走了六年；Ch8「八年」说的是 Franco 这个昵称，不冲突） |
| ⭐⭐ **炭灰**：他看见了，想擦，抬手才想起自己的手更黑 →「我们这行留下的印子，人家都是要擦掉的」＋「我这辈子留下的东西只有一样不被擦：那些风箱……可没有人知道那是我做的」 | ⚠️ 他不知道她没擦（Ch1 结尾）——B 面最疼的一处 |
| ⭐⭐⭐ **那条旧皮子他带走了、到今天还留着**（旧皮子本来是留着比缝口用的，攒够一堆就烧，⭐ **这一条他没烧**） | ⚠️ 口径：形状必须是**活儿**，不是纪念——「我那天没有想过为什么，后来也没有想」。⭐ 与她那颗樱桃核成对而不抢戏 |
| ⭐⭐⭐ **结尾多一节**：他说的是明天九点，第二天八点半就到了，在巷子口站到九点整才敲门。「我那天也没有想过为什么。」 | Ch2「他大概自己都忘了，你却记住了」的同一形状——⭐ 他做了，却不知道自己在做 |
| ⭐ **那第九只从来没在单子上**（单子上是八只） | 与 Ch19 那张 No.214 订单「八只」严格对齐；⭐ 而且「多出来的」正是他理解一切好事的方式 |

## ⚠️ 守住的铁律

- 他的对白全程「您」（⚠️ 这一篇在锁开之前，第②把锁满负荷）；她对他「你」。
- 他一次也没叫她的名字，连心里都没有；「小姐」说了三次（与 Ch1 对齐）。
- 那句「回头我给您上一点，不算钱」——⚠️ **必须写「我说完就忘了」**，否则 Ch2 那颗钉就废了。
  ⭐ 顺带给了他的商业逻辑：「一罐油我能上二十家，二十家里有三家再叫我，这一罐油就赚了。」
- 不预支后文：没有 Franco（只说「那个我没有说」）、没有排练／公爵、没有第三级台阶
  （那是十七岁修地板时才发现的）。

## 校验

- `check_desino.py` → exit 0（WARN 全是「小姐」＝ Signorina，人工放行）。
- `check_honorifics.py` → exit 0。
  ⚠️ **为这一篇给脚本加了两条**：
  ① `first_person_him_files: ["his-pov", "他视角"]`——他视角的第一人称篇目里叙述出现「我」是对的，
     跳过「叙述第一人称」那一组，并按「我说／她说」认说话人；
  ② ⚠️ **把 `lock2_open_files` 从模糊的 `["extra","番外"]` 改成逐篇点名 `["extra1","extra-i-love-you"]`**
     ——番外完全可以发生在锁开**之前**（这一篇就是），那种篇目里他的「你」仍然是错的。
- 弯引号 ✓；全角标点 ✓；多行收束行尾两空格 ✓。
- ⚠️ 对白处理：他视角里大部分对话用**间接引语**（「我说多谢您」这种），只有最要紧的几句
  落成真的对白（「它不是坏了，它是老了」／「我在听」／「你叫什么名字」／「我叫 Winter」）。
  ⭐ 这样它读起来是**回忆**，不是把 Ch1 又演一遍。
