# 番外八《我以为她睡着了》· 笔记

＝ **Ch22 结局那一夜的 B 面**，只写一段：她半夜醒来看见他背对着她坐在床边的**那很久**，
到他转过身说出「我爱你，Winter」，再到第二天早上他差点说回「您」。
Winter 2026-10-26 在岔路里点的（选项 A「床边那很久」），同一次她把那片簧片定成
**「一辈子不说」**（见圣经 PINNED）。

⚠️⚠️ **这是全系列第②把锁（`Lei`→`tu`，您→你）真正被打开的那一篇**，所以：
- 他全篇叙述、全篇对白都是「您」「小姐」，**只有最后那一句是「你」**；
- 第二天早上那一句「您——」咬住、换成「……你头发上全是水」是 Ch22 的原话，照搬；
- `tools/check_honorifics.py` 的 `lock2_open_files` 已加 `extra10` / `i-thought-she-was-asleep`，
  否则校验会把他说的「你」判成错。

## ⭐⭐⭐ 这一篇的机关：他说给一个睡着的人听

Ch22 她那一边写的是：「他转过身来，一只手撑在床上，低下头看她——他看了很久，看得那么久，
**你都要以为他是在等你重新睡过去**。」

他那一边的真相就是这句字面意思：**他是在等她睡实。**

> 她睡着了。她睡得很匀，我数过的。那我就说给睡着的人听。……
> 睡着的人不用答。我说完了她什么也没听见，这件事就跟没有过一样。
> **她睡着也算。**

⭐⭐⭐⭐ 这一下把全系列的「留后路」收了尾：
- extra7（那封信）：「说出来的话是要人接的……写下来的不用。她看完了可以把它烧掉。」
- extra6（车上那个吻）：「没说出口的就不算数。我连那一下都给自己留了后路。」
- 这一篇：说给睡着的人听 → **「我这辈子每一次都留。那是最后一次——她没让我留。」**
📌 而她那一边一声没出地听完、然后把他拉下去，正是「她没让我留」这句的全部内容。

## ⭐⭐ 他为什么不敢（不是自卑，是一笔他不敢开的账）

> 只要她还是小姐，这件事就还是真的。……没道理的事可以是真的。
> 要是我改了那个字，这件事就变成另外一桩了。就变成：我这个人配得上她。
> **那个我不信。**
> 我宁可它是一桩没道理的事，也不要它是一桩我配得上的事——因为我要是说我配得上，
> 那就是我自己说的，说错了就得由我来还。

⚠️ 这是 Ch22 那句「我一改那个字，我怕那些都是假的」的**内在逻辑**，别写成一般的自卑。
配一个很他的物证：镇上那年「井里头出了鱼」——没道理的事他见过，所以他宁可这是那一种。

## 回收与串线

| 东西 | 怎么用的 |
|---|---|
| ⭐⭐⭐ **那一排樱桃核** | 他在床边才想到后头那一层：**他是转过身去摆的**（怕人看见一个干活的人手心里攒的脏东西）→ 而她那时候在看，她把最末尾那一颗拿走了 |
| ⭐⭐⭐⭐ **「别转过去」** | 由此推到全篇的顶：**「我这辈子转过身去藏起来的东西，她一样一样，全都拿了。」**（核 · 信上划掉的地方 · 那一夜他要去拿衬衫擦的手腕 · 磨低的那片铜）→ **「我不是要把它给她。她早就拿了。我现在要做的只有一样：把手打开。」** |
| ⭐⭐ **磨过头那片铜**（番外七） | 「有些活干了就回不去」——他一辈子只干过一回不能回头的活，所以他知道拆掉那个字是哪一种活 |
| ⭐⭐ **在土地上练名字**（番外六） | 同一套办法：他在黑里**把那一句做了很多遍口型，没有出声**。⭐ 落差：「它没有变容易。我这辈子练过的东西都是越练越顺的。只有这一句不是。」 |
| ⭐⭐ **她睡着时手在被子上弹**（番外七） | 这一夜他改成**听她喘气**、数了很多下（「我这辈子的活就是听这个」）→ 接到系列母题 **「有气它就响」** |
| ⭐ 「我一辈子看东西都是看哪儿要坏」（番外五） | 原样再用一次：「看她的时候我看不出来她哪儿会坏。」 |
| ⭐⭐⭐ Ch22 那块**起坏的皮子钉在墙上** | 这一篇给它**第一人称的归属**（那本来就是他对徒弟说的话）：那个「小姐」是他故意留的——「那是我从后门进去的那五年……我不要它像没发生过一样。所以那个字我钉在墙上了。」 |
| ⭐ 「那个字我做了五年」 | 把敬称写成**一件天天上手的活**：「不是做一回就完了，是天天擦、天天看着它别锈。那是我这辈子做得最久的一件活。」 |

## ⭐⭐⭐ 落点：难的不是那一夜，是第二天早上

> 夜里那一句是豁出去的。豁出去只要一下——人这一辈子总能豁出去一下，哪怕是我这样的人。
> 早上那一句不是。早上那一句得我天天说。
> **天天说的东西才是活。**

→ 再接一个很准的身体细节：「‘你’这个字我说一回要在心里垫一下，像一级不平的台阶，
走到那儿要抬一抬脚。垫了很多年。到后来才不用垫了。」
（⭐ 和第三级台阶那条线同形，但不点破。）

## 守住的

- 第一人称「我」；她全篇只有「她」「小姐」；**她的名字只出现一次**，就是他说出来的那一句。
- 他「您」到最后一句才换「你」；第二天早上**又差点说回去**，所以锁不是一夜就开完的。
- 不重述 Ch22 已有的山上那一段（核的来历由她在正篇里说过），只写他**事后**才想到的那一层。
- 没有数汉字（「那个字」「一个字」指的是 `Lei`/`tu`，单词，Ch22 原文就这么写）；
  没有中式名物与度量；`check_desino.py` 只剩正篇一直在用的「小姐」WARN，`check_honorifics.py` 全绿。
