# Ch16《从缝上开的还能补》· 写作笔记

## ⚠️⚠️ 2026-09-16 改版记录（Winter 驳回了初稿的后半，必读）

她的两条意见，两条都对，后半整段重写：

**① 「他有点太克制了，这不是他。」**
原话：「他是个努力扛生活的少年，拼命保护他做梦都没想过自己能拥有的东西，他面对我为了和他一起
受的苦**会道歉、会心疼，会一遍遍地说小姐我拿什么还你**，我说**你在就够了**，然后我们搂在一起
无比亲近。**他不会闪躲逃避，我也不会。**」「总之就是**心疼和怜惜不通过逃避而是通过更深的亲密
和陪伴来体现**。」
→ ⚠️ 作废的初稿写法：他看她的手时「一个字都没有」；她**三个晚上不肯把手给他**；
她**在河边一个人哭**、屋里把脸转向墙、「他没有问，后来一次都没问过」、「你恨这一样」。
→ ✅ 改成：他的拇指在弹琴时摸到那道口子（**她没有躲**）→ 他点灯 → **话稠得停不下来**
（碱、井水、都是我的错）→ **「小姐，我拿什么还您」说了一整夜** → 她摸他的脸 →
**「你在就够了」** → 他把脸埋进她手心里哭、一边哭一边说话 → 她把他搂过来。
⭐ 并明写定调：「**他不会躲。他做不到躲。他难受的时候只会离你更近。你也不躲他。**」
⭐ 她哭那一场也翻过来了：**他推门进来她没来得及收，而这一次她没有说「是烟」**，她直说
「我想我的琴」——⚠️ 这是 Ch15 那颗种子正确的收法。
📌 已把这条写成**全系列通用铁律**，记进圣经「他」那一节。

**② 「手不能坏到弹不了琴，那就和教人弹琴为生矛盾了。」**
原话：「既然我是一直弹琴的，**我会比较在意自己的手**，天冷没办法避免，但也不至于冻得琴都弹不了
还得藏起来……我感觉就是**裂了个口子之类的**，他就会很心疼了。」
→ ⚠️ 作废：右手三处左手两处、指节肿到够不着八度、**藏手不让 Vannucci 太太看见**、
怕丢了这份活、血滴在白键上、「一辈子留一条白线」、结尾「两只手都硬了」。
→ ✅ 改成：**她比谁都当心这双手**（Borghi 先生的规矩、母亲那瓶杏仁油、左手拎提梁、
木板搓衣、少用碱、布条缠指根）——**护得很仔细，还是裂了两道**（虎口＋右手中指头上），
「**不至于弹不了。远远不至于。**」⭐ 落点改成一句判词：
**「一双弹琴的手上有一道口子，不是伤，是一句话：这只手现在还干别的活。」**
→ ✅ 「太太会不会看见」也翻过来了：**太太看见了，什么也没问，下一课客厅生了火**
（⭐ 回收他那句「叫她生个火」）；⭐⭐ 并且「Emilia，把凳子给**先生**擦一擦」。
→ ✅ 过道那一场也翻过来了：初稿她**从前门走了**（＝逃避），改成 **她走进灶房那六步**
——「你在你自己家里，从来没有走过这六步」，⭐ 因为在这个镇子上他们不用假装。

⚠️ Winter 2026-09-15 的原话：「**写细节！🥺不过得先写我教人弹琴，然后手开裂之类的……并在一章**」
→ 所以**原框架表里 16《她的手》/ 17《我教琴》两章合并成这一章，而且顺序倒过来**：
**先教琴（前半），再开裂（后半）**。框架表已改。

## ⭐⭐⭐ 全章的结构脊梁（这一条是这章能成立的原因）

**她那双手先替她说了话，后来又替她说了第二句话。**

- 前半：Vannucci 太太看了三秒她的手——**指甲修着、没有茧、指节圆而白**——
  一个每天洗衣打水的女人不会有这样一双手。⭐ **她的出身第一次变成一门可以卖的手艺**，
  而**替她开口的是她的手**，不是她的话。
- 后半：同一双手上裂了两道口子。⚠️ **不是「手废了」**（那版作废，见上方改版记录），
  ⭐ 而是一句判词：**「一双弹琴的手上有一道口子，不是伤，是一句话：这只手现在还干别的活。」**
- ⭐⭐ 两头都由**别人看她的手**来完成：太太第一次看她的手 → 给了她这份活；
  太太第二次看她的手（那道口子）→ **什么也没问，把客厅的火生了**。

所以这一章不是「教琴」＋「手裂」两件事，是**一件事的两头**。

## 前半 · 教琴（细节清单，别删）

- ⭐ 开头先立她一个人的白天：会生火（他教的那套）、会打水（绳子磨细、要往身上侧一下）、
  会烙面包（第一炉硬、第二炉忘盐、第三炉他说了六遍好吃）。
- ⭐⭐ **她会绣花，不会补袜子**（十年花／一个鼓包 → 他自己拆了重缝，针脚小得像牙，
  「皮子上的针脚得这么走，不然坐着就顶脚」）。⚠️ 这是全章最省字的一处阶级刻痕，别改。
- ⭐⭐⭐ **由头是一个错音**：主街上那扇窗，一条五指练习曲，第三小节上头那个音该升没升，
  弹了四遍都不升，**没有人纠正她**——「那一屋子人里没有一个听得出来。而你听得出来。
  你身上剩下的东西不多了。这是其中一样。」
- ⭐ 她去敲门穿的是**那一夜的那件衣服**（Ch13 私奔时穿的那件），用烧热的砖当熨斗，
  膝盖那块颜色深的（Ch12 翻窗磕的）藏在褶子里。
- ⭐⭐⭐ **「您就是修风箱那个的太太。」**「你说是。你没有纠正她。」
  → **「那一伙人喊他的姓。镇上人喊他的活计。而现在有人用他的活计喊你。」**
  ⚠️ 这是称呼铁律那张表的**反面兑现**：她嫁进了一个也没有名字的位置。
- ⭐⭐ 面试她弹的**正是刚才听见的那条练习曲**（证明她是从街上听会的、能读谱、够级别），
  ⚠️ **她没有弹自己的东西**——「差一点滑进另一样东西里去了……你收住了」。
  📌 这是刻意的：**她自己的曲子留给「第一次弹出声给他听」那一章**，别提前花掉。
- ⭐⭐⭐ **「你这辈子第一次为了钱弹琴。他不在场。」**＋「那两个钟头他在半条街外头
  一家人家的灶跟前，蹲着。」→ Winter 要的「她一天摸得到琴，却不能弹给他听」。
- ⭐ 她还顺口报了琴的毛病（中央那一区偏低、踏板底下松了）——⚠️ 行家不是靠说自己是行家。
- ⭐ **Vannucci 太太只往那边问了一句**（「您从前跟谁学的」）就不问了。
  ⭐ 「这个镇子上没有人问……不是因为他们不好奇，是因为问了就得管。」
  （与 Baldi「什么也没问」、Nannina「什么都不问」同一条线，这是本系列好人们的形状。）

### ⭐⭐⭐ 两排铜子（Ch15 的正面对照）

Ch15 他把头一笔**三个铜子摆成一排**说「这是第一笔」。这一章**她把两个铜子摆成一排**。
- 他的反应严格照声口：帽子掉了 → **一连串问题**（哪一家、哪个太太、一课多久、
  礼拜几、我送您去、我去接您）→ 她叫他名字他才停 → **「您不用做这个。」**
  → **「我明天多跑一家。」**（⭐ 她挣钱＝他必须挣更多，这是他的羞耻发动机）
- ⭐ 她把两个推到他那三个后头：**一排五个**。他看了很久，说 **「……那还差得远。」**
  ⭐⭐ 落点：「只有一样东西他从来不敢往账上记。**而现在他在记那一样了，
  而且他知道自己一辈子也补不齐。**」（母题 7 最狠的一次）

### ⭐⭐ 栗子（母题 8「看他吃东西」，本章的定点节目）

第二个礼拜的四个铜子她**没有拿回家**，全买了烤栗子。
- ⭐⭐⭐ 他说「这个贵」，她说 **「不算钱。」**——**他自己的话第一次被还给他**
  （Ch1 那句「那个不算钱」的总回收）。他认出来了，然后他笑了。
- ⭐ 吃相照圣经写足：烫得两手颠、嚼得响、腮鼓着、嘴里含着东西还要说话、
  赶紧拿手挡着咽下去道一声对不住；⭐ **壳一个挨一个摆在桌沿，裂口全朝一边，
  还嫌不齐又推了推**（＝樱桃核那个毛病，同一个人）。
- 「你什么也没说。你从十六岁那年起就没有说破过这件事。」

### ⭐⭐⭐ 埋钉：教堂里那个**底下就是个风箱**（本章最要紧的一处伏笔）

他问「琴是靠什么响的」→ 弦、木榔头、不吹气 → **「那我帮不上。」**（手在裤子上擦一下）
→ 隔了一会儿他自己又说：**「教堂里头那个能吹气。那个我懂。那玩意儿底下就是个风箱，
两块板，中间是皮子和布，脚一踩它就鼓。」** ⭐ 上回镇上那个坏了半年没人管，
他差点进去说他会，**「后来我没进去。我那会儿没有工具。」**
→ 「**你当时没往心里去。**」

⚠️⚠️ **这就是「第一次弹出声给他听」那一章的答案**：她能有的第一件乐器**不是钢琴，
是簧风琴（armonium）——一件靠风箱响的乐器**。
⭐⭐⭐ **修风箱的人把弹琴的人的琴还给她。** 整个系列的题眼在这里合上。
（考据：簧风琴 19 世纪末在意大利的教堂／人家极常见，最容易坏、也最该修的正是底下
那两片皮子布做的风箱。他这门手艺**刚好**能修它。）

### 教琴的实操细节（Winter 要的「细节」落在这里）

- Emilia Vannucci，九岁，不喜欢弹琴，开门时两只手都是墨。
- 第一课什么曲子也没弹：**剪指甲**（剪到摸得着肉）、**手心里搁一个鸡蛋**、
  一个指头按下去别的三个不许掉 → 按了一百多下，第四十下开始不高兴，第七十下眼睛红了，
  歇了一会儿自己坐回去。⭐ 收在「下次还按吗」「还按」「那你下次还来吗」「来」。
- ⭐⭐ **她自己先生的话从她嘴里出来了**：Borghi 先生（城里来的，一个礼拜两趟，
  用铅笔敲手背，敲得不重）——「别用力，用你手臂的重量」「数出声，不数出声你就会赶」
  「慢的弹不好，快的就全是假的」。⭐ 她有一次差点说出「Borghi 先生从前跟我说」，
  咽回去了：**那扇门后头那间有火的屋子还在，只是她不能提它。**
- ⭐ Emilia 把那条练习曲弹对了（那个音升着）→ 她哭了一场 →
  ⭐ **「你坐在她旁边等她哭完。你没有问她哭什么。」**（⭐ 对一个孩子的体贴；
  ⚠️ 别把这种「不问」用到他和她之间——见上方改版记录①）
- ⭐ 她示范只弹两三小节就收手；有一回屋里剩她一个人，她弹了**四小节**就停了。

## 后半 · 手（改版后的细节清单）

⚠️ 顺序：**她怎么护手 → 还是裂了两道 → 他弹琴时摸到 → 点灯 → 我拿什么还您／你在就够了 →
每夜抹油成定例 → 手套戴在她手上 → 她哭他在 → 客厅生了火 → 那六步**。

### 她护手（Winter：「我会比较在意自己的手」）

- ⭐ 从五岁起就当心：**Borghi 先生**不许指甲剪秃也不许留长、不许提重东西、夏天不许晒；
  ⭐ **母亲从前替她收着一瓶杏仁油**，冬天睡前抹。「这些事现在没有人管了，可你自己管。」
- 具体怎么护（细节都在这儿）：**打水用左手拎提梁**（右手要弹八度，虎口不能压坏）、
  洗衣**拿一小块木板搓**不用手抠领口、**少用碱**宁可多搓两遍、柴**抱在袖子上**、
  布条剪成细条收在窗台上、出门前**缠在指根**。
- ⚠️ **裂的只有两道**：右手**虎口**一道横的（细，不流血，一伸手牵着疼）＋ 右手**中指头肚**
  一道更小的（碰到硬东西才知道它在）。⭐ **「不至于弹不了。远远不至于。」**
  她照旧上课、照旧示范。**「只是你知道它在那儿。」**

### ⭐⭐⭐ 他怎么发现的（⚠️ 改版：她没有躲）

- 那一夜她**照旧**把手放上他摊开的掌心弹（Ch14 起每夜最后一件事，⭐ 他从来不说「弹」，
  就是把手摊开）→ ⭐⭐⭐ **弹到第二段，他的拇指从她手背上过去，摸到虎口那儿，停住了。**
- ⭐ **他去点灯**（⚠️ 反转：他从来不肯**吹**那盏灯，这一次他**点**它）→ 托到光底下 →
  「这是什么时候的」「前几天」「哪几天」「中旬」→ **「您怎么不跟我说，小姐。」**
  「这个不值得说」「不值得——**这是您的手**。」
- ⭐⭐ **然后他话稠得停不下来**（⚠️ 这一段是改版的核心：他的难受走「说得更多」，不走沉默）：
  碱最吃皮、他师傅当年拿碱洗坏过一张羊皮、井水把油都带走了、**他天天摸皮子皮子干了
  他一眼就看出来，怎么会没看见您的手**、**「这个都是我的错」**、「您不该干这些的」→
  ⭐⭐⭐ **「您那双手，全镇上就我一个人知道它们是干什么的——它们弹给我听过一百多回了。」**
  （⚠️ 这一句只有在「每夜在他手心里弹」这条线上才成立，是全章最贵的一句）
- ⭐ 抹羊油（他修皮子那一罐，掺了蜡）：灯上烘热 → 自己手心搓开 → 一个指头一个指头往上推 →
  **碰到口子就绕开，先把周围抹软，再从两边往中间赶**。
  一边抹一边讲皮子：「不是用得多才开的，**是没人管才开的**」→
  ⭐⭐⭐ **「从缝上开的还能补，从中间开的就不行了。」**
  ⚠️ **这是 Ch15 结尾说那只旧风箱的原话**，在这里落到她手上；⭐ 他说完**自己听见了，停住** →
  「……对不住」「你说什么对不住」「**我不知道。我什么都对不住。**」

### ⭐⭐⭐ 本章心脏：「我拿什么还您」／「你在就够了」

Winter 亲口要的一段，照她的话写：
- ⭐ **她先摸他的脸**（Ch14 定的方向），他往她手心里靠了一下。
- ⭐⭐⭐ **「小姐，我拿什么还您。」**（⚠️ 守第②把锁写「您」——Winter 口述是「你」，
  同 Ch15「我把您弄脏了」的处理）→ 他一遍遍说，还把账算出来：
  「您跟我走的时候什么都没带……我一天挣三个铜子。**我连一双手都没保住。**」
- ⭐⭐⭐ **「你在就够了。我不要别的。我什么都不要。你在。」**
- ⭐⭐ 他把整张脸埋进她手心里哭，**一边哭一边还在说话**（他一直是这样，眼泪和话一起往外跑）：
  十六岁那年推第一趟车只想着把八只修完拿钱回去／**做梦都没想过会有一天他睡在您旁边**／
  没有一样东西是配得上的／**一辈子都还不完**。
- ⭐ **她把他搂过来，那盏灯没有吹。** 每说一句「对不住」她就搂紧一点。
- ⭐⭐⭐ **定调（全系列通用，已进圣经铁律）**：
  **「他不会躲。他做不到躲。他难受的时候只会离你更近，一句话说不明白就说十句，
  说不出来就把脸埋到你手心里来。你也不躲他。这个屋子这么小，本来就没有地方躲。」**

### 往后的日子（＝「更深的亲密和陪伴」怎么落地）

- ⭐ **抹手从此成了每天最后一件事，排在弹琴前头**：先把她的手握热（冷的抹不进去）、
  一个指头推三遍虎口五遍、用针尖挑最细的木刺。⭐ 抢活：「明天别去河边」「我洗」
  「天黑洗有什么了不得的，我又不用看，**我摸得出来哪儿脏**」；两桶水是他早上打的。
- ⭐⭐ **那罐油见底他就添**，不是修皮子的量；⭐ **她翻过他外套那个小口袋（他每天把挣的搁在
  那儿），里头是空的。**
- ⭐ 抹完他把左手摊开：**「弹。」**——⭐⭐ 他现在会说这个字了。
- ⭐⭐⭐ **手套**：她在集市买的（厚的那双＝她两个礼拜的课，她挑了薄的）；他不要，
  理由是行家话（「戴上我什么都摸不出来，那我就不知道哪儿薄了」），⭐ 把手伸给她摸
  「这个比那羊皮还厚。它不裂。它早不会裂了」——**说的时候有一点得意**。
  ⭐⭐⭐ **那双手套他一天也没戴过，它们在他外套口袋里**：礼拜二礼拜五四点，
  他在 Vannucci 家门口那棵树底下等她，**半跪下去把手套一只一只给她套上**，
  还把袖口捋下来盖住手腕；「我不冷」「您冷」；他自己两手插口袋走一路。
  ⭐ **「你从来没有赢过这件事。」**

### ⭐⭐⭐ 她哭那一场（⚠️ 整段翻过来了）
