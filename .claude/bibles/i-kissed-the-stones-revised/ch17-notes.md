# Ch17《您弹您的，气我来》· 写作笔记

⭐⭐⭐ **全系列最大那颗钉在这一章收**：Ch10「您弹」→ Ch11「以后你要弹给他听，就只能弹在
他手心里」→ Ch14 货车上她在他手心里弹到天亮 → **这一章她弹出声了**。
⚠️ 圣经的硬要求：**要写成「她一辈子最贵的代价终于有了回报」，不是简单的甜。**

## ⭐⭐⭐ 这一章的发明（Winter 选了岔路①A「在教堂弹」之后长出来的）

**那台琴要靠人给气。**

- 教堂那台是给小教堂做的**大号簧风琴**：两片脚踏板（自己踩，短曲子够用），
  ⭐ **边上另有一根木杠杆——曲子长的时候脚跟不上气，得有人在旁边压。**
  从前有人管压，现在没有了；杠杆头上那个皮碗子干成了硬片，一压就漏。
- ⭐⭐⭐ **于是：她弹，他给气。** 她这辈子最好的一样东西，响起来靠的是他的一只手。
  **「修风箱的人把弹琴的人的琴还给她」这句话在这一章不是比喻，是字面。**
- ⭐⭐⭐ **本章的台词心脏（也是章名）**：**「您弹您的，气我来。」**
- ⭐⭐⭐ **乐器学的那一刀（本章的思想）**：
  **「钢琴按下去，那个音就开始死……这台不是。这台你按住不放，它就一直响。」**
  「有气它就响。」→ 落点：**「它站得住，是因为有人在给它气。」**
  （考据：簧风琴／风琴的音只要供风就不衰减，钢琴的音一击即衰——这是真的物理差别，
  不是修辞。整章的情感就架在这一条上。）
- ⭐⭐ **节奏的反转**：Ch15 他教她压风箱生火（「它亮一下你压一下，它暗下去你就等一等」）；
  这一章**她教他压杠杆**（长音压得匀、重处压得深、她抬手换气他就停下来等）。
  ⭐ 他的回答是把那句原话背了回来：「它亮一下我压一下。它暗下去我就等一等。」
  「那是我教您的。」「**现在我教你。**」

## ⭐⭐ 他去求人（开场）

- ⭐ 他忍了两天，第三天自己说了（⚠️ 照「他不会躲、藏不住东西」的铁律，**不许写成瞒着她
  做惊喜**）。他一进门就把活儿报了一遍：哪儿开了、哪儿朽了、几天能好、料钱多少
  ——「他这辈子跟人说话都是这么开头的。他会算，他能报出准数，**那是他唯一拿得出手的东西**。」
- ⭐⭐⭐ **章首题词那三行的兑现**：他这辈子没替自己求过人。
  他跟神父报完价，说了第二句话：**「神父，这个镇子上有一个人会弹这台琴。」**
  「我说她弹得很好。我说她不是随便会弹，**她是真会**。」
  → 「你怎么知道我弹得好。」→ 愣了一下 → **「我听过。」**
  ⚠️ 这是全章最省力也最狠的一处：⭐ **他头一次开口求人，求的是给她一个位置。**
- ⭐ 修那六天的手艺细节（母题 6／7）：薄刀顺着钉孔撬、旧皮子摊在长凳上把三道缝比给她看、
  ⭐ **「它不是被谁弄破的。它是自己干开的。这东西一年不动，比天天用还坏得快」**
  「动的时候它自己出油。**人也一样。**」；⭐ **新皮子裁的时候多留两指宽**
  （「折缝那儿要吃劲……留宽点，它折得动」）；熬胶；换杠杆上那个皮碗子，钉完拿手背贴着试，
  又拆了两颗重钉。⭐ 第六天夜里他把耳朵贴在木架上听了很久才说 **「不漏。」**（声音是哑的）

## ⭐⭐⭐ 神父那一问（＝本系列「阻碍永远是好人在做对的事」的最高形态）

- 神父 **Don Pietro**（五十上下，个子矮，走路一只脚有点沉）问了**这个镇子上第一个
  问她事情的人**该问的那句话：**「您二位结婚了吗。」**
- ⚠️ 口径必须立住：Baldi 不问、Baldi 太太不问、Vannucci 太太看见她的手也不问
  ——「你到这个下午才明白那是因为**他们不必问**……⭐ **神父必须问。他要把一台琴、一个位置、
  一个礼拜天早上站在这个屋子里替他弹琴的人交到一个人手上。他不问，他就不配站在这儿。**」
- ⭐⭐⭐ **他站到她前头去了**（⚠️ 照新铁律：他不躲、他护着）→「没有。」「为什么现在不行。」
  → ⭐ 他不说——**不是不敢，是在算**（她在他侧后头看见他耳根的红往下走、两只手攥了又松）：
  他在算说出来这屋里的人会怎么看她、这台琴还给不给她弹。**他算不明白，所以他不说。**
- ⭐⭐ **于是她从他后头走出来自己说**（她也不躲）：**「三年。到我二十一岁，我可以自己作主。
  在那之前，我要我父亲同意。我父亲不会同意。」**
  📌 ⭐ 圣经里那条「未满 21 须父亲同意」的法律在这里第一次被**说出口**，
  ⚠️ 而且是她自己算给一个陌生人听——它从此是**一口钟**，不是一把刀。
- ⭐⭐⭐ **神父给的不是恩典，是一个技术性的口子**：
  **「那这台琴，谁来试。」「修好了的东西要试……总得有个懂的人坐下来试一遍。
  这是他的活的一部分。」「试吧。试到您满意为止。」** 然后他从边门出去，把门带上。
  ⭐ 一个必须守规矩的人，用「验活」两个字给了他们一个下午。⚠️ 别把他写成通达的好人，
  他是**照规矩办事的人在规矩里找出的那一条缝**（⭐ 母题 3：缝）。

## ⭐⭐⭐ 那一段（本章正心）

- ⭐ 她弹的**就是 Ch16 里收住没弹的那一段**——十四岁那年整整一个冬天在那间有火的屋子里
  弹了几百遍的、属于她自己的那一段。⚠️ **这就是那颗钉的钉头，前面十六章一直压着没花。**
- ⭐ 写实的身体反应：两年半没摸过属于自己的琴 → **手抖得第一个和弦按不下去** →
  他说 **「您慢慢来。气足着呢。」** → ⭐⭐ **前四小节是她这辈子弹得最糟的四小节，
  她弹错了三个音**（「你这辈子没有在一段曲子里弹错过三个音」）→ 然后手自己走了。
- ⭐ 曲子的具体样子（不给作曲家名字，只给手感）：慢的；右手一条线一直唱、唱到高处不肯断；
  左手四个音一组托着；⭐ 中间有一处要撑开够一个很宽的音，**她十四岁够不着，是整个人往那边
  倾过去够的**——⭐⭐ 那天她又倾了一次（因为紧张），**肩膀碰到了他的胳膊，他的胳膊没有停**。
- ⭐⭐⭐ 「到长的那一段，你抬起右手，在空里停了一下——**他也停了一下。停在同一个地方。
  一点也不差。**」
- ⭐ 收：最后那个音她按着不放、他压着不停 →「你把手抬起来它才停」→ ⭐ **石头把它送回来**
  （母题 3 ＋ 系列名的暗照：这一次石头不是隔开他们的东西，是把声音还给她的东西）。
- ⭐⭐⭐ **他的反应必须先说错话**（声口铁律：他不会抒情，他只会讲活儿）：
  **「它不漏了。」「它一点都不漏了。我刚才听着呢，一整段我都在听，它一下都没有漏。」**
  然后才崩：擦脸擦得又快又粗、把炭灰抹到眼睛底下 → **「我不知道是这样的。」**
  → ⭐⭐ 「我以前听过您弹。在您家院子里、在窗底下、在走廊上——**可那都是隔着东西听的。
  隔着一层楼，隔着一堵墙，隔着一扇关着的门。**」→ ⭐⭐⭐ 抬起自己的手心：**「还有在这儿。
  您在我手心里弹了两年多……我不知道它出来是这个样子的。」**
  → **「小姐，我这辈子第一回听见您的琴。」**

## ⭐⭐⭐ 「我拿什么还您」这句话的收法（PINNED 兑现，别改）

正文用一小节明写，⚠️ 但**不是他宣布还清了**：

> 他没有说那句话。那句「我拿什么还您」，他从这个下午起，再也没有说过一次。
> ……不是因为他觉得还清了。他记账记了一辈子，他心里那笔账他到死都算不平。
> **是因为他终于有一样东西，是他给出去的。**
> 不是一趟白干的活，不是三个铜子，不是天黑了替你去河边洗衣服，不是那双他一天没戴过的
> 手套——**那些都是替你挡的**，挡的是你为了他才要受的苦。
> **这一样不是挡。这一样是给。**

⭐ 然后才接 Ch11 那句的正面回收：「你这辈子最会的一样东西……后来你只能弹在他手心里。
**现在它响了**……而它靠的是他的气。」

## 收尾（＝Ch18 的地基）

- ⭐ **待遇**（Winter 要的「在教堂弹待遇也会好一些」）：神父给的数目**＝她一个月教八课的钱**；
  礼拜天大弥撒＋礼拜三礼拜五两回小的，三月起加礼拜六下午孩子们的唱经。
  ⭐⭐ **学生从一个变成五个**，⚠️ 不是神父介绍的，是**礼拜天早上坐在底下的人听见了**；
  Vannucci 太太头一个替她说话。⭐ 镇上人开始隔着半条街喊她「先生」（Ch16 那颗钉长大了）。
- ⭐⭐ **还钱那一幕**（Ch14/Ch15 埋的）：那包凑份子的钱第一次拿出来数，他一笔一笔念名字
  （「Snug 三个」「Snout 五个」「Quince 那个是他自己塞进来的，他不肯说数，我看着像十个」→
  **「那就还十二个」**）；他写信写了两个晚上，⭐ 信里有一句 **「我现在什么工具都有了」**
  （Ch16 末那句的回声）。
- ⭐⭐⭐ **Ch6 那颗钉的正面回收（压了十一章）**：
  一百多支蜡烛那一夜他在台上抬脸找她、台下是暗的、**他没有找到**。
  → 这一章：**「这一次你在上头，他在你手边。你低头看他。他正仰着脸看你。」**

## ⚠️⚠️ 这一章之后仍然压着的东西（别提前花掉）

- ⭐⭐⭐ **第②把锁（`Lei`→`tu`，您→你）**：他这一章照旧一个「你」都没有（已 grep 核过）。
  留给结局。
- ⭐ **她还没有弹给「他们」听过**——Ch18 家里人会在她弹琴的时候找到她。
  ⚠️ **因果要写清楚**：让她终于能弹出声的这个位置，正是暴露她的那个位置
  （教堂的琴手是有名有姓、每个礼拜天站在同一个地方的人）。
- ⭐ 神父 Don Pietro **只问过一次，再也没有问第二次** → ⚠️ Ch18/19 家里人来了以后，
  他这个人物还有用：⭐ **一个必须守规矩、却替他们找过一条缝的人**，
  到了「结婚要父亲同意」这件事上，他是唯一站在教会那一边又站在他们这一边的人。
