**这一章做了什么**：戈尔韦晴了一个下午，克拉达河口的旧码头和天鹅 → 他讲 Richard Joyce 的传说（十七世纪被海盗劫到阿尔及尔、跟金匠学打金、金匠许他一半家产和独生女他不留、回来打了第一枚）；“给谁？”“看你信哪个版本……”“你信哪个？”**“我信她在等。”**——然后笑着挡：“不然这戒指卖不出去。” → 往西，石头墙、羊、山、海；一栋孤零零的石头房子，泥炭壁炉；“没有信号，也没有 Hollis。”“那有什么？”“海。还有我。” → 住了一个礼拜，在那里日子没有名字；海边捡磨圆的蓝玻璃“像那只杯子”；他难得闲着，像把这一个礼拜从世界上剪下来 → 大风暴，停电，蜡烛，老唱片机里一段酒馆小提琴 → **“那天晚上，你在布鲁克林是怎么跳的？跳给我看。”** → 你光脚在石头地板上跳，笑出声；他没笑，眼睛里像饿又像怕 → “过来。”跨坐，“再笑一次”；**“今晚你来。”**——第一次让你在上面；“动，你想怎么动就怎么动”；“大声点……这儿除了海，什么人都没有，你想多大声都行” → 你以为这回你说了算，可他扣在你胯上的手一直在替你调节奏（快了按住、要到了提起来）——**你在他手里放开，在他手里疯** → “现在。”你第一次感觉到他在发抖 → 事后：“那天在布鲁克林你在笑什么？”“什么都笑。”**“以后，笑给我看。”**（你觉得是最温柔的一句）→ 离开那天手机憋了十几条：Margot 礼拜三“我到了 / 你到哪儿了 / Winter？……我先试了，店员问我伴娘呢 / 算了。” → 他停车：“是我不好，我光顾着你，把日子给忘了。”你说不怪他 → 电话没人接，消息只发出去一句“对不起。我真的对不起。”没有回音 → “他那么爱你。只是这一回，爱得太满了，把日子都挤掉了。”

**Winter 定的发动机落在这章**：他喜欢你自由、放开、沉溺的样子，但只准在他手里——“你来”是他下的令，节奏在他手里，自由是他给的。

**新埋的钩子**：蓝玻璃；“我信她在等”（等的人是他——接“等到天黑”）；“以后，笑给我看”；他第一次发抖；你弄丢了一个礼拜三，Margot 没回。

**查证**：克拉达在戈尔韦河口，老渔村，天鹅；Richard Joyce 传说（1675 年被劫、阿尔及尔金匠、威廉三世时获赎、回乡打第一枚戒指；为谁打有两个版本；传说本身未经证实）。
