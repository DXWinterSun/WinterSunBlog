**这一章做了什么**：紧接第一章最后一句“别动”，同一夜 → 他先解你的珍珠项链，再一齿一齿拉开墨绿丝绒的拉链，“看着” → 裙子是他挑的，背开得太低、底下什么也穿不了，他当然知道 → 镜子里你只剩高跟鞋和戒指，他从领带到袖扣一丝不乱；“别挡，我在看”，像重读一份读熟了的合同；“今晚全纽约都在看你，只有我看得到这个” → 手：码头留下的粗指腹；“出声”；手指进去，“一整晚了？”；“眼睛睁着，看着”；两次到边上被他停下，“还不行”，眼泪被他吻掉，“乖” → 他西装笔挺地跪下去，把你一只脚踝搁上脚凳，“看镜子，别看我”，用嘴把你推上去，“现在”，你碎了 → 他抽出口袋巾擦嘴、叠好放回，“还没完，love” → 你俯身撑住梳妆台，他只解开皮带和拉链，外套领带袖扣全没动，“看着我”；他额头抵你后颈，那是今晚他第一次乱 → 十指扣住你戴戒指的左手，“谁的？”“你的，Dec，你的——”“看着说” → 又一次“还不行”，然后“好了，现在”，他跟着你，那声 love 里的都柏林全回来了 → 他这才脱下西装，热毛巾替你擦干净，一杯温水看着你咽下去 → 你知道自己上瘾了，“明天晚上他再说一句别动，你还是会一动也不动” → 半夜他没醒，却替你把转歪的戒指转回朝里；床头明早那一粒已经摆好（这一段从第一章挪过来）。

**Winter 点的菜，全在**：他对着镜子把你剥开、自己西装革履（从头到尾只解了皮带和拉链，事后才脱西装）；你羞红了、他稳稳掌控；矜贵美丽的妻子在他手里只属于他（“今晚全纽约都在看你，只有我看得到这个”“那张 Whitmore 家的脸完全散了，只剩下他”）；先用手、用嘴把你拆开到不能自已，再占有；你喜欢得上瘾。

**主人级别的掌控**：命令都是他在床上的声口，几个字、不大声、不说第三遍：别动 / 看着 / 别挡 / 出声 / 站好 / 眼睛睁着 / 还不行 / 看镜子，别看我 / 现在 / 看着我 / 谁的？/ 看着说。什么时候停、什么时候哭、什么时候放你走，全归他。

**衔接**：第一章的镜子（婚后第三个月搬进来，“看你”）在这里兑现；早上你亲手扣的袖扣，他到最后都没摘；那杯温水和“看着你咽下去”在床上又来一遍；戒指在梳妆台上被他十指扣着攥歪，半夜又被他转回来。
