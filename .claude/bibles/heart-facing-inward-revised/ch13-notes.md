**这一章做了什么**：礼拜四早上照旧咽下；“今天什么安排？”“没什么安排，下午 Paolo 来修头发”（Hollis 的日程上午空着）→ 你穿上大学时的旧驼色大衣、戴那条他从不让你戴出门的灰围巾，**自己扣大衣**，扣错一个眼又全解开重扣 → 按住关机键停了很久，松开：“手机开着，他就找得到你；他找得到你，你就不算一个人走”——你在跟自己讨价还价 → 门房“要我叫车吗？”“不用，我走走。”走出十几步回头：玻璃门后面，门房拿起了电话 → 好几年没坐地铁，没有地铁卡；穿校服的男孩：“拿银行卡碰一下就行”，你碰的是 WINTER WHITMORE 那张，屏幕亮绿 GO → 六号线：走调的手风琴圣诞歌、抱橘子打瞌睡的老太太、看手机笑的高中女孩；没人认识你；车窗里一个脸色很白、围着不好看的灰围巾的女人，你看了好一会儿才认出是你 → 红头发的接待员：“Whitmore？”牛皮纸信封写着 4471，“要我给你念吗？很多人不敢自己看。”“不用。”“祝你好运，亲爱的。不管是哪一种。” → 你没回家，往东走到东河边，威廉斯堡大桥上地铁轰过、海鸥；指甲卡进封口又停住；想坏的（扔进河里、回家、等明天那一粒）、想好的（Bunny 还是离了）；两只手压着信封像压着一只会飞走的鸟 → **有人在你身后站住了**，你不用回头；那双手把被风吹松的灰围巾绕两圈、系结、掖进领口：“冷不冷。”→ 你把信封塞进口袋，不知道他看见没有 → ⭐ **他的大衣没扣**——替你扣过一千次大衣的人，自己一颗都没扣；没戴手套、手指冻红、头发乱、喘着白气 → “你怎么找到我的？”**“你手机开着。”**声音平常，搁在膝盖上那只手在抖 → 你终于想明白（路线图要的那一下）：那天手机没电、四十一个电话、“天黑了。你不在。”——你以为是脾气；杂货店老太太“等到天黑”；你自己在布鲁克林台阶上等到天黑，等的是一个会来的人——**你不知道他那时候等的，有没有哪一天没有来**；“不是生气。是怕。” → 你握住他那只手，他把两只手一起塞进他的大衣口袋；你另一只手在自己口袋里碰着信封的角 → 他一直没问你去了哪儿（“不知道这比问了更好还是更坏”）→ “这条丑。”“我喜欢。”他把结系紧了一点 → 下东区一栋红砖楼：**“我来纽约头一年住那儿。朝北。一扇窗。”**五楼、绿窗框漆掉一半——第十二扇窗；一个在下城一扇朝北的窗，一个在上城一整面朝公园的玻璃 → 车上他把你的脚搁到腿上揉（呼应第四章，第七章那晚他没这么做）→ **“从今以后，你再也不会走丢了。你不知道这是一句情话，还是一句判词。”** → 夜里没拆的信封夹进《秘密花园》同一页，挨着那张旧名字的收据，书鼓起一小块；他在梦里确认戒指朝里；你睁眼到天快亮。

**为什么这么写**
- 路线图原句：「你亲口许过‘不一个人走了’。这一回你故意违背：手机开着……不到一个小时他就出现在你身后，没有生气，只替你把围巾系好。你终于想明白，上一回那两个钟头，他为什么怕成那样。」全部照落。
- 标题从路线图的“一个人出门”改成“你手机开着”：第五章已经叫“你多久没一个人出过门了”，两个名字放一起分不开（移植测试不过）；“你手机开着”是他本章唯一一句要紧的话，记得住。
- 手机开着的理由写成她自己的讨价还价（半守承诺、半违背），不是赌气，符合恋爱脑的她。
- 他怎么找到的，给了两条线（门房的电话、手机定位），都不说破——灰色地带。
- “大衣没扣”是本章的钥匙：全系列他替你扣东西（母题 3），他自己的永远扣好；这一次他一颗都没扣，比任何独白都说明他怕成了什么样。**他本人一个字都没解释**（守“他永远不直白”）。
- “有没有哪一天没有来”——你只是隐约猜，不知道；给第二十二章（他母亲那一天没有来）留足。
- 第十二扇窗：接第三章“十一次家，每一处只有一扇窗”和第八章都柏林十一扇窗。
- 信封本章不拆：拆的那一刻留给第十四章，让她**先咽下药、再看结果**。
- 语言：地铁闸机屏上的 GO、关机提示都是屏幕上的字（实物），其余照常中文；没有数字数。
