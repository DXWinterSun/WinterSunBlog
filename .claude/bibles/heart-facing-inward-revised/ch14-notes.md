**这一章做了什么**：礼拜五早上，信封还没拆，离你不到二十步——**你先咽下去了**（“不知道这算是信他，还是算你认了；你只知道你的手没有抖”）→ 锁进浴室、开着水龙头拆信封 → c-decree 成分分析报告（No. 4471，送检人 W. Whitmore）：硫酸亚铁（含铁六十五毫克）＋维生素 C＋叶酸＋B12，刻字是厂家代码，**未检出其他药物成分** → 从浴缸边滑坐到地砖上，笑着哭，“没有。什么都没有。是你想多了。” → 补铁？书房电脑上查：累、脸白、手脚冰凉、头疼、记不住事、上楼梯要歇——每一条都对上（布鲁克林回来冰凉的手、“你今天脸色不好”、coddle 那句楼梯）→ ⭐ **“服药前后至少间隔半小时再饮用咖啡或茶”**——咖啡在厨房，过半个钟头再喝，一年了每天早上 → 你拼命想：公园大道诊所、针、护士凉的手、他的手搭在你膝盖上“好像在替你听”，你在看窗外想婚礼的花用白的还是淡粉的；**哪一天不知道，医生说了什么一个字想不起来**（守记忆规则）——“你什么都不记得。可是有人记得。” → 夜里他从西装内袋摸出**一只小银盒子**（你一直以为是他装薄荷糖的），倒出明天那一粒放在杯旁 → “那一粒到底是什么维生素？”“补铁的。你不记得了？” → **结婚前那个夏天体检，血色素八点几**，再低就得去医院打铁剂；“一天都不能断，至少吃一年，一月份复查，咖啡茶隔开半个钟头，不然白吃” → **“三天。你吃了三天，就忘了。”**第四天药瓶还在你包里没撕封，你当成你妈塞的东西 → “所以我。”从蜜月那天早上起，一天都没断过，连石头房子里也带了一整瓶塞在剃须包里 → 在那里连礼拜三都丢了，那一粒没丢；一周年早上那句“这件忘不了”原来不是漂亮话 → “你那时候多难看你自己都不知道”：嘴唇白、指甲白，婚礼那天早上你妈问他你怎么脸白成这样，他说是太紧张了；拇指摩挲你的颧骨：“现在好了。你看。有颜色了。” → 你想坦白（现金、旧名字、河边、嚼口香糖的陌生人），说不出口：“对不起。”“对不起什么？”“对不起我忘了。”——**第四个谎，每一个字都是真的，只把最要紧的那一半咽了回去** → “你要是什么都记得，还要我干什么。”“傻。这有什么好哭的。”（口音漏出来一点）→ 拔不掉的那根刺：一个怕你忘的人把药放你手里就够了，一个每天要亲眼看着你咽下去的人，怕的是另一件事 → **“那你为什么每天都要看着我咽下去？”他停了一下**（跟你说“我不走”时一样短），晚宴上那种笑：**“因为你连礼拜几都记不住，love。”** → 熄灯后他确认戒指两遍 → 你想：他在等的不是你咽下那一粒，**是一个不会再有的“没咽下去”；那个人不是你** → 收据和报告还夹在那一页，你没扔：证明你怀疑过他，也证明你错了 → 第二天早上你咽下后抬眼看他看你：那张脸上不是掌控，“是一个男孩，在等天黑以前，那个人回来。”

**为什么这么写**
- Winter 定的真相：「缺铁，他记得你忘了」＋「他母亲……他那种不安全感和占有欲的根源🥺」。前者本章全揭（数字、医嘱、三天、一年没断），后者只让她**隐约感到有一个人**，不说是谁——留给第二十二章。
- ⭐ 她**先咽下药再拆信封**：结果出来之前她已经选了他，这是恋爱脑的她自己的选择，不是被证据说服；也给结局“你看清了还是选他”打了底。
- 前两章埋的两颗（咖啡隔半个钟头、上楼梯要歇）和第一章那句“这件忘不了”在本章一起兑现，读者会回头觉得一路都是真的。
- 灰色地带没有因为药是清白的就消失：他记得她的血色素、替她听医生的话、“我记得就行了”式的“你要是什么都记得，还要我干什么”——**连她的身体和记忆都由他保管**；她今年的困是什么，不说破。
- 他仍然不直白：真心全在“你看。有颜色了”“傻”这类小话和一下停顿里；被问到要害，拿玩笑挡——守声口铁律。
- 小银盒子补了一个漏洞：药一直不在贴标签的瓶子里，而是在他的内袋里（她以为是薄荷糖），所以她一年都没法“看一眼瓶子”——也跟婚礼上他从西装内袋掏出戒指呼应。
- “他知不知道你拿去验了”本章不答（收据和报告还在书里），作为岔路给 Winter 挑。
- 语言：报告是实物，用 c-decree；“一个字都想不起来”“每一个字都是真的”属成语式用法，不是计数。
