**这一章做了什么**：一月初，门厅银盘子里一张请柬，信封写 **Winter Whitmore 小姐**（只有大学时候的人这么写）→ c-note 请柬：Lassiter 画廊冬季新展，一月十五日礼拜五；背面手写 **“你一直没回我。还是想请你来。这回别再迟到了，那是我的专利。— T.”** → 你以为是自己这一年总在忘 → Dec 扣着袖扣下楼，眼睛在 Whitmore 上停了很短一下；“去吧。我陪你。” → 画廊里他跟 Theo 握手只说“恭喜”，然后**退开**，站在展厅另一头背着手看画，不跟任何人说话——他在努力（第十五章之后）；你等那只手落到腰上，它没有，“腰上空空的” → 三人联展：海、旧工厂、一整面墙同一把旧木椅；俄亥俄姑娘有了底气要再画一百张杯子 → ⭐ Theo：当初敢挂出四十七张是因为想起你——大三研讨课有人笑莫奈画了二十几遍干草垛，你站起来吵，**“重复不是没有想法。重复是一个人，不肯放手。”** → 你一点都不记得那个站起来的姑娘，只记得这一年坐着的样子 → “你到底为什么一直不回我？”他递来手机（c-comm「Theo → Winter · 已送达」：开展那天没见你 / 四十七张全卖了我猜是谁 / 她哭了替我谢谢他 / …… / 冬天有个新展 / 好吧。不打扰了。）→ 号码一个数字都没错 → 洗手间昏黄的灯下：没有消息、通讯录里“那个迟到的”不见了；设置里从没点开过的一栏——**已屏蔽的联系人：一个，没有名字，只有一串数字**，你一个一个对，一样 → 这是那部新手机（他设的密码）→ ⭐ **你把这一年排出来**：改过的名单 / Margot 挪到下下个礼拜三“是他挑的日子” / “Winter 常提起你” / 少了一个号码 / 新手机里屏蔽一个——**每一件单拿出来都有一句温柔的解释；排在一起，是一张图** → 出来时他就站在洗手间外的走廊上看着那扇门：“还好吗？”“嗯，里面太热了。”（第五个谎）→ 他替你扣大衣；你想起不到一个月前他在地毯上哭——那是真的，这张图也是真的 → Theo：“这回你先生没全订？”“这回留给别人。”拥抱时 Theo 耳语：“有事给我打电话。号码没变。” → 车上揉脚：“玩得好吗？”“好。”“那个画椅子的，画得不错。” → 夜里被子底下，“解除屏蔽”那行蓝字，拇指停着；想起地毯、“我怕”、手腕上的眼泪；按下去他明天就会知道你看见了那张图——**你没有按，也没叫醒他问，只把那串数字背了下来**（看三遍、默念三遍）→ 手机放回杯子和明天那一粒旁边；重复是一个人不肯放手——你想起他每天早上看着你咽下去、每夜确认戒指一遍又一遍。

**为什么这么写**
- Winter 选岔路二 C：「和之前他那些看似稀松平常的随口一改一样，都是他致密的布局🥺」——本章的心就是把“随口一改”排成一张图（名单、日子、号码、新手机），用她自己的话落地。
- 删号码其实是**屏蔽**：光删联系人拦不住短信，只有屏蔽才让 Theo 的消息一条都进不来；新手机是他一手设好的（第六章），所以查得到、说得通。
- 他在画廊“一句话都没说、退开”：第十五章之后他在努力，这份努力是真的；可旧的布局同时浮出来——承认 ≠ 痊愈，两样都真。
- Theo 给的是一个问题（岔路 C），顺带还给你一样“不是因为他而发光”的东西：你大三时说过的那句话。**这是全系列第一次，有人替你想起你自己**。那句话同时照着他（重复＝不肯放手＝每天早上那一粒、每夜确认戒指），题词用它。
- 你**不质问、不解除屏蔽，只背下号码**：他刚在你怀里哭过，恋爱脑的你舍不得；可你已经开始有自己的档案了（和他的记事本是镜像，下一章他的记事本出场）。
- 新埋：你背下的 Theo 号码；“有事给我打电话，号码没变”；请柬信封上的“Whitmore 小姐”；第五个谎“里面太热了”。
