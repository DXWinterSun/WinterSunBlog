**这一章做了什么**：Margot 约了三次都不巧（一周年相册样片 / 临时去汉普顿 / 他说你脸色不好），第四次她直接打家里座机，“你要是再有事，我就去你家门口坐着” → 麦迪逊大道绿遮阳棚的老餐馆，靠窗那张桌子 → 你点沙拉不点薯条（他说油炸的第二天会头疼）→ “你瘦了”；五个月没收到她的消息，“周年那天我给你发过……往你家打了两次电话，都说你不在”；你说新手机可能没导过来 → **回收第一章那条“我有话想——”**：她七月订婚了（细细一圈蓝宝石），想让你当伴娘；你想起自己的七月里没有一天想起过她 → 她的未婚夫在布鲁克林教物理，把戒指冻在冰里等了四十分钟 → 你又在转戒指；“你多久没一个人出过门了？”你想不起来；“他就是太爱我了，你不懂” → “吃一根，明天头疼了算我的”，薯条跟记忆里一模一样 → 结账时 Byrne 先生已经付过了（你没说约的是谁）→ 你让 Eamon 先回去，“二十个街区，我走得动”，Margot 轻轻吹了声口哨 → 一个人进了公园，湖、划船、抱着半个热狗的松鼠；手机没电了 → 阿姆斯特丹大道的旧书店，戴毛线帽的老头，铅笔题字的旧诗集 “For J. — the one you said you wanted, that winter.” → 天黑了，出租车回家，心里满得发慌，想着要跟他讲这一天 → 晚了两个钟头；门厅、客厅都没开灯，他穿着大衣坐在窗边那把扶手椅里：“你去哪儿了。”

**Winter 定的方向**：“他冷一秒钟”——这一章把刀递到这里，冷的那一秒放在第六章开头。

**新埋的钩子**：Margot 要你当伴娘（她的婚礼 → 第二幕一场大戏）；家里电话“都说你不在”；那本写给 J 的诗集；“不一个人出门”这件事的起点。

**拟好的发布信息**：summary “Margot 问你多久没一个人出过门了。你想了想，想不起来。”（30 字）；mood：暗涌 · 怅惘。
