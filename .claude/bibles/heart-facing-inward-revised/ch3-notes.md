**这一章做了什么**：倒叙，框在第二章那一夜之后的早上 → 他看着你咽下那一粒，亲手给你套上高领毛衣，“今天别出门了，外面起风了” → 你抱着《秘密花园》窝在窗边，想起全城下的注，“他们要是知道你们是怎么开始的，就不会下注了” → **前年十二月，广场饭店**：你母亲的冬季慈善晚宴，你被介绍了十一次，Carter 家的小儿子讲了四十分钟帆船；你穿过后厨推开侧门，看见一个靠着黑色轿车抽烟的男人（领带扯松、袖子卷起、脚边三个烟头），以为是谁家的司机 → 你问他要烟、呛出眼泪，“你不抽烟”“今晚开始抽”；他什么都能聊，刻薄又好笑，送货摔断两颗门牙“后来补的比原来贵” → 你发抖，他脱下外套披给你、一颗一颗扣到最后一颗 → “那你替谁开车？”“多半是替我自己。” → 只报了名字 Declan，把半包烟塞给你，“你抽得真难看” → 第二天烟盒锡纸背面：Kavanagh's, Avenue A. / Thursday. 8. / — D.（你至今夹在日记本里）→ **东村爱尔兰酒馆**：你坐错了桌，跟另一个 Declan 聊了十分钟，真的那个端着两杯酒回来，“我就去拿了两杯酒，你就跟别人跑了”；斯文的 Declan 脸一白：“Byrne 先生。”→ 你在财经版上见过这个名字 →“你说你是司机。”“我说我替自己开车。”→ 他问你小时候最喜欢什么（《秘密花园》，“那是你没找对院子”），问你想要什么（“那就慢慢找，不急”）→ 门口小雪，他又替你扣大衣，你第一次叫他 **Dec**，“在纽约，没人这么叫过我。”“那我叫。”→ **一月**，第一次去你家吃饭，洗手碗那一口，你父亲也喝了一口；台阶上你父亲：“他看你的样子，像一个人在看他这辈子头一回有的东西，生怕有人来收回去。”→ 春天推荐信原样退回，“他什么都不要，他只要你” → **他那时住的就是现在这套**：十一个房间、冰箱里只有水和橙子、墙上没画；你一样一样往里搬（外婆的绿玻璃台灯、书、地毯、每礼拜一的花）；他靠着门框“看你把我家弄得乱七八糟……我十六岁以前搬过十一次家，每一处都只有一扇窗。你再这么弄下去，我就搬不走了”；你懂了：他什么都有，就是没有家，所以他娶了你 → **四月求婚**，在厨房，你煮糊了意大利面、烟雾报警器响个不停，他掏出四页讲稿，念了两句你就说好，“那你留着，以后念给我听”，那颗“大得有点新”的钻石；那四页他到现在也没念过 → 回到窗边：是你推开了那扇侧门，是你先找上他的。收束里轻轻一歪：宾客名单上没有他的名字，你从来没问过他在后门等的是谁。

**Winter 挑的三样**：初遇＝你以为他是司机；你心里的版本＝你给了他一个家；裂缝＝只在最后一句歪一下（全章都是你相信的甜版本，只有收束最后两行露出：他不在宾客名单上、他在等谁）。

**立下的设定**：她叫他 Dec 的来历（酒馆门口第一次叫，“在纽约没人这么叫过我”“那我叫”）；她在家族基金会帮忙；她父亲会看人、话少，一个动作表态（洗手碗）；他十六岁前搬过十一次家、每一处只有一扇窗（接第一章“一间只有一扇窗的公寓”）；他替你扣扣子这件事，从初遇那晚就开始了。

**新埋的钩子**：① 宾客名单上没有他，他在后门等谁（三个烟头）→ 大钩子，见路线图新岔路；② 锡纸夹在你日记本里；③ 求婚那四页讲稿，他从没念过（“以后念给我听”）；④ 你父亲那句“生怕有人来收回去”；⑤ “你想要什么？”——她答不上来，因为她一向想要什么就有什么、还没学会“想要”；可她说“不知道”时正看着他，心里说“这个，你想要这个”，没说出口（“那就慢慢找，不急”）→ 第三幕她说出口；另一层：婚后他延续的正是这个模式，什么都在她开口之前放到手边；⑥ “那是你没找对院子”——他给她的就是那座有墙的花园。
