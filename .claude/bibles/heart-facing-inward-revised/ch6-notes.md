**这一章做了什么**：黑暗里，“别开灯” → 你解释午饭、公园、书店、手机没电 → **冷的那一秒**：“我知道你跟 Margot 吃了午饭。我问的是后面那两个钟头。”——没有笑、没有都柏林、没有 love，谈判桌上拆人之前的声音；你怕了你的丈夫；闪过一个念头：你没告诉过他约的是谁 → **下一秒**他起身，抽走诗集，捧起你的手：“你的手这么凉”，呵气、搓手，蹲下脱鞋；那个念头不见了 → “过来。”伏在他膝上，裙子撩起，“两个钟头，二十下，你自己数” → 每一下都揉一揉；“下次呢？”“先给你打电话” → 第十四下之后他的手停在半空，只说了一句“天黑了。你不在。”（他唯一漏出来的一句，不说前后）→ 第十五下最轻；“不让手机没电”“还有呢？”——**“不一个人走了。”**（你亲手交出了刚尝到的那一点自由）→ 二十下，抱进怀里，“好了，love”，都柏林浓得化不开 → 落地窗前，整座城的灯；“你想去外面。看。都在这儿。”领带松松绑住你的手腕，你挣得开，你没挣 → “这就是你的认错？” → 进来以后要你把那两个钟头一样一样说出来（湖、松鼠、书店、诗集），每说一样他收一笔账，“现在它们也是我的了” → 按着你被绑的手在你心口上，“现在” → 事后：解开领带揉手腕、热水澡、药膏、一杯温水看着你咽下去；他坐在床边没躺下 → 早上：新手机，“电池能撑两天，再没电就是你故意的了”；昨天四点到六点四十一个未接来电；“你那么担心？”——他用晚宴上那种笑挡回去：“我只是想知道那只松鼠后来把热狗吃完了没有。” → 你隔着玻璃看那座公园，觉得这样也很好。

**Winter 点的菜**：他冷一秒钟；惩戒意味的炽恋；包裹成担心的占有欲。惩戒是成年、自愿的——手腕绑得很松，“你挣得开，你没挣”；她身体的反应是真的。

**声口守住**：他不说那两个钟头里在想什么（DEFERRED → 第十八章），只漏了“天黑了。你不在。”；早上四十一个电话被问起时照样用笑话挡。

**新埋的钩子**：“不一个人走了”（她亲口许的锁 → 第十章她第一次故意违背、第三幕收回）；四十一个未接来电；电池能撑两天的新手机（新的锁，包装成关心）；他那晚坐在床边没躺下。
