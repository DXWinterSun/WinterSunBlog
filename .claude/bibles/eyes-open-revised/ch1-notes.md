# Ch1《桌上的不算》· 写作笔记（v2，2026-09-17 按 Winter 反馈重写）

- **v1 → v2 改了什么**：v1 她靠声音认出他、v2 她第一眼就认出、装不认识、没收住；v1 他太正经、v2 满篇「老流氓」式贫嘴；
  内核从「桌上骗桌下不骗」升级为「你永远逃不过他的眼睛」；补了 26 岁 / 老师 / 暑假 / 照着他的照片来的这条理由。

- **起点**：Winter 选的 A 方案（公路上捡到的）+ 她上桌玩（不当法官）+「桌上他耍全场、桌下不骗我」。
- **认出 → 装 → 露馅 → 被拆穿 → 摊牌**：她的每一次「没收住」（笑一顿饭、手抖、「来了」）既是粉丝的可爱，也是他桌上的板子、桌下的证据。
- **「十六」那两秒**：老流氓也有心虚的一下；这是他这章唯一不贫的地方，别删。
- **他骗她的那一局**：她真预言家、他狼悍跳、报她查杀、警徽流——全是他的拿手戏。让他**连她一起骗**，
  「桌上的不算」才有分量。
- **他读牌的细节**（手抖、夜里叹气）：既是他厉害，也是「他一直在注意你」的暗线，不点破。
- **最露的一句**「桌下不骗你」放在转身走两步、没回头之后——挡话方式。
- 章名「桌上的不算」= 本章锚句，过遗忘测试。
- summary（28 字）：你装得挺像。可从他摘下头盔那一秒起，你就没逃过他的眼睛。
- mood：悸动 · 絮语。
- 中文设定：拆字「王字旁的璇」合法；「一个字也没听见」是成语式用法。
