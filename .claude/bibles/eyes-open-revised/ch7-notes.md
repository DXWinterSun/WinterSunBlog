# Ch7《回程多少钱》· 写作笔记

- Winter 三选（2026-09-18）：谁先开口 = **A 她手滑把评论发出去**；她补的细节：**他压根不知道一堆粉丝里哪个是她**，
  她不小心评论出去他才看出来，「他难得看了每条评论」，回复了她。→ Ch2 补了一句「你微博叫什么？」「不告诉你」「你女粉那么多告诉你你也记不住」。
- 校门口 = A（大白天、学生围观）但 Winter 提醒：她学生年纪小，认识他的少 → Ch9 写成学生只当他是「骑摩托的大叔」，
  认出他的是年纪大的同事 / 某个学生的哥哥。他来了以后 = A（在上海开线下局，待一周，每天散局送她回家）。
- 这章的核心画面：他不回评论的人，把那条两千条评论一条一条翻，「找一个问回程的」。
- 「你没说想我，你问的是钱」——他替她把「说了我就没数了」那条规矩绕过去了，老流氓式的温柔。
- 视频里留的那一秒橙色 + 那一声笑 = 「他把别的都剪掉了，把这一秒留下了」。
- Ch6 改：「配文四个字」→「配文只有一句」（Winter 抓的：粉丝票用完了是六个字）。
- 中文设定，数字合法：「五个字，一个问号」（回程多少钱？）、「三个字」（找着了）。
