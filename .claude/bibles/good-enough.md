## 一句话灵魂（Winter 定，钉死，v3 继续沿用并升级）

**别人看他是小丑，你看他是宝贝。**

Justin Hammer 油嘴滑舌、无时无刻不在耍宝、动不动没来由地傻笑、脸皮厚到"只要我自己不尴尬，
尴尬的就是全世界"。他这辈子拼了命想成为斯塔克那样的天才，可那条路他到不了顶——
**但这根本不该定义他是谁**。他会跳舞、跳得那么好；他品味好得要命；他有一把能唤醒天使的嗓子；
他做一场推销又好笑又迷人。他浮夸、爱演、又贱又缺爱——但他**好看、鲜活、好玩、有魂**。

**⭐ v3 把这句话推到了极致**：在他的世界里，别人看他是小丑；而在**你的世界**里，他连"人"都不是
——他是一部十几年前的电影里那个输给斯塔克的笑话角色，是表情包，是别人拆卡拆到会顺手扔掉的
那一张。**全世界几十亿人，只有你把他的卡一张张收起来、做成手机壳，让他的脸天天贴着你的手。**

**系列名 *Good Enough* 兑现的那一刻 = 你终于亲口把这一切告诉他的那一刻。**

## ⭐ v3 前提（Winter 2026-09-17 亲口定，钉死）

1. **他掉到你这边来。** 你正在家里重温《钢铁侠 2》，看到欺负他最狠的那一段，一边看一边骂
   "凭什么要这么写他"——他就出现在你家地板上。
2. **他是从他人生最低的那一刻掉出来的**：博览会之后、被拷上带走的那一刻。所以他到你这边时，
   手腕上有勒痕、眼镜裂了一道、嘴还硬。**而电视上那一幕还在演。**
3. **你的世界 = Winter 现在的真实生活**（Winter 定）：中国、当英语老师、拆卡、做痛壳。
4. **他不会中文。** 这辈子最拿手的本事是张嘴就能把东西卖出去——现在他张嘴，只有你听得懂。
5. **第二幕的目标：你们一起想办法穿回他那边，帮他改写结局。**
6. **⚠️「他绝不进监狱」这条老红线，在 v3 里从一句规矩变成了整个故事的目标。**

## 人物

### 他 · Justin Hammer
- 美国人，约 40。哈默工业创始人兼 CEO，军火承包商。
- **核心（官方）**：斯塔克作为"商人"的暗面镜子——**内核是嫉妒 + "怕自己一文不值"的深层恐惧**。
  导演原话："斯塔克是兔八哥，他是旁边那只达菲鸭"——拼命追、永远差一步、还想不通为什么。
- **⚠️ 卖家 > 天才（最容易写崩的一点，官方设定）**：嘴上销售天花板，真本事二流。他不蠢，
  但技术上被斯塔克和万科碾压，死不认。**绝不把他写成"隐藏的工程天才"。**
- **声口（Winter 最看重，钉死）**：油嘴滑舌、无时无刻不在耍宝、没来由地傻笑、死不要脸地闪光。
  快嘴推销腔，爱掉书袋、爱给人乱起外号。"只要我自己不尴尬，尴尬的就是别人。" 真情实感从不明说，
  只在身体细节里泄。
- **肢体动作拉满**：大开大合的手势、说着说着当场给你来一段舞。**核心是用自恋 / 表演盖住自卑**：
  越心虚越浮夸，越被戳穿越加码演。写他，手脚就别让它闲着。
- **性向**：照电影，**异性恋**。不采用短片《万岁吾王》里监狱那段设定。
- **官方台词彩蛋**：他真有一句 **"Is it my birthday?"**（得意时说的）——留着埋进生日章。
- **眼镜**：银幕实证他戴那副方框眼镜，本 AU 当**盔甲 / 骄傲**的象征来写。
- **⭐ v3 新增 · 他对"自己是虚构的"这件事的反应**：这是 v3 最大的新戏肉，也最容易写崩。
  口径——**他不会崩溃成一个哲学病人，他会先用演的盖过去**（"所以我是明星？我早说了我该拿奖"），
  然后在没人看的时候一个人坐着。跟 v2 的 Ch2 是同一个动作：**亮起来 → 被撞见 → 一秒钟藏回去。**
  ⚠️ 别让他大段自剖"我原来不存在"，那是 OOC。

- **名 = Winter**（全站 AU 通用铁律，绝不再改、绝不再问）。
  ⚠️ **本系列的姓氏待 Winter 点头**：v2 用的 `Frost` 是给美国职场设定的；v3 里"你"是中国人，
  建议跟 Interoffice 一样用 **Zhang / 张**。**问法只有一种：「这个系列姓什么？」**
- **身份 = 中国的英语老师**（Winter 定 = 她本人的真实生活）。所以你能跟他说话，全世界只有你能。
- **你的收藏**：一整桌他的卡（Disney 100 · Marvel · PHANTOM 那套银色卡），外加一个把他的卡
  夹在背面的透明手机壳（"痛壳"）。⭐ **这是全系列第一信物。**
- **天赋 = "看见"**：但这是**普通人的眼力，不是超能力**。你看见他的，不是因为你特别，
  是因为你**愿意看**——全世界都懒得多看他一眼。
- **⭐ 你独有的立场（v3 的发动机）**：**你早就看完了他的结局。** 你知道博览会会出什么事、
  知道他会被拷走、知道他嘴硬说"这不算事，我会回来的"。**你知道，然后你还是喜欢他。**
  这是任何人都给不了他的东西：不是"我相信你会赢"，是"我看过你输，我还是选你"。
- **关系内核 = 你早就暗恋一个你以为永远不会存在的人**。他站到你面前那一刻，
  这份暗恋从"安全"变成了"要命"。

## 关系动力学（发动机）

- **权力方向（v3 翻转了 v2）**：在他的世界他是老板；可在**你的世界**，他一无所有——
  不会说话、不能出门、不能被人看见，全靠你。**是你在护着他。**
  但注意：**绝不能把他写成宠物或废物**，他会拼命找回一点主控（做饭、修东西、替你出主意），
  这份"我不能白住你这儿"的自尊心正是他可爱的地方。
- **暗恋方向**：是**你**偷偷要他——而且你在他出现之前就已经要了很久了。
- **甜点**：他撞见你收藏他的证据时那一下、你替他挡住这个世界的每一件小事、
  他把眼镜摘下来的那一刻。
- **救赎是双向的**：你帮他改写结局；他让你终于敢说出口、敢不再藏。

## 语言（⚠️ v3 专条，全站语言规则的**合法例外**）

跟 Interoffice 同类：**语言差是剧情本体，不是穿帮**。口径：

- **他说英语，你说中文**；你用英语跟他对话（你是英语老师，这是你能接住他的原因）。
- 正文可以、也应该**明写"他说的是英语"**——因为此刻这确实是一次真实的语言切换，
  且交代了是哪一门、为什么。这正是全站规则允许的那种合法切换。
- 他听不懂的中文（你跟外人讲电话、点外卖、你自己的碎碎念）是**天然的戏**，多用。
- 屏幕上的电影：**英文原声 + 中文字幕**，所以英文原句可以原样落纸（那是"读者看见的实物"）。
- ⚠️ 仍然守死：**别让他中英各说一遍**；**别数汉字**（他说的话在中文里几个字，在他嘴里不成立）。
- ⚠️ `tools/check_desino.py` 会把本系列里**合法的中国生活细节**（筷子、外卖、小区）误报，
  人工放行即可——"你"这一侧本来就在中国。他那一侧照旧严格去中式。

## 母题（每章尽量带一下）

- **⭐ 卡 / 痛壳**：v3 的第一信物。他的脸贴着你的手。反复回响。
- **眼镜 = 盔甲 / 骄傲**：掉过来时**裂了一道**（他被打的那一拳留下的）。
  全篇走向：他**主动**在你面前摘下眼镜 = 终极卸防。
- **"第 X 分钟"**：他的东西总在第 N 分钟出问题；你们的关系却一分一分地撑过去。
- **他没来由的傻笑**：那种特别欠又特别真的笑，反复写。
- **你咽回去的那半句话**：你一路把想说的话咽回去，攒到 good enough 才放。
- **他的嗓子 / 会跳舞 / 好品味**：反复让"你"注意到这些他自己不当回事、你却偷偷着迷的地方。
- **⭐ "我会回来的"**：他被带走时那句嘴硬的台词。第一章就落地（他真的"回来"了，
  只是回到了你家客厅），结尾还要再回响一次。

## 红线 / 护栏

- **别写得像银河系（Zaphod AU）**：世界踩死在人间地面；"命中注定"只配给生日那一处；
  他是失败者不是王；你的"看见"是普通人的眼力不是超能力；救赎是渺小、挣来的。
  一句话：银河系是"我愿为你跨越宇宙"；哈默是"你不必成为斯塔克，你本来就够好"。
- **声口红线**：他动情只靠身体动作泄，绝不明说心里话（被问软处就打哈哈 / 耍宝岔开）。
- **卖家 > 天才红线**：绝不把他写成隐藏的技术天才。
- **⭐ v3 新红线 · 别把穿越写成科幻**：门怎么开的，**不解释机制**。这是个爱情故事，
  不是时间旅行论文。谁都不许在正文里推导原理。
- **⭐ v3 新红线 · 他不是宠物**：他一无所有，但他有自尊心，会拼命找回一点主控。
- **他绝不进监狱**（v3 里这是故事的目标）。
- 全站通用红线照旧：正文弯双引号 “”/‘’、`summary` ≤35 字且无 ASCII 双引号、身份标签齐、
  de-sin 去中式（他那一侧）、内链带 `{{ site.baseurl }}`、章尾收束引语短（3–6 行诗式，
  不复述整章）、正文严禁 cue 章节名。
