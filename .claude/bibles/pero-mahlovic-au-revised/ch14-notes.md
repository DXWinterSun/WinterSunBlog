### 这一章干了什么（你要甜的——甜里带着他那张永远还不完的欠条）

- ⭐⭐⭐ **§一–二 十二月二十四号：他隔着门给你两颗糖。**
  药房提早关门（Lombardo 家过了三十年的圣诞，一年一年一样都不差）；
  他在外头缩着脖子、耳朵冻得通红、**不进来**："我知道你们今天——我就说一句话。"
  "圣诞快乐，doll。""……你也是。"⭐ **"我不是。我们家还有十三天呢。"**
  → 塞给你一个纸包就跑，跑两步回头挥手。
  ⭐⭐ **纸包里是两颗润喉糖。**不是你们家的——蜡纸是浅绿的，印着两条街外那家药房的字。
  **两颗。他买得起两颗。**
  🎯 **全书最重的一次回收**："一九四一年他八岁，第一次伸手拿了一颗，说'我明天还'。
  这十八年里他大概拿走了一千颗，**你一颗都没有记过账。你没记。而他一直记着。**"
  → 纸包背面铅笔字（做成 `c-note` 卡）：**"这个不算还账。这个是新的。"**
- ⭐⭐ **§三 你父亲的第二次松动**：他手上那片红退了、**起茧了**（"茧不是一天两天长出来的东西"），
  你还是没说。有一天他进门时你父亲在配药台后面，他手抬起去够领口那颗扣子——
  ⭐⭐⭐ **"Mahlovic。"**（**你父亲第一次叫他的姓**；在这之前他嘴里那个人一直只是"他"）
  **"把门带上。外头灌风。"**
  → 他把门带上，**然后把手放下来了**：⭐ **没扣完，也没解开，那三颗就那么停在那儿，一整个下午。**
  （伏笔账里"当着你父亲的面不扣"的**中间一步**，还没兑现到底。）
- **§四 你问他能不能带你去看他们家过节**——⭐ **他躲了**（说得很快、转那个小架子：
  "那个没什么好看的……我哥现在管着那个屋子……反正没什么看头"）。**你没有再问。**
  → "不过，我教你一句话。"
- ⭐⭐ **§五 他教你那句对答**：`Hristos se rodi.` / `Vaistinu se rodi.`
  纠了你三遍口音（"你那个音太软了"），然后 **"sugar，你这个说得比我表哥好。
  我表哥四十岁了他还说不利索。"** → ⭐ **你反过来要他说一遍，你接下句。**
  灯很暗，他睫毛上有一点湿的东西。"行。"他说。
- ⭐⭐⭐ **§六 他妈妈那本西里尔字母的祈祷书**（黑色、边角起毛、书脊用线缝过）：
  ⭐ **他念得很慢**——"平时那张嘴一秒能出六个字，现在他一句话要念半分钟"；
  **念到第四行他停住了：'……这个我不认得。'**
  → "我妈教我的时候我才这么高。**她要是听见我念成这样——**" ⭐ **他没有把这句说完。**
  （母亲第一次由他自己提起，回忆式，合规。）
  → 合上书："回头我把它认全了再念给你听。"⭐ **又是一张欠条。你把这张欠条也收下了。**
- ⭐⭐ **§七 画十字的方向**：他划右→左，你划左→右；他问"你们那边怎么划来着"，
  ⭐ **然后他抬起手，照着你的方向慢慢划了一遍**，划完自己愣了一下，笑："别告诉 Giacco。"
  （🎯 **留着的对称**：你照他的方向划一次——留到终章／更后面。）
- ⭐⭐⭐ **§八 你那句话被他打断了**（你原话「我不管他成不成大事都喜欢他」的写法）：
  "Pepe。""……你不用非得——" → ⭐ **"哎哎哎。"两只手举起来挡着，"不许说。"**
  "我还没说呢。""**我知道你要说什么。**"
  ⭐⭐ **这是十八年里他第一次知道你要说什么**（对照全书那条"他读不懂你"）。
  → 他把它推走："**你等着。等我把那个东西弄回来——到时候你想说什么说什么，你说一整天我都听着。**"
  → 收在一句，不解释：**"而你想说的那句，本来就跟那个东西没有关系。"**
- **§九 收尾**：下雪；他在路口回头挥手（跟上一章一样大）；
  ⭐ 你站在空街上，把那句话自己又念了一遍：**"Vaistinu se rodi。"**

- ⭐⭐⭐ **§十 补写（Winter 2026-09-12 抓出的问题，这一补反而成了全章最好的落点）**：
  一月七号早上店里人不少（Bertoni 太太、送冰的、一个八九岁男孩、你父亲在称东西），
  他整个肩膀把门撞开：**"Hristos se rodi！"**
  → ⭐ **他见谁说谁，一个都不落**：对送冰的（"你这个人怎么当美国人当成这样"）、
  对 Bertoni 太太（**"Hristos se rodi，darling。""这是什么意思啊。""意思是您今天特别好看。"**）、
  对那个男孩（逼人家学三遍还鼓掌）、⭐ **对你父亲**（"Mr. Lombardo！Hristos se rodi！"→
  你父亲抬眼看他一下，"嗯。"，低头接着称东西）。
  → 最后他走到柜台前，两手一拍台面："Hristos se rodi。"
  ⭐⭐⭐ **"Vaistinu se rodi。"你说。** → **屋子里安静了一下。**
  那男孩问"她说啥？"——**没有人回答他**；他站在柜台外面看着你，一秒，两秒，
  ⭐ **脸上那个笑没有动，像是忘了收**；然后猛地转身冲一屋子人张开两只手："**你们听见没有！**"
  ⭐⭐⭐ **收在两句，不解释**：
  **"他把那句话给了这屋子里的每一个人。／只有一个人接得上下句。"**
  🎯 **这一节把全书的甜昵称母题整个翻了过来**：他撒出去的东西永远是一把撒给所有人的，
  而**"独一份"不在他给的那一句里，在你能接上的那一句里**。
