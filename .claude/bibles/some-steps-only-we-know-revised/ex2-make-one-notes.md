**改了什么**：按你说的，把机关整个翻了过来。原先那版是“他二十年都不知道自己在做什么”，现在是——**他一直都知道，比谁都清楚**。

**新的底层设定（这是全篇的心脏）**

- 你是真的依赖它们：那只**秃了耳朵的旧兔子**你抱着睡了十几年；心里不痛快就一只只摸过去，像点名；每一只是哪年来的你都记得。
- 但你怕被笑话，所以你对外的说法二十年只有一个：“**都是 J 硬塞给我的，我拿他没办法。**”——被迫收下的东西，是不必为它害臊的。你在这句话后头躲了二十年。
- **他看穿了，而且一声不吭地陪你演到底。**他每回买，都先把自己变成个混蛋，**给你一个能心安理得收下的由头**。
- 甚至有几只，他根本没惹过你——**是他故意惹的**。你十四岁生日他“跑去赛车”，其实是因为那礼拜你在那家铺子的橱窗前停了三回（第三回还装作在看隔壁的帽子）。“你想要，又死活不肯开口。”
- 他的账算得明白：“这买卖我做了二十年，成本是被你骂几句，我赚翻了。”

**他那一击**：你红着脸坦白“我喜欢它们，你别笑我”，他说——“**我知道啊。**你当我瞎啊。”

**两层秘密分得很清**（所以 Julian 那条引信照样成立）：
- 他知道**你喜欢** ✅
- 他不知道**你为什么喜欢**——那句“羡慕有人在几百只里挑中它，一路抱回家，从此它就属于那儿了”。原文写明这话你“从没跟人讲过”，而你讲的那个人是 Julian。他那句只说了半截：“我一直以为，我只是在哄你开心——”然后说不下去了（他这辈子最不会做的事，就是把这类话说完）。

**辣的部分**：道具从熊换成了那只秃耳朵兔子（你真正睡的那只）。他塞进你怀里让你抱着，“今儿让你尝尝，被人挑中、一路抱回家，是什么滋味”。结束那一下他贫的是：“……挑中了。抱回家了。”称呼机关床上版不变（你骂 Crocker，他挠你逼你叫回 J）。

**收尾按你要的“他还会一直买”**：
> “往后还买吗。” / “买。买到你屋里堆不下。买到你嫌我烦。明儿路过摄政街，我瞧瞧有什么新到的。” / “……你又没惹我生气。” / “**那我现在惹一个。**”
