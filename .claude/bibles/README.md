# 系列圣经存放处（内部工作文件，Jekyll 不发布）

每个在写的 AU 系列在这里留**两样**东西（缺一样，接手的对话就得靠猜）：

1. **系列圣经** `<series-slug>.md`——人物内核、关系动力学、复现母题、称呼铁律、
   章节流水、PINNED/DEFERRED 伏笔账。用法与格式见
   `.claude/skills/winter-au-writing/SKILL.md` 第二块及其 `references/worked-example.md`。
2. **正文全文存档** `<series-slug>-revised/chN.md` + `chN-notes.md`——一章一个文件、
   一字不差的正文，外加「这章为什么这么写」的笔记。圣经记的是「发生了什么」，
   正文存档留的是「原话怎么说的」；守声口、回收原话、查称呼当初怎么写，都得靠它。
   ⚠️ **写完一章立刻存，别等 Winter 过目完再存**——还没发布的章不在 `_posts/` 里，
   只躺在会话临时目录里 = 随时可能没。

完整工作法见仓库根 `CLAUDE.md` 的「写连载 = 每章都要留下两样东西」一节。

规则：

- **续写任何系列前，先读它的圣经**；每写完一章，回来更新章节流水和伏笔状态。
- 圣经不存在的老系列：续写前先从已发布章节（`_posts/`）重建一份再动笔。
- 这里是给模型看的工作笔记，不给读者看——`.claude/` 目录不会被 Jekyll 构建进站点。
- 改动随正文一起 commit / push，这样任何后续对话（换模型也一样）都能接上记忆。
