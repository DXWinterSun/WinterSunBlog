# 系列圣经存放处（内部工作文件，Jekyll 不发布）

每个在写的 AU 系列在这里放一份 `<series-slug>.md` 圣经——人物内核、关系动力学、
复现母题、称呼铁律、章节流水、PINNED/DEFERRED 伏笔账。用法与格式见
`.claude/skills/winter-au-writing/SKILL.md` 第二块及其 `references/worked-example.md`。

规则：

- **续写任何系列前，先读它的圣经**；每写完一章，回来更新章节流水和伏笔状态。
- 圣经不存在的老系列：续写前先从已发布章节（`_posts/`）重建一份再动笔。
- 这里是给模型看的工作笔记，不给读者看——`.claude/` 目录不会被 Jekyll 构建进站点。
- 改动随正文一起 commit / push，这样任何后续对话（换模型也一样）都能接上记忆。

（这个目录由 Fable 在 2026-07 设立：圣经从前放在会话临时目录里，会随容器回收
而丢失——伏笔账丢了，续写就失忆。入库后跨对话续命。）
