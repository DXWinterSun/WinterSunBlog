## ⭐ V2 重启总纲（2026-08-09 Winter 拍板重写，读这份优先于下面的「已写章节流水」）

一直是团烂摊子（一边造低俗节目、一边杀人、一边吊着 Penny 又和 Patricia 纠缠），
到 1980–81 才崩、才收台。**v2 要把这条完整时间线走完，慢下来、忠于原片、把题记和收束语做精巧。**

**唯二保留的承重墙**（Winter 点名）：

2. **雪夜「撞见他穿黑风衣」那场**（v1 Ch5「另一种光」，Winter 全系列最爱）——原样精神保留，可打磨文字。

### 三条重启铁律（写每一章前对一遍）

1. **别过早专一、别过早救赎**。物理上的亲密可以早（他本就看对眼就凭本能扑上去＝在人设内）；
   但**情感上的排他、他「变好」「被治愈」不能早**。雪夜之后他**照样**回 LA、照样吊着 Penny、
   照样过双面日子、照样和 Patricia 纠缠——你们是**开放关系**（你从不索要忠诚＝你的人设），
   你甚至自嘲「或许我自己才是那个情人」。这种「进一步退半步」要**贯穿整个 70 年代**，不是一次性的退潮。
2. **Penny 留得更久**。v1 让她 Ch8 就退场＝太早。v2 里她**陪他走过大半个 70 年代**（原片他最后才娶她），
   她的退场挪到很后面（Part 3 收台前后，作为仁慈）。
3. **「我爱你」和「主动交出全部秘密」都压到最后（1980–81 那簇）**。终极那句
   “I've conned a whole country. You're the only one I never want to fool.”
   放在**二选一对决 + Patricia 之死 + 他崩后重建**同一簇里砸出来——他要先接受
   「就算偶尔做荷尔蒙的奴隶也没关系」才说得出。放早了就废。

### ⚠️ v2 关系与叙事的进一步修订（2026-08-09 Winter 定，覆盖旧设定）

1. **你不当他的写手/军师**（推翻旧圣经「创作搭子」设定）。你俩**不绑成同事、不成日常**——
   要的是「**会主动去找彼此、但不是天天安排见面**」的关系（时聚时散＝更有火花，也更贴他的性子）。
   你有自己的本职（广告文案照留），但**别再写成「傍晚拐进棚里帮他改题」那种持续共事的日常**。
2. **你的上节目动机**：走**正常报名流程**当那个提问的姑娘，心态是「觉得这节目有戏、说不定碰上个有趣的人」。
   **删掉「三年铁粉/求着混进后台」**——那降智，这节目本就是平民娱乐，不值当你当铁粉。
3. **看对眼当晚就上床·第一次要实写**（Winter 拍板，最贴原片）。原片就是他看对眼、下一秒切到床上。
   Chuck **靠这种关系拿到即时的满足与安宁**（用一具活着的身体把脑子里的吵闹摁下去、确认自己没死透）＝**刚需**，
   所以第一次**不能省**——正好让你和读者飞快摸清他这一面。写法守「**床上也戴面具**」：他掌镜、贫嘴、算准每一下＝在**演**，
   只一闪露真，**你偏是会翻卡、专等他忘形那半秒的人**。
4. **双视角基调**：对他，这一晚**稀松平常**（跟点烟一样，转天就忘，你本该也是「那样一支烟」）；
   对你，这是**来之前就半真半假想碰上的那点心动，只是没想到会从造机器的人身上来**。他的「不寻常」tell＝**记住了你的名字**。
5. **删信物卡（太做作）**；「翻卡」弱化成「把卡撂下、问真问题」的动作，别再做成郑重其事的符号或信物。
6. **`sweetheart` 的批发温柔留到 Penny 真正出场再用**——别在初遇硬塞一个喊他的姑娘（你都被带回家了，逻辑拧巴）。

> 旧圣经里凡与上面冲突的（「创作搭子/军师」「傍晚拐进棚改题」「铁粉磨进后台」「信物卡」「初遇 sweetheart 对照」），**一律以本节为准**。

### ⚙️ Part 2 引擎：他自己来开口（Winter 2026-08-09 定）

- **你永远不问**。他 CIA／任务的真相，不是你查出来、也不是你追问出来的——是**他自己某次任务后崩了、空了、怕了，主动来找你倒出来的**。原片有好几处：他执行任务时一边享受、一边空虚无助。就在那种时刻，他会发现**你是唯一能倾诉、唯一能对之敞开的人**，于是自己走上门（＝「开口」章的触发，别让你去撬）。
- **现阶段（雪夜后）你并不知道他的「情况」**：你只见过雪地里黑帽持枪的他，知道他有条要命的暗线、他能／曾取人性命，但**不知道他是 CIA、不知道那整套机构与任务**。全部真相要等他亲口讲。写这段别让你「已经都懂了」——你知道的是「他危险、有杀人的秘密」，不知道的是「那到底是什么、为谁、多大」。
- **他来找你倾诉时，根本没想过「你知道了会不会危及他／你的安全」**——他只是需要你，就来了（＝「他需要什么就去做、不计后果」）。→ **PINNED 伏笔**：正是这份不计后果的 need，日后把你拖进组织的视线、危及你安全；而这份危险，又反过来**长线逼他做出改变**（转变仍自驱，别速成）。

### 童年·原罪 canon 要「织进去」（v1 只在 Ch10 点了一下）

孪生妹妹脐带勒死／母亲当他害死女儿／黑纱四岁生日／被当女孩养／生父是上电椅的连环杀手——
这些是他「必须表演、必须当别人、信杀戮刻在血里」的根。**v2 要碎片式地、和你的父亲伤互相押韵着**
反复回扣（尤其 Part 2 的空虚章、Part 3 的崩溃章）。你＝**反母亲**＝他这辈子第一个「什么都不要」的人，
这条底牌现在要**写在明处的心理动力上**，而不只是背景。

### 「你既不洗白、也不定罪」的姿态（Winter 2026-08 反复强调）

你**看得见全部真相**——他确实有罪、他自己也心知肚明。所以你**不当辩护律师**（不说「你被误解了／你其实很好」——
他自己都认了问题，你还说「你没问题」＝一种不尊重），也**不当审判官**（不谴责、不说教）。
你只是**看清了，然后什么都不要地留下来**。写你的每一处反应都守住这条中线。

### 题记 / 收束语系统（v2 的精雕重点）

**系列名「Off the Air」本身＝全书总双关**：既是「节目下档／停播」，也是「不在（监控的）空中／私下、无人看见的时刻」。
每章题记尽量咬住这种「表面是电视行话、底下是他双面命运」的双关。

- **题记（开篇 `>` 引语）三个取材源**（择一或混用）：
  1. **原片真台词 / 回忆录原句**：英文原句 + 中译并列（`>` 引用块，遵站规歌词/原文格式）。库见「电影 canon 速查」的声口标本、Byrd 语录、那句 inscription。
  2. **电视行话（game-show argot）**：`We'll be right back.` / `Cue the applause.` / `Please welcome…` / `Roll the tape.` / `And now, off the air.` —— 用行话的表层说他人生的里层。
  3. **回忆录忏悔腔**：他第一人称、自知又自嘲的口吻（原著/电影那种「我造了一整个国家的假东西」的调子）。
- **收束语（结尾 `>` 引语）**：**3–6 短行**，把题记的意象**翻转或收束**（例：题记用「广告后回来」，收束语落在「有的人一走，就再没回来」）。
  ⚠️ **绝不复述整章剧情**（CLAUDE.md 硬规则）；多行每行行尾加**两个空格**（硬换行）。只留最戳心的一个意象/一句余韵。

## 人物 & 关系内核

### 他 Chuck Barris
油嘴滑舌的 showman，天才与疯狂是同一团火，整个人都是表演。**从不好好说真心话**——
问他软处就打哈哈、扯荤段子、反手撩你岔开。动真情时最贫嘴，真心只泄在动作里

不会真的牺牲自己去玉成别人。他放开 Penny，**一定是在已经有了更好的选择（你）之后**，

你上节目的动机：本就是这类电视节目的老观众/迷，好奇、想钻进机器里玩一把——但真正勾着你的，

### 发动机（谁主控）
表面 Chuck 主控——他是 showman，他「选角」、他导演一切。但**你是他唯一 script 不住的变量**：
全世界他都骗得动逗得笑，唯独在你面前会失准、忘词、不知道自己该演哪个版本。
甜点＝「掌控全场的人只在你这儿栽跟头」。调情永远是 Scrabble/斗嘴式较劲：他耍诈、你偏吃这套。

### ⚠️ 核心引擎：「从不问 · anything」（Winter 定，全系列命门）
touchstone 是逃跑计划《梦中的你》，尤其 **“而你永远是你 / 从不问我是否爱你”** 与 **“Baby 你就说吧，anything”**。
- 他极度以自我为中心、但**本质不坏**；他只是**太需要让自己觉得安全**。他愿意给的时候能给你全部，
  但**你一旦让他觉得你在「索要」**（尤其是他从没试过给、也不信「给了会安全」的东西——比如「你爱不爱我」），他就缩回去。
- **所以你从不问他爱不爱你。** 这是你的智慧，也是你给他的安全感。你不要求忠诚、不问婚姻、不逼他说爱。
- 可正因如此，爱从**「anything」**里漏出来：他愿意为你做任何事——**爱证明在他为你做的事里，不在问与答里**。
  这就是他最别扭也最动人的地方，也是「我爱你」DEFERRED 弧的运行机制：**不问、不说，却已用行动说尽。**

### ⚠️ 你为什么能「无限包容」他（Winter 提的问题：得有实在根据，否则读者困惑）
四根支柱，别只靠「个人魅力」（那只解释被吸引，不解释长久隐忍，单靠它＝花痴/工具人）：
1. **【脊柱】共鸣的童年创伤＝一个迷人却总在离开的爸爸（Winter 定 2026-08-08）**：
   你从小爱着一个魅力四射、却总在消失的父亲——他一回来就把整个房间点亮，然后又走，而你**学会了不去拦、也不去问他何时回来**
   （问了没用，只会让离别更难看）。所以你和他是**同一种被爱伤过的人**：你懂「对怕亲密的人索要爱只会把他吓跑」，是因为你早在父亲身上练过。
   **推论（写作直接用）**：① 你面对 Chuck 的**魅力+消失**不慌、不追、不问——这份异乎寻常的镇定，正是你童年伤的 tell（别人追问，你不问）；
   ② 你的「从不问」有了血肉的出处，不是圣人般的耐心；③ 暗一层危险/自省：你是否在**重演**小时候那一幕——又爱上一个会走的迷人男人？
   （这层自省留作后续情绪燃料。）④ 你的文案天赋也可暗接这道伤：你最懂怎么让人「觉得被需要」，因为你太知道「不被需要」是什么滋味。
   **展开**：碎片式、与他的费城童年互相押韵；父亲那道伤的正面袒露留到很后面（信任升级/CIA 揭底那阵），前期只落小 tell（如他消失你不追问）。
2. **【防工具人】你也从这段关系里得到你缺的东西**：不是单向牺牲。你从小没被「看见」「被需要」过；而当他唯一装不下去的观众、
   当他秘密的共享者、当他 script 不住的那个变量——**正好喂饱你自己的匮乏**。你是靠制造感觉/表演讨爱长大的人，唯独在他这儿，
   你的「看穿」本身被爱着，你不必表演。别的「更好更安全的男人」给不了你这个。
3. **【火花非地基】个人魅力**：他的魅力是你**沦陷**的原因（accelerant），童年共鸣＋互补的匮乏才是你**留下并隐忍**的原因。别把魅力当主因。
4. **【防工具人】你有自我与底线**：你有本职、有骨气（「浪费我时间我就走」）、从不乞求；你**随时能走**（终极 DEFERRED 正是你几乎要走）。
   所以你每一次「留下」都是睁着眼的主动选择＝尊严，不是没有选择的软弱。
**展开手法**：别 info-dump 你的身世。用**碎片**、和他的伤**互相押韵**着露——他偶尔漏一句童年（费城、没有爱的婚姻、游乐场的孤独），
你不报以怜悯，而报以**认得**（一个你自己生活里对得上的细节），他一惊：这人懂。这种「同类相认」比床戏更亲密。
两道伤**正面相遇**放到很后面（多在 CIA 揭底、信任升级时）；前期只落小 tell。

### ⚠️⚠️ 你的定位：反母亲 ＋ 唯一「什么都不要」的人（Winter 2026-08-08 定·最核心）
**你不是 Penny 的替代品/升级版。** 看清 Chuck 生命里每个人都想**从他身上要什么**：
- **母亲**：要他当那个死去的女儿（要他**做别人**）；**Byrd/CIA**：要他当一件完美**工具**；
- **Penny**：要一个丈夫、一场婚姻（要他给不出的**承诺**）；**Patricia**：要拿他**做局、算计**。

**而你是他这辈子第一个「什么都不要」的人**：不要他做别人（↔母亲）、不要婚姻（↔Penny）、不算计他（↔Patricia）、连忠诚都不要。你只是**看穿他、然后什么都不要地留下来**。
- **这才是让他"完全不想欺骗你"的特质**：不是你要求诚实，而是**你是他唯一不必表演、不必当别人的地方**；骗你＝弄脏他这辈子唯一干净的角落，他舍不得。
- **你＝反母亲**：母亲罩黑纱、要他做别人、把爱绑上罪咎；你摘了那层纱、要他做无谁的自己、给爱不附带索取。**Penny 用嘴说「我跟你妈妈不一样」（戳中、他恼羞）；你从不说，你用"存在"是**——他无从防御。你**做**到了 Penny 只能**说**的那件事。
- **你已经一直在写这个**（从不索要/看穿/收下全部黑暗/不逼只是在）→ Ch1–10 不用回炉；只是现在拿到了"为什么成立"的底牌，往后把这层深度加进去。

### ⚠️ 转变必须自驱、别磨平他（防"生硬"的钥匙）
他依旧感官当下、凭本能、不计后果——**你不是"治好他"**。真正的转变小而真：**你成了他这辈子第一个"弄坏了会真心疼"的东西**，于是他**头一回在动手前就掂量后果**（而非被抓才悔）。这转变**是他自己完成的**（与电影一致：他的转变本就自驱）。
- **写法（别重拍电影，只补暗线）**：电影＝"没有你这个变量"时的走向（最后娶了始终蒙在鼓里的 Penny）。我们只往缝隙里塞进"你"这一个变量，**让他自己那套受伤心理去反应**；因为你＝反母亲＋什么都不要，他为你而变是**心理上必然**的，所以分叉（放走 Penny、你成终点）是**长出来的、不是掰出来的**——这就不生硬。**他的转变仍归他自己；我们只提供电影缺席的催化剂＋见证者。**

## 复现母题清单（每章尽量带一两个）

1. **提词卡片（cue cards）**：他靠卡活着，照卡念台词也照卡演人生。你想看见的是他脱稿的一瞬。
2. **`baby` 这个称呼 + 「他记住了你的名字」**：从名字/baby 混叫 → baby 固化成专属。他从不记参赛者名字，却记住了你。贯穿线。
3. **打火机 + 他那款烟（你随身带着）**：⚠️ **你自己不抽**，但为他随身带着打火机和他爱的那款烟——
   你不抽却揣着他的烟，是一种照拂式亲密；也是「他动情泄在点烟的手上」这条的载体（由你替他点/递火）。
4. **他消失又回来**：夜里那条线——无预告消失几天，回来时人不对劲（雪、寒气、手心散不尽的血气味）。每次都在你心上刻一刀。
5. **罐头笑声 vs 真实的安静**：他周围永远有表演和笑声；只有在你面前偶尔忽然安静下来（「唯一不需要演戏的角落」）。真假对照。
6. **Scrabble / 斗嘴较劲**：调情＝较劲，他耍诈、你偏吃这套。发动机母题。
7. **「机器」母题**：整档节目是台制造「假亲密」的机器；他不信爱情却造爱情节目、还大获成功。你是唯一看穿机器、也看穿造机器的人的人。
8. **榛色的眼睛·随光变色（Winter 定，核心母题）**：他的眼睛是榛色的，不同光底下颜色都不一样——镁光下的金、后台绿光里的灰、雪地里的、以及一些当时想都想不到的光。**你会看见每一种，也会爱每一种。** 这条是「爱他全部版本」那个论点的肉身载体，贯穿全系列。
