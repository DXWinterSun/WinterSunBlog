# 《三件套的私人谢幕》创作笔记

- 状态：待 Winter 审阅；未发布、未进入正式连续性。
- 定位：未来订婚期炽恋 Extra；Justin 以蓝灰色三件套、条纹领带、红色口袋巾和方框眼镜出席哈默工业发布会，Winter 穿深红色露背高开衩长裙陪同。
- 前半场：公开场合的吃醋与延迟满足。旁人看 Winter、与她交谈，Justin 不断用“未婚妻”、戒指和腰间的手宣示关系；Winter 通过整理领带、耳语、第一排换腿、侧厅触摸又停下等方式悄悄撩拨，却坚持让他保留整套衣服到独处。
- 后半场：私人休息室的逐层剥离。规则为 Justin 不准自己脱、不准擅自碰 Winter；违反一次就重新扣回刚解开的扣子。顺序：麦克风与口袋巾 → 外套 → 袖扣 → 领带只松不摘 → 马甲 → 衬衫 → 皮带、西裤、鞋袜与内裤 → 最后摘眼镜。
- 核心视觉：Winter 始终穿着红裙与高跟鞋，Justin 最终全裸，只剩领带和眼镜；两人在镜前形成“公开场合的完整包装／私下被她拆开”的反差。成人场面明确自愿，Justin 在得到允许后才触碰她。
- 情绪落点：他因所有人都看她而吃醋，Winter 明确告诉他自己一整晚都只在看他。摘眼镜后从“全世界的哈默先生”落回“你的J”；她既喜欢他穿三件套的表演，也喜欢亲手拆开以后真正的他。
- 结尾生活感：Justin 要求红裙以后只用于“私人活动，一名受邀嘉宾”；Winter 替全裸的他重新戴上眼镜，欣赏三件套被完整剥离后的成果。
