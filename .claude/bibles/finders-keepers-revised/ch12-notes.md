**这一章做了什么**：一个礼拜三的早上，你注意到他每天天不亮就回林子里那半截露营车“看看它们还好不好”（还没回家的三个摆件），再走回来**站在门廊上敲门**——哪怕前一晚睡在你床上、枕头就在楼上，他还是每天早上等你来开门，好像每天都要重新被请一回（“没人请，就不能进人家的院子”）→ 你开着外婆的旧别克去邮局旁边的五金铺配了一把钥匙（“一块钱。”）→ 第二天天刚亮你坐在台阶上等他 → 钥匙放进他手心、替他把手指合上：“以后不用敲门了。”**“Buck，搬进来吧。住在这儿，跟我一起。”**→ 他摊开又合上，怕它不见：“……这个是我的？”“**Finders keepers？**”——**“不是捡的，是我给你的。”**（他这辈子身上的东西全是捡的、借的、“修一修”拿回去的，这是第一样有人亲手递给他、让他留着的）→ 钥匙穿上皮绳、挂在 MOONPIE'S 瓶盖牌子旁边，叮的一声 → 冲到草坪正中间冲摆件喊“Dolly！Porter！我住这儿了！”（对门窗帘唰地拉开）→ 抱起你在门廊上转圈 → 蹲在门口一遍一遍开锁上锁，听那声咔哒 →
搬家一下午：枕头、狗食盆、摔跤杂志、天线缠铝箔的小电视（**“这回插的电是真的，不是借的。”**）、你画的那几张像（卷好揣怀里谁都不许碰）→ **一只旧雪茄盒**，盖子上钉子划的几道，“这个我自己拿。”（月光盒第一次露面，你没问）→
阁楼腾地方，帽盒底下压着外婆的**蓝布面本子**（c-note 卡片，署名 Opal Harmon）：1979 夏光脚戴浣熊皮帽的七八岁孩子蹲篱笆外看小矮人 / 1980 夏 Hank 不见了、留一根松鸦蓝羽毛“随他去吧，他会还的” / 1983 “没人请，不能进人家的院子”，第二天夜里 Lucille 不见了 / 1987 蓝盘子里的饼干，底下压一颗很圆的石头 / 1995 春“镇上都叫他 Kid……我请过他好几回进屋，他一回也没进来。**也许哪天会有一个人，他肯进她的门。**”→ 你念不下去；他帽子尾巴垂着：“她每个礼拜天都留……我每回都还她一样东西。”“你为什么不进去？”**“那不是我的门。”**——拎起皮绳上的钥匙：**“这个是。”**→
傍晚你把蓝边缺角的瓷盘洗净摆回门廊小桌，放一盘饼干。“我已经住进来了，你不用留了。”“我知道。我就是想留。”——他拿一块饼干，在盘子底下压了一根**松鸦的蓝羽毛**（接外婆本子里 Hank 那一条）→ 那夜他没回林子，第二天早上床的另一半没空，钥匙硌着你的锁骨 → **那天早上，没有人敲门。**

**你要的**：“当然和我住在一起！”——这一章就是你正式让他住进房子里。结局岔路你挑了 **C 两边都是家**：他住进白房子，林子里那半截车也还是你们的（本章他每天早上还回去看摆件、那夜“没有回林子”都给 C 留了口子，第十三章展开“小河就是走廊”）。月光盒挑了 **A 什么都没有**，但他真心相信里面是月光，你也依着他——本章只让盒子露个面、他自己抱着不给碰，第十四章再开。

**回收**：第二章“没人请，就不能进人家的院子。Harmon 太太说的”（→ 外婆本子 1983，和“那不是我的门 / 这个是”）；门廊上那只蓝边缺角的空瓷盘（你收进了厨房 → 本章摆回去）；他一提 Harmon 太太就垂尾巴、在外婆厨房门口那一阵安静（→ 她请过他好几回，他一回没进）；Hank 借得最早（→ 1980）；Lucille 回家（第五章）；“偷电是借，电又不会少”（第九章 → “这回插的电是真的”）；MOONPIE'S 瓶盖牌子（第十一章 → 钥匙挂在它旁边）；Finders keepers（第一章起 → “不是捡的，是我给你的”）。

**本章改变了原路线图**：原来第十二章是“Hank 最后一个回家 + 外婆的本子”，现在外婆的本子提前到搬家这天从阁楼翻出来，**Hank 挪到第十三章**最后一个回家（还没回家的：蘑菇、抱水罐的小女孩、Hank）。外婆的本子里原先设想的那句“林子里那个孩子又来借我的小矮人了”改写成了分年份的五条，意思不变。

**小处理**：配钥匙的价钱写“一块钱”（1996 年五金铺配一把门钥匙大约一块钱上下，原稿的“两毛五”太便宜，改了）；钥匙“它”——东西用“它”，没问题；“看看它们还好不好”指石膏摆件，也用“它”。
