## 二、四条铁规矩（Winter 2026-09-27 定，每章必守）

1. **逐章重写，剧情和名场面台词全保留**，每章铺成完整热闹的场景，正文约 4500–6500 字。不是润色，是重写。
2. **章首放一件「小物件」**（题词之后、第一个小节之前），组件见 CLAUDE.md 卡片一节：
   `c-cassette` 卡带标签 / `c-fridge` 冰箱门便利贴 / `c-flyer` 演出传单 / `c-polaroid` 拍立得（画框里用一两句写画面，底下手写一行）/
   必要时 `c-note` 手写字条。标签、传单上的字可以写英文原文（实物上的字），便利贴写中文。**每章的物件要长在这章的剧情里**，
   像是这章留下来的纪念物（谁写的、为什么写，读者读完这章会会心一笑）。
3. **严禁回望式旁白**：「你没看见」「你不知道」「后来才知道 / 后来才明白」「很多年以后」「那时候你还不知道」「你怎么会知道」
   一律不写（Winter：「没有沉浸感」）。「你」看不到、不知道的事就不写。要泄露 Rob 的心意，只能用：
   ①「你」撞见了、但读错了；② 旁人一句话带出来（样板：Ch2 你谢 Jack 送蜂蜜水，Jack 愣一下拖长音「……不客气？」）；
   ③ 他的动作被「你」看见（按错弦、耳根红、手按着谱纸很用力）。结尾收束引语 3 行左右，停在当下，不预言未来。
   ⚠️ 旧版几乎每章都有这类句子（「你没回头。所以你没看见——」），重写时全部换掉。
4. **多写外貌穿搭**：每个场景 Rob、Jack、「你」、男孩们各穿什么，具体到颜色、料子、磨损、配饰、头发。每章都换，别重复上一章。

## 三、其他全站规矩（CLAUDE.md 全文适用，最容易错的列在这）

- 第二人称「你」= Winter Delaney。正文引号用弯引号 “ ” / 内层 ‘ ’。
- 1994–96 美国加州圣克鲁兹，全员说英语，中文是译文：不写「他用英文说」，不数汉字（「那三个字」）。
- 去中式：没有筷子碗、没有中式成语典故气味的器物；度量用英里、英尺、磅、点钟。
- 正文不 cue 章节（「上一章」）。人物不预支后文才发生的事。记忆不按日期调取。
- 称呼：你俩互称 C / D（Ch6 海边之后才有带刺的 C/D，**之前的章别用**），他叫你 princess；日常 Rob，吵架撒娇才 Robert；
  Brody 叫你 Winnie（只有他）。
- **腕带 ≠ 皮筋**：信物永远是运动腕带（毛巾料），你扎头发用的就是腕带本身。你自己那根白色、印蓝色香蕉蛞蝓；Rob 每天手腕上套一根（旧文从旧 Ch8 起：你忘带，他扔给你；你每次都还）。
- **炽恋章**按 CLAUDE.md「完全吃爽」档写，直白实写，同时守声口（Rob 越紧张越话痨、贫嘴全用来哄你）与情感落点。成年自愿。
- 歌词：英文原句 + 中文翻译并列，放 `>` 引用块，只引几行。歌都是 CD 自己写的原创歌，**绝不说「翻唱」**。
- 结尾收束引语：3–6 短行，每行行尾两个空格。

`chN.md`：

```
---
title: "Chapter N · 中文章名 — Everything in Transit"
summary: "≤35 个汉字的钩子，内部不许出现 ASCII 双引号"
tags: [Rob Cove, Sam Rockwell, AU, Everything in Transit, mood1, mood2]
version: v2 草稿（2026-09-27）
---

> 题词 2–3 行，行尾两个空格  

<小物件 HTML>

### 小节标题
正文……

> 收束 3–6 行，行尾两个空格
```

`chN-notes.md`：给 Winter 看的说明（中文、说人话、别用术语）：这章保留了什么、新加了什么热闹 / 穿搭 / 小物件、
删了哪些回望句、有没有改章名（为什么）、**自己发挥了什么**（这条最重要，要汇总进给她的报告）。
小节用 `### `，条目用 `· ` 开头各占一段（预览脚本不支持 `- ` 列表）。

写完每章跑：`python3 tools/check_desino.py <文件>`，再 `grep -n "没看见\|不知道\|后来\|很多年\|才明白\|才知道\|个字\|眼镜\|皮筋\|英文\|中文" <文件>` 逐条自查。
