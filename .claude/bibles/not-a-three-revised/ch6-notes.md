**这一章做了什么**：天黑，Riptide 院子里挤满了人：Trent 翻一个肉饼讲一个笑话，Kip 每个都笑；Betty 坐在两家门廊中间的栏杆上给每个人起外号；Joan 一条白裙子，转到哪里哪里就有人回头 → 妈妈端着土豆沙拉跑了一晚上，经过你身边停了一下，好像想起了什么——“Pam！番茄酱！” → 你坐在台阶最下面一级，口袋里揣着那卷硬币，Peter 隔着一拳坐在旁边 → Connor 拿着两只手电和一个空罐子：去抓鬼蟹（白的，跑得快，手电一照就僵住，像被抓了现行）；Peter 去年三只、今年要十二只 → 你没跑，关了手电蹲着等，照住一只，跟它对峙；Connor：“你今天去哪儿了？图书馆今天放假。”“你今天好像……挺高兴的。”“没有。”“有一点。” → 他爸每年独立日和圣诞打两次电话，“他连我生日是哪天都记不住”；你爸在别的州，有了新的一家，“今年还没打”——你没说今天他最应该打 → “那我们俩差不多。”你没告诉他，至少他爸还记得独立日 → 九点半，车库那箱烟花在海滩上点起来；你转身往镇子那头看，漂流河方向几支稀稀拉拉的小烟花，一支歪着飞出去，一支炸得像打了一半的喷嚏；你认认真真比了一下：比去年高，你决定了，反正你没见过去年的 → 回屋给 Peter 拿大罐子，绕到房子侧面，户外淋浴的木隔板后面——白的那支烟花一亮，Joan 的白裙子、Trent 搭在她腰上的手；绿的那支一亮，他越过她的肩膀看见了你 → Joan 低头快步绕开 → “你在这儿干什么？回海滩上去。”“Winter。你什么都没看见。听见没有？”你一个字都没说，像拿手电照着那只鬼蟹一样看着他 → 他先移开了眼睛，低头理衬衫下摆 → 你从他旁边走过去，拿罐子，再从他旁边走回去 → 从那一晚起，他看你的眼神变了：不是打分，是在算你什么时候会开口 → 快十二点，窗台上防晒霜旁边那卷硬币，纸卷一点没拆 → 妈妈敲门，一个超市的纸杯蛋糕，红蓝糖粒、独立日特供，一根点着的蜡烛：“对不起。晚了。”“十六岁了。” → 那句话就在你嘴边；你看着她笑得很累很小心，像怕笑大了这一天又会被她弄砸——你咽回去了 → 许愿（没告诉任何人），吹灭 → “你晒黑了。”“嗯。”她没问你去了哪儿 → “生日快乐，Winter。” → 蜡烛擦干净，放进防晒霜的盒子，跟那张纸条放在一起。

**你挑的三样**：没告诉 Connor（他爸起码记得独立日，你爸今年还没打——那句“我们俩差不多”你没接）；让 Trent 知道你看见了（你一个字都没说，用的还是你那一套：不吵，不躲，看着他，等他先移开眼睛）；那卷硬币一枚没花，纸卷都没拆。

**原片对照**：鬼蟹、两个孩子聊各自缺席的爸爸、Duncan 撞见 Trent 和 Joan 接吻，都是原片七月四号那一夜的事。改的是：原片里 Duncan 只是看见了；这里你让他知道了。

**Owen**：这一章他不在场，只在镇子那头放了几支歪歪扭扭的烟花。你替他看了一眼，“比去年高”。

**埋下的钩子**：
① “比去年高”——你替他看的那一眼 → 下一章你会不会告诉他；
② Trent 知道你知道了 → 他在算你什么时候开口；当众翻脸那一章；
③ 你没告诉妈妈 → 那句话最后是当着所有人说出来的（原片那一场）；
④ 你的生日愿望，没告诉任何人 → 十八岁那天才揭开；
⑤ 防晒霜的盒子里现在有两样东西：他的纸条、妈妈的蜡烛 → 一直带着；
⑥ 你爸“今年还没打” → Trent 后来那句“你爸不要你”；
⑦ Connor 说“你今天好像挺高兴的” → 他看得出你在别处有个让你高兴的地方。

**语言自查**：七月四号全部改叫“独立日”；“一个字都没说”是成语式的说法，不是在数字。

**标题备选**：主推《他先移开了眼睛》（这一章最要紧的那一下，过多久都记得是撞见 Trent 的那一夜）；另一个候选《对不起，晚了》（妈妈半夜那一句）。
