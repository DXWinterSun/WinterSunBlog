**这一章做了什么**：隔壁的 Connor 每晚在门廊上弹《Hey There Delilah》，每次都错在第三句；第一晚你没在意，第二晚你把枕头压在脸上 → 早饭，妈妈开了个头“四号那天，Winter——”，被 Trent 的派对盖过去（Kip、Joan、Betty 一家，车库里那箱烟花拿去海滩放，“不许再去什么图书馆”）；妈妈把煎蛋切成很小的块，一块也没吃；你知道那句话后面是什么，没提醒她 → 乐园午休，他往嘴里扔爆米花一颗不失手：七月四号乐园不开，他们几个在漂流河边自己放，Roddy 去年烧了半边眉毛；“我热爱派对，我只是讨厌别人的派对”；“替我看一眼烟花，看看它们有没有比去年的高” → 你没告诉他那天还是什么日子；Caitlin 的蓝色文件夹压在一摞排班表底下 → 傍晚院子里烤肉，Betty 当着一院子大人笑 Peter 胆子比老鼠还小；你什么也没对她说，只说“Peter，走，带你去看个东西”，领他下海滩看礁石缝里的小螃蟹 → “我不是胆小。”“我知道。”“你怕什么？”“很多东西。”→ 从那天起 Peter 黏上你 → 天黑，Joan 的手搭在 Trent 胳膊上，比别人多了半秒；你看人一向看得清，像看那几只鬼怎么走；妈妈在给 Kip 倒酒 → 夜里第三句又歪了，你推开窗：“第三句那个和弦，错了。”“你会弹？”“不会。我会听。”他换了三次按法，对了 → “你是纽约来的？”“Albany。”“那也算纽约，这首歌里那个姑娘就在纽约。”“不是。”（纽约不是个特别好的地方）→ 他爸前年去了佛罗里达，他想去波士顿念音乐 → “镇上的图书馆星期二不开门。”你没说话，他也没再问：“那你明天还去图书馆？”“嗯。”“行。”——Connor 是个好男孩，是真的好 → Peter 蜷在隔壁的秋千上睡着了 → 他又弹了一遍，第三句特意按得很稳，抬头看你的窗户；你已经关了窗，却靠在窗边一直听到他弹完。

**你挑的三样**：Connor 是因为吉他才说上话的（他是真的好，你没选他，那个选择才有分量）；Peter 黏上你——你不替自己吵，可你会替他，用的还是你那一套：不顶嘴，直接把人领走；妈妈的那句话被派对盖过去了，第五章她半夜才补上。

**Owen**：只在午休露一面，照旧把你当乐园里的小员工；“替我看一眼烟花”是随口一句，他不知道那天是你生日。收束那几行点了一下：你一整晚想着的，是谁让你替他看一眼烟花——这是你那边的心事，他那边什么都没有。

**埋下的钩子**：
① 妈妈没说完的“四号那天，Winter——”→ 第五章半夜的纸杯蛋糕；
② “替我看一眼烟花，看看它们有没有比去年的高”→ 第五章你真的替他看了；十八岁那天的烟花；
③ Joan 的手多了半秒 → 第五章你撞见；
④ Connor 想去波士顿念音乐、还没跟谁说过 → 他的那条线，临走那天的拥抱；
⑤ Peter 问你怕什么，你说“很多东西”→ 以后由他问回来；
⑥ Connor 知道你没去图书馆，没问 → 他替你守着；
⑦ 蓝色文件夹还压在排班表底下 → 第五章、第六章之间他翻到。

**语言自查**：歌名照原名；没有引歌词。“行。”那里说“就这一个字”——翻回英文是 Okay，也是一个词，成立。“大人”是成年人的意思。

**标题备选**：主推《第三句那个和弦，错了》（你对 Connor 说的第一句话，这章就是你们俩怎么说上话的）；另一个候选《替我看一眼烟花》。
