**这一章做了什么**：早饭桌上“图书馆”“又是图书馆”“看什么”“书”，妈妈多放了一片吐司 → 九点不到，他坐在售票亭台阶上捧着咖啡，盯着你的鼻子：比消防栓还红，“作为经理，我不能容忍有员工抢消防栓的风头” → 扔给你一瓶防晒霜，SPF 50，“职业素养，本园员工不许晒成龙虾，影响园容，每两个钟头抹一次，我会检查”“你检查不过来”“我会派 Roddy 检查”“我不去！” → 瓶身上还贴着镇上药店的价签，封口锡纸都没撕；昨晚那瓶芦荟胶管的是晒伤了以后，这一瓶管的是明天 → 午休，小卖部后头的游戏厅：弹球机、Galaga、《街头霸王 II》 → 你把硬币放在面板边上排下一局；“女生不会打这个，抓娃娃机在门口” → 你站上一号的位置，选了整台机器里唯一的女生春丽 → 连赢五局，你一句话没说；打游戏的时候心里那块吵的地方会安静下来，“血槽是公平的” → 门口挤满了人，Roddy 叼着哨子踮脚看 → 喇叭一响：“本园游戏厅目前正在发生一起屠杀事件，请家长捂住孩子的眼睛……现在仍然站在台上的，是——Player One。” → 他举手等你击掌，你从他旁边走过去；他自己跟自己击了个掌，“欠我一个” → “在哪儿练的？”“家里。”“跟谁打？”“机器。”他安静得不像他，然后说：机器从来不让着你，也从来不说你不行；马上转头冲 Roddy 喊话岔开 → 下午每条广播后面都多一句 Player One，最后一条是“Player One，抹防晒”；你假装没听见，还是两个钟头抹了一次 → 回家：“图书馆怎么样？”“安静。”这不算撒谎 → 防晒霜放在窗台上，被夕阳照成橙色 → 一号，比三分好拿多了。

**你挑的三样都照办了**：游戏厅里没有 Connor（他留到下一章两个门廊之间）；他还不知道三分，那句“机器从来不说你不行”是他凭你一句“跟机器”猜到了一点，什么都没问；家里照旧以为你在图书馆。

**防晒（你加的）**：他的关心全裹在玩笑里（消防栓、龙虾、影响园容、派 Roddy 检查），真心只从药店价签和没撕的锡纸里漏出来，他自己一个字都不认。这是一个经理给一个晒伤了的小员工的东西，这一章里没有别的意思。

**Owen**：还是把你当一个会打游戏的孩子，乐坏了，替你喊。他看你的方式没变；变的只是你听他广播时会停一下手。

**埋下的钩子**：
① 那瓶防晒霜（他的第一件礼物）→ 一路带着；十八岁那年夏天你回来时，包里装的是同一个牌子；
② 他举着手等你击掌，你没拍，“欠我一个” → 留着，最后一天或十八岁那天还给他；
③ “在哪儿练的？”“跟机器。”→ 乐园那一夜，他才知道“家里”是什么样的家；
④ “Player One，抹防晒”成了他广播的固定一句 → 广播是他跟你说话的方式。

**语言自查**：SPF 50 是瓶子上的字；Player One 是称呼，照写；《街头霸王 II》用中文通行译名。气温写华氏八十九度（美国的说法）。
