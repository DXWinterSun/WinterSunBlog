**这一章做了什么**：手电的光从泳圈架子缝里扫进来，停在你的帆布鞋上，灭了 → 他绕过架子，没说话，叹了口气，背靠着墙挨着你坐下，慢得像膝盖不好的老头 → “这是本园最好的躲藏点。很多年前，我也在这儿躲过。”“缺点是有一股橡胶味，还有一点 Roddy 的脚味。”你没笑，他就不说了 → 很久以后：“派对上的蛋糕还剩一块，我给你留着了。……好吧，我吃了一半。” → “我不想回去。”他没问为什么：“那就不回去。今天晚上。” → “在披萨店那天，你打了三关，我在旁边一直看着。红的你吃了，粉的你吃了，蓝的也吃了。橙的那只，你一次都没吃。它离你远的时候就追过来，一挨近你就掉头跑。你每次都放它走。”没有墨镜，没有笑话：“你也是。” → 这个夏天咽下去的全涌上来：三分、四点前到齐、这不是在问你、图书馆、别听孩子瞎说、妈妈的对不起、他不要你；还有更早的好几年，旅行车最后一排 → 你哭了，来不及把脸放平；他愣了一下，伸出一只胳膊，有点笨、有点犹豫，像怕碰坏什么，把你揽过去；花衬衫上有氯水、太阳和蛋糕奶油的味道 → 他没说别哭了，没讲大道理，一只手在你背上拍，拍得很笨、节奏都不对，“好了，好了”，说了很多遍，一点用都没有 → 你哭得像一个终于找到了人的、走丢的孩子 → 一张披萨店的皱餐巾纸，“可能擦过番茄酱”，真的有番茄酱味 → 你把整个夏天说给他听；说到“你自己几分”，他没忍住笑了一声：“你真这么问了？当着一桌子人？天哪，Player One。”——全是骄傲 → 说到“他不要你”，他不笑了，下巴绷了很久 → “我爸是那种什么事都有个标准的人……每一样都有个分。我长到十七岁，没有一天是及格的。后来我就跑了，跑到一个不看你几分、只看你开不开心的地方。就是这儿。” → “这世上有一种人，你一辈子都达不到他们的标准。不是你不行，是他们那把尺子本来就是做出来让你达不到的。所以别让那种人给你打分，Winter。他们没资格。”——这是他第一次正经叫你的名字 → “这是唯一一个没人给我打分的地方。”“这里本来就是干这个的。” → 他伸手拉你，你想起还欠他一个击掌，没拍，握住了 → “你得给你妈打个电话。不是告状，我不说你在哪儿，你也不用说。表格上电话那一栏你空着呢，所以这个电话得你自己打。” → 办公室里 Caitlin 攥着车钥匙一直没走，看见你的脸什么也没问，把电话推过来 → “我没事。我在一个朋友这儿。明天回去。”妈妈吸鼻子：“……好。你没事就好。” → Caitlin 放下车钥匙：“我今晚留下。”一条旧毯子丢在瘸腿沙发上 → 他坐在门口躺椅上值夜班；走进广播室，磁带咔嗒一声，整座空乐园的喇叭响起那首歌（Home is where I want to be）→ 他隔着纱门：“最出名的和最好的，不是一回事。”——你第一天在披萨店说的，他记得 → 你睡着了，这个夏天第一次睡得那么沉。

**你挑的两样**：就在泳圈架子后面（两个人缩在一堆泳圈后面）；他说破了橙色的那只鬼——在披萨店他就看见了，你从来不吃它。

**红线自查**：他抱你，是一个大人抱住一个哭坏了的孩子——有点笨、怕碰坏、节奏不对、只会说“好了”；他那边只有心疼和不知所措。之后他做的都是一个靠得住的大人该做的：让你给妈妈打电话报平安（不逼你说在哪儿），Caitlin 留下来陪你过夜，他在门外躺椅上值夜班。

**原片对照**：原片里 Duncan 在乐园过了一夜，告诉 Owen 这是唯一一个让他觉得被接纳的地方；Owen 讲了自己被管得很严的童年，让他做自己。这里加了：橙色的鬼、在他怀里哭（你定的）、“三分”在这一夜说出口（第三章你挑的）、那首歌、Caitlin 留下来。

**埋下的钩子**：
① 你握住了他的手，那个击掌还欠着 → 最后一天；
② “别让那种人给你打分。他们没资格。”→ 最后一天他见到 Trent，“我是三分的好朋友”；
③ 那首歌从整座空乐园的喇叭里放出来 → 十八岁那天；
④ 他第一次正经叫你 Winter → 十八岁那天他认出你时叫的是哪一个；
⑤ 你跟妈妈说“我在一个朋友这儿，明天回去”→ 她没追问，第二天；
⑥ 他十七岁从那个打分的家跑出来 → 你最后的决定：你不跑，你回去好好念书，用自己的办法离开。
