**这一章做了什么**：早饭桌上 Trent 宣布全家坐 Kip 借来的船出海，你说“我不去”，他说“这不是在问你”，你接着一勺一勺吃麦片 → Steph 说“她不去最好，省得我朋友以为她是我们家的”，你回了今年夏天的第一句：“放心。没人会以为我是你们家的。” → 妈妈小声求你“就今天，好不好，就当是帮我”；你没回答 → 你坐在门廊台阶上把一只鞋带系了拆、拆了系，Trent 按两回喇叭，“随她去！”；妈妈从车窗里回头看你一眼 → 骑车到 Water Wizz，钱只够一块披萨不够一张票，你趴在栏杆上往里看 → 广播里是披萨店那个声音：漂流河里洗头的先生，以及“东侧栏杆外停着一辆非常有品位的粉色自行车”；你把脸放平转身就走 → 侧门铁链一响：“专家。我认得那辆车。” → 员工侧门「员工专用 / 包括 Owen」；他带你逛：漂流河十一分钟、造浪池抓紧你的人生选择、“Winter，夏天最热的地方来了个叫 Winter 的，我喜欢你父母”（你不接话）；Roddy 吹哨吹出了个人风格；Lewis 什么都不喜欢，“尤其是你” → 魔鬼峰底下一群男孩在吵那个超车传说，Owen：“经理不参与传说，经理负责维护传说” → 办公室，Caitlin“你又迟到了”；“我们没在招人”“我们现在在招了”；她那一眼不是 Steph 的扫法；最小号的员工 T 恤，你要了最大号，她什么也没问就换了 → 填表：十六岁，生日七月四号，电话空着；表格夹进蓝色文件夹 → “你会干什么？”“……打游戏。”“完美，我们正好缺一个——”“Owen。”“——在滑道底下收泳圈的” → 一下午捞泳圈、扛泳圈，没有一个人看你；他每次广播，你都停一下手 → “明天见，专家。”“我还没说我明天来。”“你说了。你还穿着呢。” → 回家说去了图书馆，Trent 问怎么晒成这样，妈妈先开口替你圆了过去 → 枕头边一小瓶拧松了盖的芦荟胶 → 你穿着那件员工 T 恤睡了；那个三分好像坐得离你远了一点。

**你那股劲儿**：不吵、不顶，就是不去；十次不理 Steph，这一回只回一句。对妈妈：她求你，你不答应，可她回头那一眼、她替你圆的那句谎、那瓶芦荟胶，你全看见了。

**Owen**：这一章还是只把你当一个会打游戏、骑粉色小车的孩子；他叫你“专家”，外号要等下一章游戏厅那一场才有。Caitlin 看他的那一眼先露了一角（“对一个人无可奈何了很多年，却还愿意再无可奈何一次”），他看她的眼神留到第六章。

**埋下的钩子**：
① 表格上的生日七月四号，夹进了 Caitlin 的蓝色文件夹 → 七月四号那天他从这里知道；
② 电话那一栏你空着 → 他一直没有你家的电话（以后他要找你只能等你来）；
③ 魔鬼峰的超车传说，“经理负责维护传说” → 最后一天；
④ 你趴在栏杆上往里看、买不起票 → 十七岁那年你又一次隔着栏杆看；
⑤ 那瓶芦荟胶、妈妈替你圆的谎 → 妈妈那条线，最后她爬到最后一排；
⑥ 你那句“没人会以为我是你们家的”→ Steph 记仇。

**语言自查**：WATER WIZZ 招牌、员工 T 恤上的 WATER WIZZ STAFF、侧门上的「员工专用 / 包括 Owen」都是实物上的字（门上那两行用框角引号）。Roddy 和 Lewis 的介绍原本跟 Summer Never Ends 那边的梗撞了（出发的艺术、辞职信），已改。“面条”改成意大利面。

**标题备选**：主推《我认得那辆车》（侧门里他那一句，过多久都想得起这章是进乐园那天）；另一个候选《最小号，要最大号》。
