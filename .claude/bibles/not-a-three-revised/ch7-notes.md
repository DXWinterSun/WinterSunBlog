**这一章做了什么**：独立日过后第一天，他坐在高台台阶上替 Roddy 看哨子；你扛着泳圈从他身边经过，没停：“高。”“什么？”“烟花。比去年高。”——他在脑子里倒带，倒到“替我看一眼”，笑得差点从台阶上栽下去，哨子掉了；“你替我看了？”“你让我看的。”“本园将把这一条记入年度报告，标题是：比去年高。”“那一支歪了。”“那是 Roddy 点的。”“我听得见！”你没让他看见，你也在笑 → 三天后，Trent 先下手：早饭桌上只有你们三个，他给妈妈倒咖啡，“我昨天给镇上的图书馆打了个电话……他们说从来没见过”“你不觉得她撒谎撒得有点太顺了吗？” → 你全明白了：要辩解，就得交出乐园；要说那晚看见的事，在妈妈眼里就是一个刚被抓住撒谎的孩子往大人身上泼脏水——红的追你，粉的堵你 → “我没去图书馆。”“那你去哪儿了？”“外面。”“你看，她连解释都不解释。以后她出门得先跟我说去哪儿。” → 第二天你照样没说就走了；妈妈站在窗户后面，拦不住你，也拦不住他；那件事你更说不出口了 → 你在乐园待得越来越晚，Caitlin 走之前看你一眼，像要问又没问 → 七月最后一个礼拜的傍晚，漂流河不转了，河沿上坐着他和 Caitlin，鞋脱了、脚泡在水里，中间只有一罐汽水，你一口我一口，谁都没说话 → 你第一次见他不说话；她看天边最后那点光的时候，他看着她：很安静，很软，还有一点怕，像看一样很想要又觉得配不上的东西 → 他看你从来不是这样：是亮的、乐的、骄傲的，像看一个打赢五局街霸的小孩——那很好，可那不是这个 → 你知道那是对的：你十六岁，他是大人，Caitlin 等他长大等了那么多年 → 你还是在阴影里站了很久；Caitlin 把头靠在他肩上，他僵了一下，没动 → 你从侧门走了，没人看见 → 冰箱门上 Trent 贴的日历，八月十八号被红笔圈起来：「回 Albany」——还有三个礼拜。

**你挑的三样**：告诉他烟花“比去年高”（他笑得哨子都掉了）；闭园后分一罐汽水，你第一次见他不开玩笑；Trent 先下手，在妈妈面前说你撒谎——这样哪天你开口，妈妈也不会信。

**你说的“夏天快结束了”**：这一章收在冰箱门上那个红圈，八月十八号，还有三个礼拜。后面的夏天收紧成三章：当众翻脸 → 乐园那一夜 → 魔鬼峰和离开；然后直接接“两年后”，十七岁那几次隔着栏杆远远地看，并进两年后那一章里写，不单独成章。路线图已经改好。
