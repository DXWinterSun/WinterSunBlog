### Ch7《他跟你下山》约 5500 字 · 暗涌 · 缱绻

### 这章做了什么

- **Lester 的电话**：周四你接到 Lester 的电话——周一要去 Pittsburgh 签文件。你**没打电话**（他家电话他不接），你**提前**下班开上山
- **他说"我不去城里"**：你**没**追——你**懂**他为什么说这五个字——他不要让你看见他是不懂的那个人。你**给**他一个台阶："那我帮你带文件回来，你签。"
- **他说"我去"**：他沉默半分钟然后改口——他**不让你代他扮妻子角色**。你从他眼睛里看见他的改——你**懂**。你没让他看见你懂
- **周五傍晚你带新白衬衫上山**：你**没问他尺码**——你猜 16/34——你**不**让他开口说"我没有合适的衣服"
- **周五夜 "……我出去就跟不上"**：他第一次**口头承认**害怕。你**没**反驳。你走到他**旁边**（不是对面），你坐下，你**让他握住**你的手——第一次**正面**握（Ch4 Ch5 Ch6 都是背后 / 从后面——这次你正面给）
- **那夜床戏**：ritual 没变（从后面 + 脸埋枕头 + sweet thing + 你叫 John）但他**没**说"我好想你"（Ch6 之后的 convention）。他叫 sweet thing / good girl / pretty **一遍又一遍**，像在**抓**着什么——他**攒**他敢用的那些词
- **清晨他穿你买的白衬衫**：第一次穿**没**他家痕迹的衣服。他**没**问。他**没**解释。他**自己**穿上。你**没**说一句话
- **他第一次坐副驾驶**（他从没让自己不是开车的那个男人）——他让这件事发生
- **他看那块地在身后缩小 + 他的手在抖** —— 你从后视镜看见，没让他知道

### 声口样本（他本章的话）

- "city girl。今天周四。"（周四傍晚你提前到）
- "我不去城里。"（五个字一个句号）
- "我去。"（沉默半分钟后改口）
- "city girl。……我出去就跟不上。"（第一次口头承认害怕）
- "……sweet thing。" / "……good girl。" / "……pretty。"（床上一遍又一遍）
- **他本章没说**："我好想你" / "我害怕" / "谢谢你带的衬衫" / "我爱你"
