# 语言重理中发现的剧情逻辑疑点（待 Winter 拍板，2026-10-10）

## Ch7
1. 第二节「你周三走，说周三再来。今天是周四。你提前。」——Ch6 是周三上山、周四清晨才走；「周三再来」是 Ch5 周日说的；周四在周三之后不算「提前」。
2. 出发日子：Ch7 定「周一七点半出发、十点半到」「我周五来接你」，但第八节是周五夜、第九节清晨就出门（像周六）。Ch8 开头「下午两点」在 Lester 办公室、Lester 临别说「周一十点半银行门口等」，与 Ch7 电话「周一十点半我办公室签文件」冲突。
3. 第九节「他在刮胡子——第一次」，但 Ch4 他已刮过胡子。
4. 奶牛 Grace 的名字 Ch7 第一次出现（笔记说是 Ch5 伏笔，但 Ch5/6 原文没有）。
5. 第十节「你从后视镜里看见他握文件的手在抖」——他坐副驾驶，后视镜看不到。
6. 「他从没出过山 / 第一次离开那块地」vs Ch4 冰箱里有牛排白面包（总得去镇上买）。→ 理解为「第一次出远门」？

## Ch5
1. 第七节「他没睡——从你第二次结束之后就没睡」vs Ch4 他睡着说梦话、Ch5 第一节他睡梦里转过来抱你。
2. 第九节读起来像周六周日清晨他都说了「……我好想你」，与第十节、圣经「唯一一次说漏嘴」冲突。
3. 第十节「开门第一眼还是不看你」vs Ch4 他开门看了你很久。
4. （小）第八节吃完饭「走到那张歪桌子前」——就是饭桌。
5. （Ch6）「自从他说『我好想你』那夜之后」——其实是清晨。

## Ch10
1. 第三节「他把你从那把椅子上抱了起来」vs Ch9 结尾你们站在饭桌边。
2. 本章其实是周二上午（Moira 刚走），原稿第十节写「对着这个夜晚」，收束气氛像夜里。
3. 原收束「他第一次正对着你操」vs Ch8 已经正对过（旅馆）。本章真正的第一次是：在他自己床上、蒙眼的东西都在，他自己选择不用。（收束已去掉该句）
4. （小）第九节「额头抵在你肩上，像他哭的那一夜」——Ch4 他哭时额头抵你脊骨。
5. （小）第四节「第一次把它当成地板上的一块旧抹布」——Ch4 已经「像扔一块烂抹布」。
6. 「昨天在旅馆窗边」取决于 Ch7–9 日历。
7. （Ch9）Moira「上楼」「二楼」「木楼梯」——拖车房是单层。Moira 进卧室却没看见地板上那件白衬衫。

## Ch6
1. 梳子原处：第五节「原本搁在他的床头柜上」，但你在他床上睡了三晚从没见过；第八节又说他「头一回把它从她的位置挪到你们的位置」（他自己床头柜）。
2. Ch7、Ch10 说「像他给你梳头那个清晨」——梳头是晚上。（Ch7/Ch10 重理时已各自改顺）
3. 第十一节「第一次只是抱着你」vs Ch5 第七节炉灶边从后面环腰贴后颈。
4. （低）第一节方案「已经做完了」，五、六节你又在「改方案」。
5. （记录）你的头发写成「浅栗色」，圣经未记。

## Ch8
1. 日子（最要紧，和 Ch7 #2 同一件事）：下午两点 Lester 办公室 vs Ch7 电话「周一十点半我办公室」；Lester 又说「周一十点半银行门口等你们」；第十五节「你没问『周一不是明天』」「十一点的车」；Ch9 开头「周一下午四点回来」。建议按 Ch9 理顺：周日下午见 Lester → 周日夜旅馆 → 周一十点半银行 → 十一点动身 → 下午四点到家。
2. 他穿「你周五给他买的那件白 T 恤」——Ch7 你买的是白衬衫。
3. 第十五节「你那张床，你和他一夜睡的那张」——第十节你们睡的是他那张靠门的床。
4. 第十一节「像那夜他哭的那一回」脸埋颈窝——Ch4 他哭时额头抵脊骨。
5. 「廉价旅馆的地毯」vs 你挑的是中档 Hampton Inn；「没地毯吸着」vs 房间铺着绿地毯。
6. Lester 叫他「Moon 先生」= 英文的 Mr. Moon，而圣经说这是只有你会叫的称呼（Ch7 同）。

## Ch11
1. 第三节时间：十一月末五点半「天还没完全黑」、夕阳金色，平时「不是八点、七点」才开灯——阿巴拉契亚十一月末不到五点就日落。
2. 第一节 Moira 拿走的东西（粉猪书、浅蓝小毯子、塑料小马）vs Ch9（旧首饰盒、Nolan 小毛衣、粉猪书，翻的是他卧室抽屉）。
3. 第十一节「他送你 Pittsburgh 旅馆那件灰 T 恤」——灰 T 恤是他家旧的，Ch4 起你一直穿。
4. 第十二节「也不是在他舌头上尝的那一下」——指旧设定里 Ch4 他私下念 Winter，现在 Ch4 定为梦里念 Moira，这一下已不存在。
5. 第十一节「你第一次让他看见你哭」——Ch9/Ch10 他看见过你红了的眼睛。（暂写「第一次这样让他看见」）
6. （小）「他没煎糊自己那块了」——以前糊的是煎蛋不是牛排；第十三节「一直睁着眼看着你」但中间下颌抵锁骨看不见脸。
