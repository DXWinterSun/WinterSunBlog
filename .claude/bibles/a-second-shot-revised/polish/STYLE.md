# A Second Shot · 语言重理的尺子（2026-10-10）

Winter 原话：「整体的布局还有内容的张力我都很喜欢，但是……写着写着就开始放飞自我了，然后就是非常破碎。
我想让你把他的语言重新理一下，但是情节安排不要去变化。」
看完 Ch4 样稿后她定：**力度 B**（床戏最要命的两三处留一点喘不上气的短句，其余照样稿）；
「你都改吧，我信你的。如果有剧情逻辑问题你可以跟我确认，其他的就不用了。」

**样板**：`polish/ch4.md`（她已认可）。动笔前先把原稿 `_posts/…chapter-4…` 和它对照读一遍，
再读 Ch1 原稿（Ch1 本来就干净，是节奏的尺子）。

## 不许动的

- **情节、台词、动作、转折、意象、母题，一个不动，顺序也不动。** 他说的每一句话原样保留（只把引号换成弯引号）；
  你叫他的每一声 John / Mr. Moon、他叫你的每一声 city girl / sweet thing / good girl / pretty / baby，位置不动。
- 卡片组件（`<div class="c-note">` 之类的裸 HTML）原样保留。
- 小节标题 `### 一` `### 二`……保留；跳号的补齐。
- 文首题词、文末收束引语保留（收束引语可以收短到 3–6 行，每行行尾两个空格）。

## 要改的

1. **碎句接回完整的句子。** 「他——／他的手——／他的手抓住你的腰——」→「他的手抓住你的腰。」
   段落可以短（一句一段没问题），但每一段都要是完整的句子，不是半截。
2. **加粗：全章 0–3 处**，最好是 0。
3. **行尾破折号「——」基本清零。** 句中的破折号少量保留（一段最多一处）；对白里被打断的那种可以留（“John——”）。
4. **对白别再用 `> **“……”**` 引用块加粗包装**，写成普通对白段落。
5. **同一个意思连说三四遍的，留最准的一遍。** 「你懂了。你懂了。你懂了他……」→ 一遍。排比最多三项。
   心理解释（他为什么这样、你懂他什么）只说一次、说清楚，不要每个动作后面都再解释一轮。
6. **设定讨论用语清出正文**：ritual → 他那一套 / 那个仪式 / 幻觉；crack → 裂开 / 松动；kink → 那点羞耻的快感；
   工具认知 → 删，或「把你当成一件东西」；slip → 说漏嘴；payoff / insight 等一律不出现。
   正文里**除了人名和称呼，不出现英文词**（城里人设的少量专有名词如 Pittsburgh、Lester 照旧）。
7. **力度 B**：每章最要命的两三处（高潮那一下、最重的那声称呼、哭的那一刻、全章情绪顶点），
   可以留几行喘不上气的短句——**每行是一个完整的短句**，不是一个字加破折号。样板：
   ```
   又动了几下。

   太快了。

   他压不住。
   ```
   全章其余部分照样稿的节奏。
8. **引号**：正文一律弯引号 “ ” / ‘ ’，ASCII 的 " 一个都不留。
9. **语言穿帮**（人物说的是英语，中文只是译文）：
   - 别数汉字：“我好想你”那句在英文里是 I missed you，别写“那四个字”，写“那句话”；“……Moira。”别写“就两个字”，写“一个名字”。
   - 凡是「就 N 个字」「那 N 个字」都过一遍：翻回英文还是这个数吗？不是就改成「一句」「那句话」「那个名字」。
10. **去中式**：查仓库 `CLAUDE.md`「严禁中式出戏表达」那张对照表。阿巴拉契亚山里：刀叉、威士忌、靴子、农用品店。
11. **草稿残留直接修**：同一段写了两遍（只留一遍，留更合前后文的那个）、小节跳号、「昨天」其实是好几天前之类。修了要在报告里列出来。

## 剧情逻辑问题：不改，报告

前后矛盾、跟别的章对不上、人物知道了此刻不该知道的事、时间线算不拢——**不要自己改剧情**，
原样保留，在报告里写清楚：在哪一节、哪一句、跟哪里冲突、你建议怎么改（给一两个改法）。
Winter 会自己拍板。（只有上面第 11 条那种「明显的草稿残留」可以直接修。）

## 篇幅

通常会缩到原稿的 65–80%。少掉的只能是重复和断行，不能少情节。
