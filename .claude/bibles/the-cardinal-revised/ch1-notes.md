# Ch1 · 认得那种神情 — 为什么这么写

- **开场机关**：Vivian 把「你」丢下 → Kris 一眼认出「被丢下的那一个」。这不是巧合，是全系列的题眼：他对被撇下的灵魂有耐心，因为他认得那种神情（他自己就是）。
- **那杯水**：他没问你要喝什么，直接给水。这是他「把亲密藏进很小的动作里」这条内核的第一次示范——全系列他所有的深情都走这条路，不走台词。
- **Joe 的账**：用来立他的声口——不冷不热、不提高声音、不带怜悯地说「账还是要结」，然后一句「现在他什么都不记得了」。他的温柔是见过太多之后的平静，不是心软。
- **名字的第一层**：`Kris`（对外）→ `Krzysztof`（本名，沉默半秒才肯给）。「Close enough」是全系列被回收得最狠的一句——Ch7 她定下目标要摆脱它，Ch15 她做到了。
- **坏掉的字母 A**：CARDINAL 招牌上黑着的那个 A，「像一句话说到一半被人掐断」。这是他这个人的视觉化身。**尚未回收**（见圣经 PINNED）。
- 左手纱布在这一章只是「他自然搭在吧台下面」，不解释——伤的来历压到 Ch10 才给。
