# Ch2 · 他没有走 — 为什么这么写

- **谁先动的**：是「你」先吻的他。这一条很重要——全系列他一直在退半步，每一次跨越都要由她先迈，直到 Ch6 他才第一次自己迈过来。
- **那半步**：送到楼下「往后退了半步」。这个动作是全系列的核心肢体母题，Ch3 复现、Ch5 被月光打破、Ch6 彻底跨过。
- **小银十字架**：第一次出现，只写「他从不摘下」，不解释。来历压到 Ch8（是他妈妈的）。
- **第一夜那个波兰词**：他埋在她颈窝里说的那个词，**全系列最大的伏笔**，至今未揭。规矩是：谁都不许提前解释，她也不许问到答案（Ch15 她问了，他用「你波兰语还不够好」赖掉）。
- 床戏刻意 fade-to-black——这一夜的重量在「他没有走」，不在过程。辣留给后面（Ch10 / Ch15）。
