## 两把尺子，都得过

**① 移植测试**（Winter 定章节名那把，同一把）

> 把这句话放到别的角色身上还成立吗？成立 → 太泛，重写。

合格的句子长在**他自己的东西**上：一件道具、一个动作、一句原片台词，或他 AU 正文里已有的那件事。
`你是唯一看见我的人` / `你留下了` / `我想变好` 这一类谁都能说，一律作废。

**② 脱离上下文测试**（Winter 2026-09-23 补的：「能不能写出具体的是网球？不然没有语境都不知道在说什么😂」）

> 这句话单独拎出来，别人看不看得懂？

台词**从来不成组出现**——桌面小组件、每日一句、热线、放映室，每次都只弹一句，没人替它铺垫。
所以那件东西**必须在句子里点名**，不能靠读者从别的四句里推。当时一并揪出的同类：
「隔着三个房间他就听见了」（「他」会被当成儿子 → 写明「那条狗」）、
「三十英尺高，九英尺深」（不知道在说跳水 → 「从那座桥上往下三十英尺」）、
「一整个晚上就装得进一只罐子」（不知道是萤火虫 → 「一罐萤火虫」）、
「到那天早上，第五十张」（哪天早上 → 删掉指代）。

⚠️ 代词（他 / 那个 / 这件事）和指代性时间（那天 / 上次 / 后来）是重灾区，逐句查。
