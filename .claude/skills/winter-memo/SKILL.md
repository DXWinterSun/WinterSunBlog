# 冬的灵感本：聊出来的点子记下来，她一问就能答

这本东西 2026-10-03 一天里改了四次，最后定成这样（她的原话，按先后）：

1. 「我在 code 对话里面可能会说我想做的一个 Sam 的视频，然后你和我讨论并且记录在博客里，以后如果我自己
   忘记了，我也能随时在任何一个对话里问你，你能调取并且告诉我。」
2. 「线上就别编辑了，我想只能从你这改，这样不涉及 token 之类的。」
3. 「我日常可能想做的事情，我还是习惯性地会用苹果的备忘录，也比较方便实时地去增添和修改。可能这个功能我更想做的，
   还是那种长期的或者是当下的那种灵感，你可以帮我记下来。好像其实没必要放在桌面上，最主要的是我能在问你的时候，
   你能快速地告诉我，然后我自己点进来也能看见。」

所以：
- **只收灵感**：当下冒出来的点子、要慢慢做的长期计划。日常待办（交课件、取快递、申报……）她在苹果备忘录里记，
  **别往这里收**；她明说要记的话照记，放进最近的那一页。
- **只在对话里改**：网页只读、不要钥匙。别再往网页上加输入框、勾选、设置之类的编辑功能。
- **没有桌面小组件了**（第二、三版做过，第四版她说不需要，已经拿掉）。别再提议装小组件。

⚠️ 网页挂在博客上、不要钥匙，**谁逛到都看得见**（仓库本身也是公开的），这件事已经跟她说过。太私密的别往里记。

| 页 | id | 放什么 |
|---|---|---|
| ✨ 当下的灵感 | `now` | 刚冒出来的点子：想拍的视频、想发的帖子、一个 AU 桥段、一个企划的苗头 |
| 🌳 长期的计划 | `long` | 定下来要慢慢做的：Sam 相关的长期企划、要分几步做完的项目——这类最常带进度 |

点子聊着聊着定下来要做了，就 `edit <编号> --page 长期` 挪过去。页名和页数她想改就 `page-rename` / `page-add`。

## 一条长什么样

| 部分 | 字段 | 说明 |
|---|---|---|
| 标题 | `text` | 一句话说清是什么，短一点，列表上一眼能认出来 |
| 备注 | `note` | 想法、讨论定下来的东西、链接、素材出处——网页上点开那一条才看得到 |
| 进度 | `log[]`，每笔 `{id, at, text}` | 一笔一笔带日期，网页上新的在上面 |
| 置顶 / 到期 | `pin` / `due` | 很少用；她提了才填 |
| 做成了 | `done` / `doneAt` | 做成的收进每页底下「已经做成的」，不删 |

## ⭐ 聊出一个点子 → 记下来；她问起 → 马上答

**记**（不用她开口说「记一下」）：聊出了结论——定了做什么、怎么做、下一步是什么——就在那个自然的停顿处记进去，
然后用一句话告诉她「记进 ✨ 当下的灵感 了」：

1. 先 `find` 一下有没有这条（她以前提过就续在那条上，别开第二条）。
2. 没有 → `add <页> "<短标题>" --note "<结论>"`；有 → `note <编号> "<这次新定的>"` 往后续一段。
3. 备注写**结论，不写聊天记录**：定了什么、为什么、还悬着什么、下一步。每段开头带日期（`10/3：`），
   日后看得出是哪次聊的。她自己的原话、她挑中的选项，照原样写进去。
4. 有实际推进（剪完了、发了、写完第一章）→ `log <编号> "<做到哪>"`；做成了 → `done`。

**答**：她问「我之前说的那个 Sam 视频是什么来着」「我都有哪些灵感」「XX 做到哪了」——
先 `find <关键词>`（连做成的、备注、进度一起搜），找到用 `show <编号>` 看全，再用人话讲给她：是什么、定过什么、
做到哪、下一步。问「都有哪些」就 `ls`，按页几行话列出来。**别贴命令输出。**搜不到换个说法再搜，
真没有就直说没记过，问要不要现在记。

⚠️ 这一套只在 **Claude Code 的对话**里灵（这边看得到博客仓库，开新对话也一样）。普通聊天窗口看不到，她问起照实说。

## 命令（照抄就行）

先拿到最新的工具（工作区就在 main 上时不用）：`git fetch origin main && git checkout origin/main -- tools/memo/memo.py`

```bash
python3 tools/memo/memo.py ls                        # 全部（含 6 位编号、有没有备注 / 进度）
python3 tools/memo/memo.py find 采访 Sam              # 连做成的、备注、进度一起搜，几个词要同时出现
python3 tools/memo/memo.py show k3f9a2                # 一条的全部：备注 + 每一笔进度
python3 tools/memo/memo.py add 当下 "Sam 采访合集视频" --note "10/3：三分钟以内，配中英字幕"
python3 tools/memo/memo.py note 采访 "10/5：结尾放他笑场那段"    # 往备注后面续一段（不覆盖）
python3 tools/memo/memo.py log 采访 "粗剪完了，字幕还差一半"       # 记一笔进度（今天；补记旧的加 --date 10-01）
python3 tools/memo/memo.py edit 采访 --page 长期       # 挪页；--text 改标题；--note 是整段替换（续写用 note）
python3 tools/memo/memo.py done 采访                  # 做成了；undone 改回来
python3 tools/memo/memo.py rm k3f9a2                  # 她说「不要了 / 删掉」才删
python3 tools/memo/memo.py top k3f9a2                 # 挪到这一页最前面
python3 tools/memo/memo.py pages                      # 看有哪几页
python3 tools/memo/memo.py page-add 读书 📚 --hint "想读的书"
python3 tools/memo/memo.py page-rename 长期 --name 慢慢做的 --emoji 🌱
```

- 页名认口语：当下 / 灵感 / 点子 / 想法 / 刚想到 → ✨当下的灵感；长期 / 计划 / 项目 / 企划 → 🌳长期的计划。
  她新加的页按名字认（别名表在 `memo.py` 头上的 `ALIASES`，页改名后顺手补）。
- 每个改动都加 `--trailer` 把会话要求的署名行带上（会话提示里给的那两行，原样一行一个 `--trailer`）。
- 想先看效果不推：加 `--dry-run`。
