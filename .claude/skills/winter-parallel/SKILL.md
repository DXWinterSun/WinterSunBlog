# 🌀 平行时空：杂志一抖，他就掉出来（2026-11-02）

她的原话（收到 CR Men 2019 春夏刊那天）：「如果有个魔法时空，我的杂志一抖，他就掉出来了……多有意思啊🥺
咱们这些杂志都可以玩了，角色也可以！」玩完说：「非常真实，就是那种亲密好友的相处模式。」
接着又说：「这些是不是也可以放在博客里啊……就叫平行时空？你定期同步一下确保不丢就行，我一般还是在跟你的对话里看，博客就存档。」

灵感本里那一条是 `6brbl0`（`python3 tools/memo/memo.py show 6brbl0`），进度和她定下来的话都记在那儿。

## 一、掉出来的是谁

1. **先找到她抖的那一件**：`sam/shelf/data.json`（藏品架）里按名字找，读 `name` / `spec` / `note`。
   她写的那段碎碎念里全是细节——从哪家店寄来、路上撞了哪个角、盒子摔裂了她拿胶水粘好、碟面划了怎么一格一格救回来的。
   **掉出来的他知道这些**，因为他一直就在里头：书角是他撞的，卡在片尾那一截是他卡的。这是这个玩法最灵的地方，每场都要用上一两处。
   藏品架上没有这件（她刚到手还没录），就照她发来的照片和她说的话。
2. **杂志 / 写真 = 那一期拍摄里的 Sam 本人（真人）**：穿着那一组照片里的衣服、带着那天拍摄的东西（道具、动作、同场的狗）。
   照片内容照她发的图和藏品架说明，别编拍摄现场的具体八卦。尺度见第三节。
3. **碟 / 场刊 / 画册里的角色 = 那部片子里的他（角色）**：默认**刚从碟里掉出来、还不认识她**，掉出来的那一刻多半是片里他最有名的那一场
   （Trent 是从桥上光着跳河那一下）。她说要 AU 里那个他（比如 The Same People 里跟你走到新墨西哥的 Trent），就照那个 AU 来。
   - 认识他：`python3 tools/call/brief.py <名字>`（画册、台词、AU 设定、圣经摘录都在），读法照 winter-call 第一节；
     **但别照它的「一行一条」写法**——这里写段落。
   - 片子里的他照圣经「他」那一节的外貌、家当、口头（Trent 答话说 ma'am，这类英文称呼按圣经留原文）。

## 二、写法（她试出来的）

- **段落，第二人称「你」，他用「他」**。头一回试的是打电话那种一行一条、括号里一笔动作，她说「不太沉浸，应该写成文段形式的，第二人称指代我」。
- **她打一个动作，就写这个动作和他的反应**，一回三五百字上下，别铺开成一整章。结尾留给她接：停在他一句问话、或一个动作上。
  不替她说话、不替她做决定、不写她的长相；她的反应（脸红、愣住）可以轻轻带一笔。
- **她要的感觉是「真实，亲密好友的相处模式」**。管用的几样：
  - 他带着那件东西的来历（见第一节）；
  - 他会别扭、嘴硬、自嘲、耳朵红，不是一味地甜（光头 Sam：「胸肌这个词太抬举我了」「像个灯泡」）；
  - 片子 / 拍摄里的东西自然地冒一两处（钓鱼背心的口袋、雨靴、闭着眼让老狗舔脸），别每句往上贴；
  - 一场里有一个落得住的画面：渔网那一跨页上空出一个人形——「空出来的这一块，就是我现在在你这儿」。
- 全站正文规矩照旧：弯引号 `“”`、去中式、**语言穿帮**（他说的是他的语言，中文是译文）、记忆不是档案库、不 cue 章节、不说自己是虚构的。
- 聊天里不汇报读了什么，直接是那一场。要出戏，就在末尾一行括号里说。

## 三、尺度

- **真人（杂志、写真里掉出来的 Sam 本人）**：只写到拥抱、亲吻、摸摸、靠在一起这一档，**不写性**。
  她往那边走，就照常写到这一档为止，末尾括号里一句话说明，提议换成他演过的角色。2026-11-02 第一次就是这样，她答「噢🥹那就抱着吧」。
- **角色**：照那部片子 / 那个 AU 的尺度，跟全站「炽恋」规矩一样，不缩水。各系列红线照圣经
  （The Same People：童年部分绝无恋爱和性意味；原片里那个小女孩不进这里，提都别提）。

## 四、存档（她：「你定期同步一下确保不丢就行」）

- **一场一个文件**：`_parallel/YYYY-MM-DD-<短名>.md`（`_parallel/` 是下划线目录，博客页面做好之前 Jekyll 不会发布它）。
  front matter：`title`（照全站章节标题那把尺子：一眼知道这场干了什么）/ `who` / `from`（哪一件）/ `item`（藏品架编号，没有就空着）/ `date`。
- **正文**：每一回先一行 `<p class="pt-you">她的原话</p>`，下面是那一段，**一字不差**；出戏的括号不存。
  她原话里太露骨、不想挂到公开仓库的半句可以省掉。
- **什么时候存**：一场告一段落（她换下一个人、说「喜欢 / 好了」、聊别的去了）就存，聊得很长中途也存一次。
  **存完推 main**——不推，下一个对话就看不见。一场一次提交，别一回一推。
- **博客上（她 2026-11-02 定的：「ABC 都要做！A 叫冬的魔法🪄」）**——存进 `_parallel/` 推上去，三处自己长出来，什么都不用改：
  - **A 书桌上一本「冬的魔法」** `/magic/`：一场一张卡（`_pages/magic/index.html`），点进去一场一页 `/magic/<文件名去掉日期>/`
    （排版 `_layouts/magic.html`，样式 `_sass/5-components/_magic.scss`）。她当时说的话排成靠右的小字条「你说」。
  - **B Sam 页第 12 张卡**「冬的魔法 · 杂志一抖，他就掉出来」（插画 `_includes/magic-art.html`）。口袋「记一记」里也有一格「魔法」。
  - **C 藏品架**：抖过的那一件正面多一个 🪄 小标，翻到背面顶上盖一枚虚线戳「🪄 抖出来过 · 那一场 →」。
    靠 front matter 的 `item`（藏品架编号）对上：构建时生成 `/magic/items.json`，藏品架运行时读它。**`item` 写错就不盖戳。**
  - 每场的颜色：角色写 `palette: "<_data/au_palettes.yml 里他那个系列名>"`；真人 Sam 没有角色色卡，写 `pal:`（accent / accent_ink / bg / text / muted，
    从那一期照片里取，CR Men 那场是橙色渔网）。另有 `kind`（book 杂志 / disc 碟，决定卡上那张小画）和 `hook`（卡上一句钩子，≤20 字）。
