# 冬的私人档案

仓库是**公开的**。出行档案里有护照号、签证确认号、家庭住址、邮箱、单位、收入，
所以跟「冬的陪伴」一样**整份加密**，放在单独的 `private` 分支（不在 main，不触发建站）。
她 2026-10-27 点头同意的：「加密整份存」。

```bash
python3 tools/private/private.py ls                    # 有哪几份
python3 tools/private/private.py show <名字>           # 正文 + 带日期的进度（先读这个再答）
python3 tools/private/private.py show <名字> --log 10  # 只看最近几条进度
python3 tools/private/private.py note <名字> "一句进度" "又一句"     # 记进度（自动带日期）
python3 tools/private/private.py put <名字> --title "标题" < 草稿.md  # 整份正文换新（进度留着）
python3 tools/private/private.py show <名字> --page    # 印出网页上那份（JSON）
python3 tools/private/private.py page <名字> < 网页.json # 换掉网页上那份
```

**她自己能看**（2026-10-28：「现在这些记录你都放哪里的，我在哪能看见」→「做，重要信息都放进去」）：
书桌上那本上锁的 **🧳「冬的行程」`/trip/`**（`trip/index.html`，口袋「记一记」里也有一格「行程」），
同一个密码在浏览器里解开。页上排的是每份档案的 **page**（登机牌倒计时、下一步、戏票、每天、待办、
签证 / 剧场 / 住和走、预算），下面接着**进度**（就是 `note` 记的那些，新的在上）和折起来的原稿。
page 的格式写在 `trip/index.html` 开头的注释里。**票买了、事办了、日程变了 → 进度 `note` 一笔，
同时 `show --page` 取出来改好、`page` 存回去**（明文草稿放会话临时目录，存完就删），她刷新就看得到。
⚠️ 进度她在网页上也会读到：写成她看了也明白的话，别写成只有下一个对话才懂的暗号。

提交时带上 `--trailer` 署名尾行（同 texts.py）。

## 每次怎么做

1. **先 `ls` → `show`**，尤其看正文开头的「核对出的变化」和文末「进度」——以那两处为准，
   正文是当初交接时的原样。
2. **再答**：事实类（签证规定、收费、票价、演出档期、交通）**先查证再说**，她要求过；
   查到跟档案对不上的，告诉她，并 `note` 一笔。
3. **她报了进展**（票买了、密码改了、材料打印了、机票订了）→ `note` 记一笔。
   待办大面积变了，就把正文导到会话临时目录、改好、`put` 回去，**改完立刻删掉那份明文草稿**。
4. 她说起这件事时，顺手看一眼「待办总表」里**最近到期**的那一两项，提醒一句。

## 规矩

- ⚠️ **明文只许出现在对话里和会话临时目录（用完就删）**。档案里的号码、地址、收入
  **绝不写进 main 上的任何文件、提交说明、圣经、灵感本、护肤档案或博客页面**。
  公开文件里提到这件事，最多写到「冬的私人档案里有一份」，别写日期、别写号码。
- **别让她把任何密码打进聊天**（WINTER_TEXT_KEY、签证预约网站的密码都一样）。
- 档案里查不到的细节**别猜**：交接档案注明了来源对话（例如 claude.ai 上的 Klaus），
  让她回那边问。
- 说话照她的习惯：中文、人话、先说结论。「EVUS」这类没有通行中文说法的照写，顺手讲一句它是干什么的。
- 存档时要是被自动安全检查拦下（它见到护照号这类东西会拦），告诉她拦的是哪一步、为什么，
  等她点头再做，别绕过去。
