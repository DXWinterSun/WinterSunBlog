# 波兰语笔记本：问一题 → 讲清楚 → 收进笔记 → 下次能指路

2026-10-01 Winter 原话：**「我想之后能做成我在多邻国遇到错的或者有疑问的地方的时候，我就来对话里给你并且问你，
你给我解释清楚之后，顺便整理到波兰语学习的笔记里，你可以进行更好的分类以便我学习。我之前是在 claude 对话里问的，
看完就忘了，拿笔记本写的话很多时候局限于外部条件🥹……如果我之后还问之前问过的，你有存档可以查就可以给我指路，
也会加深我的记忆。我希望你做成不管我开不开新的对话，你都能知道我想让你干什么，我不想每次都解释一遍。」**

所以：**她来问，就直接答、直接收、直接发——不用她说「记进笔记」，也别问她「要不要记」。**

她是**真正的零基础初学者**（课本是李金涛《波兰语》，同时在多邻国上学；多邻国的波兰语课是从英语教的，
所以题面常是英语）。讲解一律用中文、说人话，别中英夹杂（她的固定偏好）。

## 一句话流程

**查档 → 讲 → 收 → 发 → 推**，每次都走完这五步：

1. **查档**：`python3 tools/polish/find.py <关键词>`——问过就先指路。
2. **讲**：在聊天里讲清楚（格式见第二节）。
3. **收**：往 `_data/polish/notes.yml` 的 `notes` 末尾加一条（问过的就在原条上记一笔）。
4. **发**：生成网页，发布到**同一个链接**（`meta.artifact`），博客那页一起重新生成。
5. **推**：commit 并推 `main`——**数据必须在 `main` 上，下一个对话才查得到。**

## 文件都在哪

| 东西 | 位置 |
|---|---|
| 笔记数据（唯一真源）＋ 分类表 | `_data/polish/notes.yml`（`meta` / `areas` / `notes`） |
| 查档 | `tools/polish/find.py`（不分大小写、不管字母上的小符号；对不上会去掉词尾再试） |

| 网页链接 | `meta.artifact`（永远更新这一个） |
| 博客上的位置 | `/polish/`，入口在 Gallery 里「波兰语变格」那张卡旁边（有了第一条真笔记才出现） |

## 一、先查档（每一次都查，哪怕看着是新问题）

```bash
python3 tools/polish/find.py kawy            # 她问的那个词
python3 tools/polish/find.py 否定 生格        # 也可以按知识点、中文搜
python3 tools/polish/find.py --id 007        # 看那一条原来怎么讲的
```

- 用她问的那个词、它的原形、涉及的知识点各搜一次；「可能相关」那一批要自己看一眼是不是同一回事。
- **问过了** → 回复第一句先指路：**「这个你 9 月 24 日问过，是笔记第 7 条《否定句里，宾语要换成生格》。」**
  然后**换一个更生活化的讲法**再讲一遍（她问第二遍＝「请说得更简单」，别复读原来那段），
  再在那一条的 `asked:` 里加上今天的日期——卡上会自动变成「🔁 问过 2 次」，目录里也会进「问过不止一次」。
  这次有新角度、新例句，补进那条的 `qa` 或 `examples`；**不另开一条**。
- **只是沾边**（比如以前问过生格，这次问的是否定句里的另一种情况）→ 开新的一条，用 `see: ["007"]` 连过去，
  回复里也提一句「跟第 7 条是一家的」。

## 二、在聊天里讲

她要的是「解释清楚」，不是一堂语法课。照这个顺序，越短越好：

1. **一句结论**：做错的，直接说错在哪个词、应该是什么（`kawę` → `kawy`）；有疑问的，直接给答案。
2. **为什么**：两三小段。第一次出现的术语用一句话说明白（「生格＝第二格，大致是‘……的’‘没有……’」）。
   能接上她已经会的就接上：类比英语、类比中文、回扣笔记里以前的某一条。
3. **记住**：一句口诀。
4. **再看两三句**：短例句，带中文。

写法规矩：

- **准确第一**（她明确很看重）。词尾、变位、性别拿不准，先 `python3 tools/polish/forms.py <词>` 核对；
  词库里没有的再上网查。⚠️ 这个环境**打不开维基词典的网页**（直接抓取会被拦），改用网页搜索
  （搜「wiktionary <词> Polish declension / etymology」，搜索结果里会带出词条内容）。**绝不凭印象写词尾。**
- **她拿来别的对话的总结**（2026-10-01 第一批就是这样来的）：逐条核对，对的照收、拆成一题一卡，
  漏的补上、错的改掉、核不到的数字删掉；聊天里只用几句话告诉她改了哪几处，不把整份总结复述一遍。
- 波兰语一律写对附加符号（ą ć ę ł ń ó ś ź ż）；她打字时省了符号，你写的时候补回来。
- **多邻国截图**：认出题型（左上那行大字）、题面、她写的答案（原样，大小写、有没有句号都照抄）、
  正确答案、底下那条结果（Great job / You have a typo / 错）和 Meaning 那句英语，分别填进
  `task` / `pl` / `mine` / `right` / `ok`·`typo` / `en`。看不清的地方直接问，别猜。
  她一次发好几张截图时，笔记本里已经有的那题就把截图上的新细节补进原卡，没有的才开新卡。
- **多邻国自己有问题的时候照实说**：有些说法其实也对、只是多邻国没收，就说「你这个也对，多邻国没收而已」，
  归到「多邻国的坑」。别为了迁就判分把对的讲成错的。
- 中文讲解里引号用弯引号 “ ”。
- 回复**最后一行**交代收在哪：**「已收进笔记第 N 条《标题》，归在 名词 › 生格。」** 加上网页链接。
  不要把整张卡再贴一遍。

## 三、收进笔记

### 每条怎么写

```yaml
- id: "003"                   # 三位数字，全本连号；永远不改、不复用（批注锚在卡片编号上）
  date: 2026-10-01            # 第一次问的日子
  asked: [2026-10-15]         # 后来又问的日子（第一次不算），问一次加一个
  source: 多邻国              # 多邻国 / 课本 第 3 课 / 别处
  point: noun.gen             # 主知识点：areas 里的「大类.知识点」
  also: [syntax.neg]          # 也沾边的知识点（可选；那里会放一张指过来的小条）
  title: 否定句里，宾语要换成生格   # 一句判词，见下
  ask: ……                     # 她的问题（有疑问时写；她原话或贴切的概括）
  pl: "Nie piję ==kawy==."    # 题目里的波兰语（正确的那句），==…== 标出关键的地方
  en: "I do not drink coffee." # 多邻国题面的英语（有才写）
  zh: 我不喝咖啡。
  mine: "Nie piję ==kawę==."  # 她写的（做错时才写；写了这条卡就算「做错了」）。只知道她写错的那个词，就只写那个词
  ok: true                    # 她答对了、只是想弄懂为什么（卡上显示「答对了」）；mine / ok 都不写＝「有疑问」
  typo: true                  # 多邻国判「You have a typo」（算过了，但拼错了一点）：卡上显示「差一点」
  task: listen                # 多邻国题型：listen 听到什么写什么 / fill 补上缺的词 / translate 翻译这句话 /
                              #   choose 选出正确的意思 / speak 把这句念出来 / match 配成对。不知道就不写
  to: en                      # 只有 translate 写：她译成哪门语言（默认 en；她把英语译成波兰语就写 pl）
  lang: en                    # 只有「顺带聊到的英语」那几张写：🔊 改用英语念，生词不挂「查变格」
  right: ["Nie piję ==kawy==."]   # 正确答案，可以几个
  why: |                      # 为什么：两三段，一行一段
    ……
  rule: 有 nie，宾语就从宾格换成生格。   # 一句口诀
  table:                      # 可选：小对照表（变格、变位最适合）。默认第一列是中文、其余是波兰语；
                              #   不是这样排的，写 pl: [1] 指明哪几列是波兰语（从 0 数）
    head: ["", "肯定 · 宾格", "否定 · 生格"]
    rows:
      - ["kawa 咖啡", "Piję ==kawę==.", "Nie piję ==kawy==."]
  extra: ["**例外**……", "**易混**……"]   # 可选：带小标签的补充
  examples:                   # 两三句
    - {pl: "Nie mam ==czasu==.", zh: 我没时间。}
  words:                      # 这题里的生词：原形 + 小标签 + 中文
    - {pl: kawa, zh: 咖啡, tag: 阴}     # 词组写 look: 要查的那个词（bać się → look: bać）
  see: ["001"]                # 相关的别的笔记
  winter: ["……"]              # 她在批注里写的话，原话照录
  qa: [{q: ……, a: ……}]        # 批注里追问的问答
```

- **一张卡只装一件要记的事。** 她一次问了两件，就两条；一道题里同时错了两处不相干的，也拆成两条。
- **标题要过「遗忘测试」**（全站定章节名的那把尺子）：过一阵子只看标题，能不能想起这条讲的是什么？
  用一句大白话判词——「否定句里，宾语要换成生格」✅，「生格」❌，「kawa 的变化」❌。
- **分类只能用 `areas` 里有的知识点**；真的都不合适，先在 `areas` 里加一个（`key` 用英文小写），
  再在本文件第六节记一笔为什么加。不要在笔记里随手写新名字（脚本会报错）。
- `words` 的小标签：名词写性（阳 / 阴 / 中，有生命的阳性写「阳 · 有生」），动词写体（未完成体 / 完成体），
  其余可空。写原形（名词单数主格、动词不定式）。
- `pl` / `right` / `examples` 里的句子都要带句末标点（复制去 Google 翻译时它只认标点停顿）。
- 这个仓库是公开的：只写那一道题、那几句例句，不整段抄课本、不抄多邻国的大段内容。

搜「属格」也能搜到生格那些卡。

### 卡片长什么样（2026-10-01 她要「做成更多邻国的形式」）

每张卡上半截照多邻国做题页排：题型大字 → 小雪人和说话气泡（听力题气泡里只有 🔊 和 🐢 慢速两个键，
其余题型气泡里是那句波兰语）→ 她的答案（听写、补词是一个答案框；译成英语是一排单词块）→
底下绿色（答对了 / 有个小拼写错误）或红色（不对哦 + 正确答案）结果条，带「意思」。
下半截是讲解：💡 为什么、📌 口诀、表格、🗣 再看几句、🧩 生词（单词块，点一下就念）。
每个大类是一条彩色「单元横幅」。⚠️ **只借多邻国的样子**：不放它的名字、标志、角色（说话的是站里的小雪人）和专用字体。

## 四、生成、发布、推送

```bash
python3 tools/polish/render_polish.py -o <scratchpad>/polish-notes.html   # 给她看的
python3 tools/polish/render_polish.py --blog                              # 博客 polish/index.html
```

- **一本笔记只有一个链接**：`meta.artifact`。
  - 同一个对话里：用同一个 `file_path` 再发布。
  - 换了对话：先 `Artifact(action="read", url=meta.artifact)`，再带 `url=meta.artifact` 发布。
  - 第一次发布带 `capabilities: {"comments": {"composer_only": true}}`（卡上的「批注」按钮靠它），
    之后**不传** `capabilities`，保持原样。
- 还没有任何笔记时页面显示 `demo.yml` 里的两张样板；有了第一条，样板自动撤掉。
- **每一轮答完都 commit 并推 `main`**（数据 + 博客页 + 有改动的话连同本文件），提交说明写
  「波兰语笔记：No. 003 否定句里，宾语要换成生格」这样。
  理由：新对话是从 `main` 拉的仓库，**不在 `main` 上的笔记，下一个对话查不到**——这正是她要的「留档、能指路」。
  她连着问好几题时，一条消息里的几题合成一次推；前后两次推得太近，前一次网站构建会被后一次顶掉，
  这没关系，最后那次会跑完、内容是全的。Artifact 是即时更新的，她看笔记不用等网站构建。

## 五、她批注之后

她在网页上点卡片底下的「批注」追问时，正在看这页的对话会被唤醒；换了对话，先
`ArtifactComments(action="watch", url=…)` 接上，或 `action="read"` 主动去读。每次：

1. 按卡片编号（`n003`）对上是哪一条。
2. 追问 → 在批注里直接回，中文、简短；有用的问答收进那条的 `qa`。
3. 感想 / 自己的记法 → 原话一字不改收进 `winter`。
4. 指出错误 → 改数据，在批注里说一句改了什么。
5. 重新生成、发布、推送；回完的批注串标成已解决。
